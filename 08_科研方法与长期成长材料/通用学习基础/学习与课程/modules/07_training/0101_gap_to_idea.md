## Gap 的定义

Gap = 论文没有解决、但值得解决的问题
Gap 不是"论文做错了"，而是"论文没做完"的地方。

## Gap 的六种类型（骨架）

| 类型 | 定义 | 改进方向 |
|---|---|---|
| 1. 假设过强 | 现实中不成立的假设 | 放松 / 替换假设 |
| 2. 范围有限 | 只分析部分情况 | 扩展参数范围 |
| 3. 缺少分析 | 该做但没做的分析 | 补充分析 |
| 4. 结论存疑 | 结论可能被推翻 | 验证稳健性 |
| 5. 应用空白 | 理论没应用到某领域 | 跨领域应用 |
| 6. 方法限制 | 有更强大的工具可用 | 方法升级 |

## 五步法（骨架）

### Step 1: 识别 Gap
1. 读论文的 AUDIT.md 中"新发现 Gap"部分
2. 判断 Gap 类型（1-6）
3. 记录位置（章节/公式）

### Step 2: 理解 Gap 的边界
1. 明确限制条件
2. 放宽哪个条件让 Gap 消失
3. Gap 影响范围（局部 vs 全局）

### Step 3: 生成改进方向
- 方向 A：放松假设
- 方向 B：扩展范围
- 方向 C：补充分析
- 方向 D：挑战结论
- 方向 E：跨领域应用

### Step 4: 评估可行性

| 维度 | 评分 |
|---|---|
| 新颖性 | ⭐-⭐⭐⭐⭐ |
| 可行性 | ⭐-⭐⭐⭐⭐ |
| 技术难度 | ⭐-⭐⭐⭐⭐ |
| 价值 | ⭐-⭐⭐⭐⭐ |
| 与主线关系 | 高/中/低 |

### Step 5: 细化研究方案
- 来源 Gap 类型
- 核心问题
- 假设
- 分析方法
- 预期结果
- 技术路径
- 时间估计
- 所需资源
