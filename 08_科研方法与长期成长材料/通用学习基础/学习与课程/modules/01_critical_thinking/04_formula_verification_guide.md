## 什么是公式推导验证？

公式推导验证是**独立重新推导论文中的核心公式**，确保：
1. 推导没有跳步
2. 没有隐藏的假设
3. 数值结果正确

**原则**：不信任任何未经验证的公式。

---

## 选择要验证的公式

### 选择标准

从论文中选择 2-3 个核心公式进行验证：

| 标准 | 说明 |
|---|---|
| **重要性** | 后续命题依赖这个公式 |
| **复杂性** | 形式复杂，有跳步嫌疑 |
| **可验证性** | 有明确数值结果可对照 |

### 通常要验证的公式类型

1. **效用函数**：核心行为假设
2. **均衡条件**：一阶条件（FOC）
3. **比较静态**：参数变化的影响
4. **数值结果**：表格中的具体数字

## 验证流程

### 第一阶段：理解公式来源

**问题清单**：
1. 这个公式从哪个原始定义出发？
2. 经过哪些中间步骤？
3. 用了哪些恒等式/引理？
4. 有什么假设？

**Paper 02 (β-1)/e 示例**：

| 问题 | 答案 |
|---|---|
| 从哪个原始定义出发？ | Kőszegi-Rabin 损失厌恶框架 |
| 经过哪些中间步骤？ | x⁺ + x⁻ = x 恒等式 |
| 用了哪些恒等式？ | E[(W-W₀)⁺] = W₀/e（指数分布性质）|
| 有什么假设？ | 参考点 W̄ = W₀（理性预期）|

---

### 第二阶段：独立重新推导

**原则**：不看原论文，自己推一遍

**方法**：
1. 写出原始定义
2. 一步步推导，每步都要写出来
3. 如果卡住，记录困惑点
4. 完成后对照原论文

**常见技巧**：

| 技巧 | 适用场景 | 示例 |
|---|---|---|
| 变量替换 | 复杂积分 | u = w - W₀ |
| 拆分期望 | 分段函数 | E[max(X,0)] |
| 恒等变形 | 简化表达式 | x⁺ + x⁻ = x |
| 边界情况 | 检验正确性 | θ = 1 时退化为... |

### 第三阶段：代码验证

#### 3.1 SymPy 符号验证

```python
from sympy import symbols, integrate, exp, oo, simplify

# 定义符号
w, W0, eta = symbols('w W0 eta', positive=True)

# E[(W-W0)^+] = ∫_{W0}^{∞} (w-W0) · η · e^{-ηw} dw
E_pos_part = integrate(
    (w - W0) * eta * exp(-eta * w),
    (w, W0, oo)
)
print("E[(W-W0)^+] =", E_pos_part)
# 输出: W0*exp(-1)

# 验证 = W0/e
print("W0/e =", W0 / exp(1))
print("相等？", simplify(E_pos_part - W0/exp(1)))
# 输出: 0（相等）
```

#### 3.2 数值验证

```python
import numpy as np

# 蒙特卡洛验证
N = 100000
W0 = 1.0
eta = 1.0

# 生成指数分布样本
samples = np.random.exponential(1/eta, N)

# 计算 E[(W-W0)^+]
E_pos = np.mean(np.maximum(samples - W0, 0))
theoretical = W0 / np.e

print(f"Monte Carlo: {E_pos:.6f}")
print(f"Theoretical: {theoretical:.6f}")
print(f"Error: {abs(E_pos - theoretical):.6f}")
```

### 第四阶段：边界情况检验

**为什么要做边界检验？**

边界情况是检验公式正确性的试金石。

**常见边界情况**：

| 边界情况 | 检验内容 | Paper 02 示例 |
|---|---|---|
| **退化检验** | 参数取特殊值时是否退化到已知结果 | β=1 → F型退化为E型 |
| **极限检验** | 参数趋向极端值时行为是否合理 | β→∞ → 效用→-∞ |
| **对称性检验** | 对称参数下结果是否对称 | θ_A = θ_B |
| **单调性检验** | 参数增加时结果是否单调变化 | θ↑ → P↑? |

**Paper 02 β 系数边界检验**：

| 情况 | β 值 | 预期 | 验证结果 |
|---|---|---|---|
| 无损失厌恶 | β = 1 | 系数 = 1 | ✓ |
| 极度损失厌恶 | β → ∞ | 系数 → ∞ | ✓ |
| 常见值 | β = 2 | 系数 = 1 + 1/e ≈ 1.368 | ✓ |

## 常见错误及处理

### 1. E[(W-W₀)⁺] ≠ W₀(1-1/e)

**错误**：
```
E[(W-W₀)⁺] = W₀ - E[(W₀-W)⁺] = W₀ - W₀/e = W₀(1-1/e)  ❌
```

**正确**：
```
E[(W-W₀)⁺] = W₀/e  ✅
```

**原因**：混淆了 E[(W₀-W)⁺]（正数）和 E[(W-W₀)⁻]（负数）

### 2. 忽略条件

**错误**：直接写 E[x⁺] = E[x] / 2

**正确**：只有当 x 对称分布时，E[x⁺] = E[x] / 2

### 3. 符号混淆

**错误**：把 θ（theta）和 θ（theta 的某种变换）混淆

**正确**：每个符号都要追踪定义和变换过程
