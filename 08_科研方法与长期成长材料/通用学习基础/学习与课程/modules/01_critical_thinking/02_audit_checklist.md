## 什么是论文审计？

论文审计是**系统地检查一篇论文**的过程，目的是：
1. 发现论文的错误（笔误、推导错误）
2. 发现论文的 Gap（未解决的问题）
3. 评估论文的贡献（创新性、可行性）
4. 为你自己的研究找方向（从 Gap 到 Idea）

---

## 审计的六个维度

| # | 维度 | 问题 |
|---|---|---|
| 1 | **假设检验** | 假设是否合理？是否过于强？是否矛盾？ |
| 2 | **推导检验** | 数学推导是否有跳步？是否使用了未证明的结论？ |
| 3 | **符号检验** | 符号是否一致？是否有笔误？ |
| 4 | **边界检验** | 边界情况是否讨论？极端参数下结论是否成立？ |
| 5 | **Gap 识别** | 论文没有做什么？什么是未解决的问题？ |
| 6 | **对比检验** | 论文与相关工作相比，创新点是否成立？ |

## 第一维：假设检验

### 检查清单

- [ ] **假设的合理性**：每个假设在现实中成立吗？
- [ ] **假设的必要性**：如果不假设这个，模型会怎样？
- [ ] **假设的内部一致性**：假设之间是否矛盾？
- [ ] **假设的强度**：假设是否过于强，限制了结论的适用范围？

### Paper 02 的假设问题（示例）

**假设问题**：
- Paper 02 假设 F 型顾客的参考点是理性预期（R̄ = R₁₂, W̄ = W₀）
- 但论文的故事线建立在"F 型不了解信息"上

**矛盾**：
- "不了解信息" → 参考点应该是有噪声的或未知的
- "理性预期" → 要求 F 型知道所有系统参数

**结论**：假设过于强，与问题设定矛盾。

### 你可以用的问句

```
"如果放松这个假设，结论会改变吗？"
"这个假设在现实中成立吗？"
"论文声称X，但假设要求Y，这是否矛盾？"
```

## 第二维：推导检验

### 检查清单

- [ ] **公式的来源**：每个公式是否从基本原理推导？
- [ ] **推导的跳步**：是否有省略的步骤？
- [ ] **符号的一致性**：全文符号是否一致？
- [ ] **证明的完整性**：证明是否对所有情况都成立？

### 常见的推导问题

1. **跳步**：省略中间推导步骤，假设读者能补全
2. **笔误**：符号写错（如 R₂ 应为 R_L）
3. **循环论证**：用要证的结论推导出结论
4. **未验证的引理**：引用了未证明的中间结论

### Paper 02 的推导问题（示例）

**问题**：命题 4.3 的证明被省略为"类似"

**影响**：
- 对称性不完全精确（λ_E 和 λ_F 交换时，边界条件变化）
- 无法验证结论是否正确

**结论**：需要独立验证。

## 第三维：符号检验

### 检查清单

- [ ] **符号定义**：每个符号在首次出现时是否定义？
- [ ] **符号一致性**：全文是否使用相同的符号？
- [ ] **符号笔误**：是否有明显的笔误（如 R₂ 应为 R_L）？
- [ ] **符号混淆**：是否有可能混淆的符号？

### Paper 02 的符号问题（示例）

**问题**：β₁₁(α) 的定义中出现 R₂

**分析**：
- R₂ 在论文中未定义
- 根据上下文，R₂ 应该等于 R_L（低服务价值）
- 这是一个笔误

**验证方法**：检查公式中每个符号是否在 Table 1 中定义。

## 第四维：边界检验

### 检查清单

- [ ] **退化检验**：当参数取特殊值时，模型是否退化到已知情况？
- [ ] **极限检验**：当参数趋向极端值时，行为是否合理？
- [ ] **边界条件**：边界情况（如 v_E = v_F）是否讨论？
- [ ] **稳定性条件**：约束条件是否总是满足？

### 边界检验示例

**退化检验**：
- Paper 02：当 α=1 且 β=1 时，U_F = U_E
- 这是合理的，因为损失厌恶系数为 1 意味着没有损失厌恶

**极限检验**：
- Paper 02：当 β→∞ 时，U_F → -∞
- 这意味着极度损失厌恶的顾客永远不会加入
- 这符合直觉 ✓

## 第五维：Gap 识别

### 检查清单

- [ ] **假设 Gap**：放松某个假设会怎样？
- [ ] **分析 Gap**：某个边界情况是否未分析？
- [ ] **方法 Gap**：是否有更简单或更强的分析方法？
- [ ] **应用 Gap**：理论结果是否被验证？是否适用于实际问题？
- [ ] **跨领域 Gap**：这个方法能否应用到其他领域？

### 六大 Gap 类型（来自 Paper 02）

| Gap 类型 | 描述 | Paper 02 中的例子 |
|---|---|---|
| **Gap 1** | 假设过于强 | REE 假设矛盾 |
| **Gap 2** | 未分析某方面 | 无福利分析 |
| **Gap 3** | 未量化某现象 | Crowd-out 未量化 |
| **Gap 4** | 未做敏感性分析 | 参考点未做 |
| **Gap 5** | 未考虑动态 | 无学习机制 |
| **Gap 6** | 结构平行发现 | θ vs α/β |

## 第六维：对比检验

### 检查清单

- [ ] **与相关工作的对比**：论文声称的创新点是否真正创新？
- [ ] **方法对比**：新方法和已有方法哪个更好？
- [ ] **结论对比**：新结论是否与已有结论一致或扩展？
- [ ] **适用范围对比**：新方法的适用范围是否更广？

### 对比检验示例

**Paper 01 vs Paper 02**：

| 维度 | Paper 01 | Paper 02 |
|---|---|---|
| 博弈类型 | 纳什均衡 | Stackelberg + Wardrop |
| 行为"旋钮" | θ（识别精度）| α, β（损失厌恶）|
| 分析方法 | 最优反应函数 | 支付意愿 v_i |
| 共同结构 | 行为参数 → 均衡变化 | 同 |

**发现**：两篇论文有共同的结构模式——引入行为参数会打破经典单调性。

## 审计报告模板

完成审计后，填写以下报告：

```markdown
## [论文名] 审计报告

### 已确认（独立验证通过）
- [具体确认项]

### 待定（需要进一步调查）
- [具体待定项]

### 新发现的 Gap
1. **Gap 名称**：描述
   - 来源：哪个假设/未分析/未量化
   - 为什么重要：动机
   - 潜在解决思路：初步想法

### 审计结论
- 论文的可靠性：[高/中/低]
- 主要贡献：[...]
- 主要局限：[...]
```
