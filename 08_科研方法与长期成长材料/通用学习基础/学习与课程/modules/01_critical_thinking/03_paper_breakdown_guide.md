## 什么是论文拆解？

论文拆解是**系统地提取一篇论文的关键信息**的过程。

目标是：
1. 把论文的"黑箱"打开，变成可操作的知识块
2. 为后续的公式验证和审计做准备
3. 建立自己的论文理解笔记

---

## 分层阅读法详解

### 第一遍：快速定位（5 分钟）

**目标**：知道论文"是什么"

**操作**：
1. 读标题（如果英文标题，先翻译成中文）
2. 读摘要（一句话一句话读）
3. 扫一遍图表标题和图注
4. 读结论部分（通常是最后一段）

**产出**：一句话总结

**模板**：
> 本文研究 [研究对象] 在 [研究场景] 下的 [研究问题]，发现 [主要结论]。

**示例（Paper 02）**：
> 本文研究心理异质性顾客在 M/M/1 排队中的定价策略，发现损失厌恶会压低最优价格并产生分段均衡。

---

### 第二遍：结构理解（30 分钟）

**目标**：知道论文"怎么做的"

**操作**：
1. 读引言的最后两段（通常总结本文贡献）
2. 读第 1-2 节（假设和模型设定）
3. 读核心命题的陈述（不一定读证明）
4. 读数值实验/仿真部分
5. 用自己的话复述一遍

**产出**：
- 模型结构图（手画或文字描述）
- 主要结论列表

**复述模板**：
> 论文的问题是......假设是......用了......方法......得到......结论......这个结论说明......

---

### 第三遍：深度拆解（60 分钟）

**目标**：知道论文"为什么这样做"

**操作**：
1. 读每个假设——问自己"为什么假设这个"
2. 读公式推导——关键步骤记录下来
3. 读命题证明——理解逻辑链
4. 读相关工作——理解论文在领域中的位置

**产出**：
- 假设清单（带"为什么"）
- 关键公式列表
- 逻辑链图

## 关键元素提取

### 模型要素表

| 要素 | 内容 | 为什么重要 |
|---|---|---|
| **决策者** | 谁在做决策？ | 确定博弈结构 |
| **决策变量** | 决策者控制什么？ | 确定策略空间 |
| **目标函数** | 决策者最大化/最小化什么？ | 确定均衡类型 |
| **约束条件** | 决策者面临什么限制？ | 确定可行域 |
| **信息结构** | 决策者知道什么？ | 确定博弈类型 |
| **时间结构** | 决策顺序是什么？ | 确定逆向归纳 |

**Paper 02 示例**：

| 要素 | Paper 02 内容 |
|---|---|
| 决策者 | 服务商（定价者）+ 两类顾客（E型、F型） |
| 决策变量 | 服务商：价格 P；顾客：是否加入（0/1）|
| 目标函数 | 服务商：收入 Π(P) = λ(P)·P；顾客：效用 U |
| 约束条件 | 稳定性：λ < μ；价格：P > 0 |
| 信息结构 | 顾客不知道队列长度（不可观测队列）|
| 时间结构 | 服务商先定价（Stackelberg），顾客后决定（Wardrop）|

| 参数 | 符号 | 定义 | 单位/范围 | 作用 |
|---|---|---|---|---|
| 识别精度 | θ | 消费者识别高质量产品的概率 | [0, 1] | 控制信息不对称 |
| 损失厌恶-价值 | α | 价值损失厌恶系数 | ≥ 1 | 放大价值损失 |
| 损失厌恶-时间 | β | 时间损失厌恶系数 | ≥ 1 | 放大时间损失 |
| ... | | | | |

**提取技巧**：
- 找论文的 Table 1（变量定义表）
- 找首次出现的符号定义
- 检查符号是否全文一致

## 常见问题

### Q1: 论文太难了，看不懂怎么办？

**策略**：
1. 先看数值实验/仿真部分（通常更直观）
2. 找论文的"图"来理解结论
3. 先读相关工作的文献综述部分
4. 用大白话解释每个变量
5. 把论文的模型类比到你熟悉的生活场景

### Q2: 英文术语太多，记不住怎么办？

**策略**：
1. 建一个术语表，一边读一边记
2. 首次出现时翻译成中文
3. 把自己熟悉的概念对应起来
   - Nash equilibrium → 纳什均衡 → 没有人能单方面改善
   - Subgame perfect → 子博弈完美 → 每一步都是最优

### Q3: 公式太复杂，怎么处理？

**策略**：
1. 先看"形式"（是什么类型的函数）
2. 再看"参数"（每个符号是什么意思）
3. 最后看"推导"（怎么从一步到另一步）
4. 跳步是正常的，先接受，后验证
