## 概览

```
Step 1: 理解问题
    ↓
Step 2: 识别变量与参数
    ↓

    ↓
```

每一步都有具体的问题清单和产出。

## Step 1: 理解问题

### 核心问题

**"谁在做什么决策？目的是什么？约束是什么？"**

### 操作清单

- [ ] **识别决策者**：是一个人还是一个系统？（服务提供商 vs 顾客）
- [ ] **识别决策**：他们选择什么？（价格 P？加入/退出？）
- [ ] **识别目标**：他们想最大化/最小化什么？（收入？效用？）
- [ ] **识别约束**：什么是他们无法控制的？（等待时间、服务质量）
- [ ] **识别异质性**：不同决策者是否不同？（E型 vs F型）

### Paper 02 的例子

| 要素 | 论文中的对应 |
|---|---|
| 决策者 1 | 服务提供商 → 选择价格 P |
| 决策者 2 | 顾客（两类） → 选择加入/退出 |
| 目标 1 | 服务商 → 最大化收入 Π(P) = λ(P)·P |
| 目标 2 | 顾客 → 最大化期望效用 |
| 约束 1 | 顾客效用取决于等待时间 W₀ |
| 约束 2 | 系统稳定要求 λ < μ |
| 异质性 | E型（经验/理性）vs F型（新手/损失厌恶） |

### 产出

一段话描述问题：
> "一个服务提供商在 M/M/1 排队系统中设定统一价格 P。系统中有两类顾客——E 型（经验型，损失中性）和 F 型（新手型，损失厌恶）。两类顾客决定是否加入队列。服务提供商的目标是最大化收入 Π(P) = λ(P)·P，其中 λ(P) 是均衡到达率。"

## Step 2: 识别变量与参数

### 核心问题

**"模型中有哪些量？哪些是决策者控制的？哪些是给定的？"**

### 操作清单

- [ ] **决策变量**（ endogenous ）：由决策者选择
- [ ] **状态变量**：由系统状态决定（等待时间 W₀）
- [ ] **参数**（ exogenous ）：模型外部给定
- [ ] **随机变量**：服从某个分布

### Paper 02 的变量表

| 类型 | 变量 | 含义 |
|---|---|---|
| 决策变量 | P | 服务价格 |
| 状态变量 | W₀ | 期望等待时间 = 1/(μ-λ) |
| 状态变量 | λ | 有效到达率 |
| 参数 | μ | 服务率 |
| 参数 | α, β | 损失厌恶系数 |
| 参数 | θ_E, θ_F | 延迟敏感度 |
| 参数 | R_H, R_L, γ | 服务质量分布 |
| 随机变量 | R | 感知服务价值（两点分布） |
| 随机变量 | W | 实际等待时间（指数分布） |

### 产出

一张变量表（或类似 Table 1 的结构）。

## Step 3: 确定结构与关系

### 核心问题

**"变量之间的关系是什么？哪个变量决定哪个？"**

### 操作清单

- [ ] **目标函数结构**："最大化 X subject to Y"
- [ ] **因果链条**：价格 P → 到达率 λ → 等待时间 W₀ → 效用 U
- [ ] **均衡条件**：在什么条件下顾客决定加入？
- [ ] **稳定性条件**：系统能否稳定运行？

### Paper 02 的结构

```
P（价格）
    ↓
λ（到达率）← 顾客加入决策
    ↓
W₀ = 1/(μ-λ)（等待时间）
    ↓
U_E, U_F（效用）← 损失厌恶项
    ↓
加入/退出决策
    ↓
λ（回到到达率，形成循环）
```

**关键洞察**：这是一个递归结构——λ 影响 W₀，W₀ 影响效用，效用影响加入决策，加入决策决定 λ。

均衡就是解这个循环，使得"假设"和"结果"一致。

### 产出

一张因果图或流程图，标注关键依赖关系。

## Step 4: 选择数学形式

### 核心问题

**"每个关系用什么数学形式表达？"**

### 操作清单

- [ ] **分布选择**：为什么用指数分布而不是正态分布？
- [ ] **函数形式**：为什么是线性效用而不是对数效用？
- [ ] **参数范围**：参数取什么值时模型有意义？（α ≥ 1）
- [ ] **简化假设**：为了可解性放弃了什么？（统一定价）

### Paper 02 的关键选择

| 选择 | 论文的决策 | 理由 |
|---|---|---|
| 服务时间分布 | 指数 Exp(μ) | M/M/1 标准框架 |
| 等待时间分布 | 指数 Exp(μ-λ) | 继承自服务时间分布 |
| 感知服务价值 | 两点分布 | 简化但捕捉不确定性 |
| 参考点设定 | 理性预期（R̄=R₁₂, W̄=W₀） | 保证均衡存在 |
| 定价方式 | 统一定价 | 不可区分顾客类型 |

### 产出

对每个关键关系，写出数学表达式，并注释"为什么这样选"。

---

## Step 5: 验证与迭代

### 核心问题

**"模型是否正确捕捉了问题？假设是否合理？"**

### 操作清单

- [ ] **退化检验**：当参数取特殊值时，模型是否退化到已知情况？
  - 当 α=β=1 时，U_F 是否等于 U_E？
- [ ] **边界检验**：参数在极端值时，行为是否合理？
  - 当 β→∞ 时，F 型是否永远不会加入？
- [ ] **直觉检验**：结论是否符合经济学直觉？
  - 损失厌恶是否降低了效用？
- [ ] **对比检验**：与相关论文的模型是否一致？

### Paper 02 的验证

| 检验 | 设置 | 预期结果 | 论文结果 |
|---|---|---|---|
| α=β=1 退化 | 损失中性 | U_F = U_E | ✓ |
| β→∞ 极限 | 极度损失厌恶 | F 型全部 balke | ✓ |
| 损失厌恶效应 | α↑ 或 β↑ | 效用下降 | ✓ |

### 产出

一份验证清单，标注每项检验是否通过。
