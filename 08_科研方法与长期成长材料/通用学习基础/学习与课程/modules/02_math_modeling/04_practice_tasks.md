## 练习说明

本清单用于训练你的数学建模能力。每个任务都基于真实论文，要求你实际动手做，而不是"读了就算"。

**完成标准**：每个任务都要产出一个小文件（自己新建一个 `practice/` 目录），包含：
1. 你的推导过程（不是只有结论）
2. 你的困惑点和卡住的地方
3. 最终验证结果

## 练习 1：复现 Paper 02 的效用函数（初级）

**来源**：Paper 02 公式 (2)

**任务**：
1. 完整写出 E 型顾客的效用函数 U_E
2. 完整写出 F 型顾客的原始效用函数（公式前，未简化的）
3. 使用 x⁺ + x⁻ = x 恒等式，推导 F 型效用函数简化为公式 (2) 的**每一步**
4. 用 Python/SymPy 验证当 α=1, β=1 时，U_F = U_E

**产出文件**：`practice/01_utility_function_derivation.md`

## 练习 4：设计你自己的效用函数（高级）

**来源**：你自己的创意

**任务**：
假设一个多智能体系统场景：
- 多个 LLM agent 竞争有限的资源（如 API 调用配额）
- 某些 agent 有"风险厌恶"倾向（损失比收益更敏感）
- 资源价格动态变化

**你的任务**：
1. 识别决策者、决策变量、目标函数
2. 设计一个效用函数，捕捉"风险厌恶"行为
3. 写出均衡条件（纳什均衡）
4. 分析：当风险厌恶程度变化时，均衡如何改变？

**产出文件**：`practice/04_design_utility_function.md`

**难度**：这个任务没有标准答案，重点是你能自圆其说。

## 练习 6：发现 Paper 02 的建模 gap（中级）

## 练习 7：理解"行为旋钮"的概念（初级）

**来源**：Paper 01 的 θ vs Paper 02 的 α/β

**任务**：

**什么是"行为旋钮"？**

在两篇论文中，都有一个关键参数控制着"行为偏离经典理性"的程度：
- Paper 01：θ（识别精度）—— θ 越低，识别越不准确，行为越偏离理性
- Paper 02：α, β（损失厌恶）—— α, β 越大，损失厌恶越强，行为越偏离理性

**你的任务**：
1. 画出"行为旋钮"的示意图（横轴：参数值，纵轴：行为偏离程度）
2. 在两篇论文中，各举一个"行为旋钮达到极端时的极端结果"
3. 思考：在你的多智能体研究中，**什么可以是你的"行为旋钮"？**

**产出文件**：`practice/07_behavioral_dial.md`
