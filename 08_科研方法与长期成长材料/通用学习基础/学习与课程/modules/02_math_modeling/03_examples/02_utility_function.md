# Utility Function — 通用定义

## 通用定义

效用函数 `u: X → ℝ` 把决策空间 `X` 的元素映到实数，用于：
- 偏好排序
- 期望效用计算
- 风险态度建模

## 建模步骤

1. 识别决策空间 `X`
2. 识别偏好结构（公理 / 实证）
3. 选择函数族（线性 / 凹 / 凸 / 阈值）
4. 标定参数（拟合 / 行为数据 / 启发）
5. 验证单调性、连续性、单调性
