2. **ETL 脚本洗库与双时态重构**：
   - 编写迁移脚本 `migrate_companion_temporal.py`；
   - 为每条记忆注入真实物理有效期 $[valid\_from, valid\_to)$；

   - 梳理不可动摇的核心身份设定（`core_presence == "always"`）；

   - 接入本地 CPU 驱动的轻量向量模型，杜绝调用外部闭源 API 导致隐私外泄。
4. **移动端 PWA 协同联调**：
