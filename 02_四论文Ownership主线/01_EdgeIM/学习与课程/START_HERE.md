# EdgeIM Algorithm 1 学习包：从这里开始

这是一条从零基础走到能够独立解释、手算、实现并审查 EdgeIM 的训练路线。EdgeIM 是一篇面向分布式边缘环境的过程模型发现论文；本包先训练论文中的 Algorithm 1，也就是“保留能扩展全局特征集合的案例”的第一阶段算法，再逐步走到发现模型、研究裁定和实验。

**谁使用**：学习者用它找唯一顺序、提交整批答案；批改者或人工智能（AI）用它统一状态词、证据口径和反馈格式。它不替代各站题面，也不替代论文原文。

**第一次打开时按这个顺序读**：

1. 先读本页，确认路线、提交方式和密封规则。
2. 再开 [PAPER_MAP.md](./PAPER_MAP.md)，先知道整篇论文在解决什么、当前站位于哪里；不要在地图里寻找推理题答案。
3. 遇到路线冲突时读 [BRIEF.md](./BRIEF.md) 的最新 Amendment（追加修订）。当前唯一路线是 `0 -> 1 -> 5a -> 2 -> 3 -> 5 -> 6 -> 7`。
4. 只打开当前站的 `README.md`。题面明确允许之前，不打开 `_sealed/` 下的参考答案。
5. 当前站要求看研究树时，从 [KNOWLEDGE_MAP.md](./KNOWLEDGE_MAP.md) 的“小视窗”进入；不要把七张地图一次填完。

本包有三类工作。**核心题**决定 `PASS`（当前站冻结条件已经逐项验收）；`CONNECT` 是核心题完成后的跨站连接题，按约定批次集中提交，但不提高既有 PASS 门槛；`EXTEND` 是可选研究延伸，不做不影响 PASS。

## 四个状态词

状态必须用下面四个词，不再用含糊的“做过”“差不多会了”。状态不会因为时间经过或文件存在而自动升级。

| 状态 | 严格含义 | 不能据此声称什么 |
|---|---|---|
| `SEEN` | 某份材料、答案或解释出现过，学习者可能已经看见 | 不能证明能独立解释或完成 |
| `SUBMITTED` | 学习者已经交出一份可定位、可检查的答案 | 不能证明满足全部冻结条件 |
| `PASS` | 当前站冻结条件已有逐项证据，并完成验收 | 不能证明若干天后仍能独立完成 |
| `RETAINED` | 到期的冷启动复测中，学习者仍能不依赖旧答案独立完成 | 不自动外推到未测试的新任务 |

典型方向是 `SEEN -> SUBMITTED -> PASS -> RETAINED`，但它不是签到流程。例如，先看了参考答案只会增加 `SEEN`；必须另有合格的新证据，状态才可能继续变化。

## 一次交一整站，反馈一次说清

默认以“整站”为一批；若题面或双方事先约定拆批，就按约定批次。不要每写一句就请求判一次，也不要把多个站混在同一批里。

提交时使用下面这个最小格式：

```markdown
# 提交：EX-__ / 批次 __

- 本批范围：题号或 PASS 条件
- 新作答：逐题写在下方，或给出文件路径 + 标题
- 复用证据：文件路径 + 标题；没有就写“无”
- 已暴露材料：AI 提示、旧答案、运行输出、密封参考答案；没有就写“无”
- 请求：整批批改 / 只核对来源位置 / 环境帮助
```

批改者一次返回完整矩阵：

| 要求 | 学习者证据 | 判定 | 仅剩动作 |
|---|---|---|---|
| 写冻结条件中的一个可检查要求 | 路径 + 标题，或本批具体回答 | `满足` / `部分满足` / `未见证据` / `不适用` | 只写达到该要求还缺的最小动作；已满足则写“无” |

矩阵之后再给本批状态。不能只说“不错”“继续”，也不能因为一项通过就把整站标成 PASS。

## 旧证据什么时候能复用

可以引用，不必机械重抄：

- 学习者自己写过、当前仍可读取的答案，使用“文件路径 + 标题”定位；批改者必须重新核对它是否真的覆盖本次要求。
- 学习者自己保存的手算表、代码和运行记录；它们只支持各自直接展示的内容，不能自动证明更强结论。
- 已核过的论文页码可以继续充当来源指针，但来源指针本身不等于学习者已理解。

必须产生新证据，不能用旧文件代替：

- **预测**：必须在本次运行、揭晓或查看输出之前写下。
- **脱稿**：必须关掉旧答案、讲义、代码和聊天，在空白处重新完成。
- **冷启动复测**：必须到题面规定的时间，用新题或规定变体重新完成。
- 题面明确要求“自己改、自己诊断、自己比较”的动作，必须由学习者在本次任务中实际做出。

AI 的讲解、代写、补全、代码脚手架和 sealed answer 只能记为暴露条件，不能冒充学习者证据。AI 可以搭环境、解释 API（application programming interface，程序调用接口）或核对页码；独立掌握仍要求学习者能自行解释、预测、修改并诊断结果。

## 密封答案与零假设教学

“零假设”在这里指：不假设学习者已经认识一个术语，也不因为它在旧会话出现过就跳过检查。一个新概念第一次进入题目前，概念卡固定包含四步：

1. 白话定义；
2. 一个与正式练习不同的微例子；
3. 它在 EdgeIM 论文或本训练路线中的位置；
4. 一道能判对错、或能暴露证据边界的问题。

密封答案遵守以下处理：

- 题面允许之前，不读取、不搜索、不摘要 `_sealed/` 内容。
- 如果参考答案意外泄露，立即停止沿答案继续作答，提交时写明暴露了哪一部分和用了多少提示。
- 被泄露内容只能标成 `SEEN`，不能直接支撑 PASS。后续按题面改用新变体、脱稿或冷启动证据；不删除历史，也不假装没有看过。
- 地图和概念卡可以给论文位置、作者明说的结构和术语定义；需要学习者推出的关系，只能先写成问题。

最后用一个简单边界检查自己：**“我能复述”不等于“我能在没有答案时预测、修改和诊断”。** 后三者还没有新证据时，就如实停在 SEEN 或 SUBMITTED。
