### 1A. Python 最短桥：先认五个动作

Python 是这一站使用的编程语言。下面都用与 L1 不同的“图书登记”微例，只教读写任务所需的最小含义。

- **函数、参数、返回值**：函数是一段可重复调用的操作；参数是调用时交给它的输入；返回值是函数交回的输出。例：`first(["登记", "上架"])` 中列表是参数，返回值是 `"登记"`。亲手把 `first([])` 的预期写成 `UNKNOWN` 或你明确选择的合同，不要默默猜。
- **set（集合）**：只记录不同元素，不记录重复次数。例：`set(["登记", "上架", "登记"])` 表示 `{"登记", "上架"}`。亲手写加入一个新元素和重复元素后集合各怎样变。
- **tuple（元组）**：按位置装多个字段的固定记录。例：`("book7", ["登记", "上架"])` 的第 1 格是编号，第 2 格是活动列表；它不是一条 DFG 边，字段含义由输入合同决定。亲手标出两格各装什么。
- **遍历顺序**：`for item in items` 按容器给出的次序逐项处理；前一项若更新状态，后一项会读到更新后的状态。例：依次读 `[{红}, {蓝}, {红,蓝}]` 与逆序读时，圈出每一步开始前已见颜色集合。assert first(["登记", "上架"]) == "登记"` 只检查这个实例，不证明所有输入都正确。
- **assert（断言）**：把一个预期写成可执行检查；条件为真就继续，为假就报告失败。例：`

接回本站：`algo1(log)` 中 `log` 是参数，`D2, S, E, R` 是四项返回值；set 表示去重状态，tuple 表示每条输入记录，遍历顺序影响“当前已见状态”，assert 把手算结果与程序输出对拍。它们只把 EX-00 的手算动作写成代码，不改变算法保证。
