## 1. 教学：什么叫噪声，什么叫非法

日志是从系统里记下来的。记错了、系统出了岔子、人手动改了——就会出现"本来不该有的东西"。过程挖掘管这叫**噪声**。三种最常见的：

- **多了一个事件**（插入）：`A B D F` 变成 `A B X D F`
- **少了一个事件**（删除）：`A B D F` 变成 `A D F`
- **两个事件换了位**（交换）：`A B D F` 变成 `B A D F`


"这条 trace 是不是**非法**"要有个裁判：知道**真正的流程**是什么样才能判。
真实日志里没有这个裁判（这就是为什么真实日志上谈噪声都是估计）；
**合成日志**里有——你先定一个流程，按它生成 trace，再故意加噪声，于是每条 trace 你都知道它合不合法。
第 7 站就是这么做的。这一站先用手。

**你用的字母表**：只用日志里已有的活动（A–F）来插，不引入新活动 X。理由：引入新活动太容易被抓——新活动一出现 S/E/R 里一定多东西。难的是用旧活动造非法。





## 2. 教学：Algorithm 1 眼里的"新"

回想判据：一条 trace 被留，当且仅当它带来了**至少一个** S、E、R 里还没有的元素。

所以对 Algorithm 1 来说，一条 trace "有没有新东西"只取决于三件事：起点是不是新的、终点是不是新的、有没有一条相邻对是新的。**它看不见别的。** 一条 trace 是不是"非法"、是不是噪声，它不知道也不关心。

这一站要你自己发现：非法和"造出新边"这两件事，什么时候重合，什么时候不重合。

### 2A. 先拆成两个轴：合法性 x 新颖性

**合法性（legality）**问一条 trace 是否符合独立的真实流程或规则，必须由 oracle（不使用待测选择规则的外部裁判）判。
**新颖性（novelty）**问它是否给算法的当前状态带来未见特征；本站先只看“是否带来当前 `R` 中没有的边”。两个问题的裁判不同，所以不能把“新”当成“非法”的同义词。




用一个与正式题无关的门禁微例。外部规则允许 `登记 入场 出场` 和 `登记 复核 入场 出场`。当前已见边集是 `R0={登记->入场, 入场->出场, 登记->出场}`；其中 `登记->出场` 来自一条先到的错误记录，说明算法状态不等于 oracle。待分类的四条 trace 是：

```text
q1: 登记 入场 出场
q2: 登记 复核 入场 出场
q3: 登记 出场
q4: 入场 登记 出场
```

先由外部规则判合法/非法，再与 `R0` 比较有无新边，把 `q1`–`q4` 各放一次：

|  | 有新边 | 没有新边 |
|---|---|---|
| 合法 | ___q2___ | ___q1___ |
| 非法 | ___q4___ | __q3____ |

亲手产物是“每条 trace 的相邻对 + oracle 判定 + 与 `R0` 的差集 + 四格位置”。
接回 EdgeIM 时，上游 `R` 只供新颖性判断；合法性标签来自另一个上游 oracle。
四格能证明两个轴可以分开，不能预测 L1 正式题里哪条 trace 会留，也不能估计真实日志的噪声比例。
