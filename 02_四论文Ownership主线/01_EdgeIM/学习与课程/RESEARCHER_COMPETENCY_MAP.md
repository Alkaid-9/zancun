# Map 5：研究者能力证据图

- **用途**：把导师想观察的能力落到行为和产物，不给人贴性格标签，也不汇总成分数。
- **读者**：学习者用它选择下一项练习；导师或批改者用它说明“看到了什么证据、还没有看到什么”。
- **第一步**：在八站证据表找到当前站，只选一个真实产物填写“路径 + 标题”；若只有讲解、答案或文件存在，就记 `SEEN`（只表示见过材料），不要勾能力达成。
- **当前入口**：先观察问题理解和抽象能否从事件、trace（轨迹，一个案例内按时间排列的活动序列）、带权 DFG（带边频次的直接跟随图）连到当前消费者，再观察严谨性和实验能力。
- **暂时封存**：人格分、综合排名、自动 `PASS`（当前站冻结条件通过），以及路线结束后的导师模式。导师模式只是一项可选的 75 分钟练习，不改变任何站点 PASS。

路线与状态合同见 [START_HERE.md](./START_HERE.md)，概念依赖见 [KNOWLEDGE_MAP.md](./KNOWLEDGE_MAP.md)，研究方法见 [RESEARCH_MAPS.md](./RESEARCH_MAPS.md)，长期偏好与匹配见 [RESEARCH_IDENTITY_MAP.md](./RESEARCH_IDENTITY_MAP.md)，跨项目变化见 [RESEARCH_TRAJECTORY_MAP.md](./RESEARCH_TRAJECTORY_MAP.md)。

统一证据接口：[RESEARCH_NOTE_TEMPLATE.md](./RESEARCH_NOTE_TEMPLATE.md)。后续系统阅读或算法怀疑必须链接它完成适用的证据审计和研究钩子；本图只记录能力证据位置，不复制模板。

## 九个基础能力轴与三项研究工作能力

能力轴是“当前任务中可观察的行为维度”，不是人的固定属性。每一项都必须附可检查证据，并同时排除一个常见假阳性。

AI（artificial intelligence，人工智能）提供的讲解、代码和摘要只能记录为帮助条件，不能替代下表要求的本人行为。

| 能力轴 | 在这里具体指什么 | 可观察证据 | false positive（假阳性，看起来像但不能证明） |
|---|---|---|---|
| `learning speed`（学习速度） | 在得到一次明确反馈后，多久能修正同类错误，并在新变体上保持 | 两版带时间的作答、差异说明、新变体复测 | 很快看完材料；AI 很快生成答案 |
| `problem understanding`（问题理解） | 能说清对象、输入、状态、输出、目标、边界和消费者 | 自己画的对象流、五问说明、对含糊条件的澄清 | 复述题面术语；背下摘要 |
| `abstraction`（抽象） | 能把具体活动名换成变量，保留决定结果的结构 | 自己写的集合、图、接口、同构微例子 | 只把中文换成公式；套用现成模板 |
| `rigor`（严谨） | 让主张带条件、来源、反例、复跑路径和证据上限 | 带标签的 note（研究笔记）、断言、反例、原始输出引用 | 文字很正式；测试绿一次就写普遍结论 |
| `research taste`（研究判断力） | 在多个可做问题中优先选择重要、可判定、能区分解释的问题 | 排序理由、放弃项、最小区分实验 | 题目听起来新；堆很多方向但不裁剪 |
| `experimentation`（实验能力） | 先定预测、对照、变量、指标、裁定，再运行并保留原始结果 | 预注册预测、生成器、运行记录、三级裁定 | 会调用库；结果表漂亮但无运行前规则 |
| `updating`（更新能力） | 结果或反例出现后，准确改写判断而不抹掉失败 | 预测对照表、版本差异、意外清单、下一步 | 把原判断换句话继续坚持；只汇报成功项 |
| `ownership`（独立接管） | 能解释、修改、预测和诊断自己使用的表示、代码与证据链 | 裸写实现、改条件预测、故障定位、来源披露 | 文件在本人目录；AI 或他人代码能够运行 |
| `fit`（研究匹配） | 当前工作方式与课题的对象、证据标准、协作节奏是否匹配 | 对研究问题取舍、反馈响应、边界遵守和真实兴趣的具体例子 | “我很感兴趣”的自述；性格推断或单次表现 |
| `agenda setting / problem reframing`（议题设置 / 问题重构） | 能从现象中选出值得做且可判定的问题，并在对象错位时改写问题 | 候选问题排序、对象边界变化、为何放弃原问题 | 把题目说得更宏大；只换标题不改测量对象 |
| `research collaboration bandwidth`（研究协作带宽） | 能让他人在有限沟通中理解状态、边界、阻塞和可交接动作 | 下方 collaboration handoff 四字段、精确提问和对反馈的可追踪响应 | 消息很多；会用协作术语但没有可复用产物 |
| `research compression / communication`（研究压缩 / 沟通） | 能在不丢条件、负面证据、来源和责任主体的前提下压缩复杂工作 | 一页研究摘要、图表说明、口头讲解与原证据双向索引 | 文案流畅或很短，但省掉限制和失败 |

原九个基础轴保持独立，新增三项用于观察真实研究工作。每个节点只选自然相关的 2 至 4 项，不要求一题覆盖全部十二项。本表不产生总分。导师可以写“本次看见/未看见哪项行为”，不能把一次任务表现改写成固定人格判断。

`Epistemic Integrity`（认知诚信）要求所有能力证据保留 `UNKNOWN`、负面证据、贡献归属和来源链；`Research Economy`（研究经济性）要求观察这项能力是否以合理成本改变了真实决定。二者是证据门槛，不是额外人格轴。

一次面试只能看到特定题目、时间压力和提示条件下的低置信度切片，测不准长期潜力。高权重判断要来自多轮共同小项目、脚手架逐步撤除和反馈后的行为变化。

## L0-L6 能力高度与撤脚手架

L0-L6 只描述某个具体能力在某类任务上的证据高度，不替代 `SEEN / SUBMITTED / PASS / RETAINED` 四个站点状态。

| 高度 | 可检查表现 | 下一层撤掉什么脚手架 |
|---|---|---|
| L0 听过 | 能指出术语或例子来自哪里，但还未独立解释 | 不再给完整答案，只保留来源和微例子 |
| L1 解释 | 能用自己的话说明对象、作用和边界 | 撤掉现成表述，要求换例子解释 |
| L2 手算 / 使用 | 一般节点须亲手数、画、切或使用并留下原始产物；源码或系统阅读须满足下方额外门槛 | 撤掉逐步提示，保留输入和检查点 |
| L3 改条件 | 条件变化后先预测影响，再修改并验证 | 隐去应改位置，只给变化目标 |
| L4 造反例 / 验证边界 | 能主动构造最小反例，区分观察、机制和适用范围 | 撤掉反例提示，只保留主张 |
| L5 陌生迁移 | 能在陌生问题上抽出共同结构，执行验证并守住类比上限 | 撤掉候选类比，只给陌生问题 |
| L6 产生并检验新问题 | 能从观察提出可证伪新问题，攻击它并做最小区分测试 | 撤掉问题清单，由其裁定信息价值和下一步 |

升级必须引用新证据。较高层证据不能仅由“讲过”“看过答案”或 AI 生成物推定；较低层也不因时间流逝自动升级。“能教别人”可以作为跨级强证据，例如同时暴露解释、边界诊断和沟通，但不另造一个等级。

对源码或系统阅读任务，L2 的合格证据必须链接 [System reading](./RESEARCH_NOTE_TEMPLATE.md#system-reading)，同时讲清：data flow（数据流）；state before / update / after（更新前状态 / 更新动作 / 更新后状态）；algorithm step -> code anchor（算法步骤到代码位置）；observed behavior / mismatch（实际观察以及与映射不符之处）。再做一次观察核对。只成功运行一次不够；源码注释很多但无法恢复这张映射，也不够。

## 八站能力与证据映射

| 站点 | 主要目标能力 | 可检查产物 | 强证据长什么样 | 只算见过或假阳性的信号 |
|---|---|---|---|---|
| [EX-00](./EX-00/README.md) | `problem understanding` | 两种次序的手算状态表、脱稿五要素说明 | 每一步能指出读了什么、状态怎样变，并能解释次序变化 | 只背输入输出；复用已暴露答案 |
| [EX-01](./EX-01/README.md) | `abstraction` | 原日志与过滤日志的带权 DFG、带来源标签的论文 note | 能区分边是否存在与出现次数，并把判断定位到消费者和论文页码 | 图画得像但没有逐边表；标签由 AI 补齐 |
| [EX-05a](./EX-05a/README-EX05.md) | `ownership` | 纸上先手、本人实现、断言和运行输出 | 不看参考实现写出状态更新，能预测改条件后的影响 | 代码能跑但不能说明变量、判据或失败原因 |
| [EX-02](./EX-02/README-ex02.md) | `abstraction` | 手切过程树、日志投影表、`run.py`、运行前预测与比对 | 能在小图上说明分组依据，并用 trace 检查模型差异 | 只贴 PM4Py（过程挖掘 Python 工具库）输出；先看结果再补预测 |
| [EX-03](./EX-03/README-EX03.md) | `research taste` | 合法性与新颖性例子、上界推导、边权对照表 | 能区分两个判定维度，提出带失效条件的问题 | 用一个例子宣布普遍缺陷；把“新”当成“非法”同义词 |
| [EX-05](./EX-05/README-EX04.md) | `rigor` | `test_invariants.py`、预测注释、跨输入结果、`takeover.md` | 能区分定理、有限测试与实现核验，改条件后恢复工作树 | 十次测试全绿就写“任何输入都证明了”；运行他人脚本即称接管 |
| [EX-06](./EX-06/README-EX06.md) | `research taste` | T0（研究对象首次裁定）与 flag（待处置信号）、Measurement Contract（测量合同）、范围与降级线 | 每个选择指向自己的上游证据，并明确不研究什么 | 选择最宏大的题；把规划文档存在当成裁定完成 |
| [EX-07](./EX-07/README-EX07.md) | `experimentation` | 冻结预测及哈希、生成器、原始结果、带证据上限的 verdict（裁定结论） | 预测先于运行，结果可复跑，结论按反证和意外真实更新 | 只交汇总图；看完结果后改预测；把合成观察外推到全部场景 |

一站可以同时暴露多个能力，但上表只指定主要观察轴，避免一次作业被解释成全方位评价。文件存在只说明有一个候选证据位置；批改者还要打开具体产物并逐条核对。

## 单次观察记录

证据位置应指向 [统一研究笔记模板](./RESEARCH_NOTE_TEMPLATE.md) 中对应记录。

```markdown
- 日期 / 站点：________
- 观察能力轴：________
- 任务条件：给了哪些定义、提示、代码或旧证据
- 可检查产物：路径 + 标题 / 纸稿编号
- 亲手行为：解释 / 预测 / 修改 / 诊断 / 反例 / 教学中的哪一项
- 看见的强证据：________
- 排除的假阳性：________
- UNKNOWN / 负面证据：________
- credit / provenance：谁完成了什么 ________；原始位置 ________
- 信息价值 / 成本 / 决策影响：________ / ________ / ________
- 当前能力高度：L0 / L1 / L2 / L3 / L4 / L5 / L6；没有直接证据就写“未判”
- 站点状态：四状态之一；没有正式验收就不得写 PASS
- 下一次撤掉的脚手架：________
- 证据上限：________
```

## 可选的分阶段导师模式

**启用条件**：只在八站路线结束后，学习者主动选择。它不补交核心题，不改变任何站的 PASS，也不自动证明 `fit`。mentor mode（导师模式）指导师用连续追问观察研究行为，而不是给答案或做人格面试。这次练习只能形成 low-confidence snapshot（低置信度快照），不能据此判断长期潜力。

| 阶段 | 导师给什么 | 学习者当场产出 | 主要观察轴 |
|---|---|---|---|
| 1. problem（问题） | 一个陌生研究现象 | 用一句话界定对象、输入、输出和可判问题 | 问题理解 |
| 2. assumption（假设前提） | 追问“你依赖了什么条件” | 前提清单和最危险的一条 | 严谨 |
| 3. 陌生小题 | 2 至 4 个对象的小例子 | 亲手数、画或推一次 | 抽象、学习速度 |
| 4. 改条件 | 只改变一个输入条件 | 先预测，再说明哪些步骤必须改 | ownership、更新 |
| 5. 排研究问题 | 三个都能做但价值不同的问题 | 排序、放弃理由、证据缺口 | research taste |
| 6. 最小实验 | 两个竞争解释 | 对照、变量、指标、证伪条件、证据上限 | 实验能力 |
| 7. fit | 询问愿意长期接管哪类困难 | 用具体经历说明匹配和不匹配，允许回答“不确定” | fit |

### 75 分钟导师模式模拟

| 分钟 | 环节 | 留下的材料 |
|---|---|---|
| 0-8 | `problem` | 一句话问题、对象边界 |
| 8-15 | `assumption` | 三条前提、最危险前提 |
| 15-27 | 陌生小题 | 原始手算或图，不擦掉错误 |
| 27-39 | 改条件 | 运行前预测、修改点、更新说明 |
| 39-50 | 排研究问题 | 排名、放弃项、理由 |
| 50-68 | 最小实验 | 对照、变量、指标、证伪条件、预期证据上限 |
| 68-75 | `fit` 与回看 | 一项匹配、一项不匹配、一项仍未知；下一步练习 |

模拟结束只填“观察到了什么、缺什么证据、下一次撤什么脚手架”。不打人格分，不汇总自动判定，不把导师印象写成 `PASS`，也不把 AI 在模拟中提供的答案计为学习者能力。

### 证据权重边界

| 证据 | 合理用途 | 不能据此声称 |
|---|---|---|
| 75 分钟导师模式 | 发现下一道练习、暴露当场推理或沟通缺口 | 长期潜力、稳定研究身份、最终 fit |
| 一次站点产物 | 检查一个明确技能在已知条件下的表现 | 能迁移到陌生问题或长期保持 |
| 多轮共同 mini-project（小项目） | 高权重观察反馈吸收、同类迁移、协作、更新和脚手架撤除 | 没有来源链时仍不能归因；一个项目也不能覆盖所有场景 |
