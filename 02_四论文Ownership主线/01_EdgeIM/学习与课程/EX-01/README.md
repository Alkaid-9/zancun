## 1. 教学：DFG 是什么

### 1.1 从 R 到 DFG

EX-00 里你已经会算 R 了：一条 trace 里所有"相邻的一对活动"，写成 `a→b`，收进一个**集合**。集合只记"有没有"，不记"几次"。

**DFG（Directly-Follows Graph，直接跟随图）** 就是把 R 画成图，再给每条边配一个数字：

- **节点** = 活动（A、B、C……）
- **边** = R 里的每个 `a→b`
- **边上的数字** = 这一对相邻在**整个日志**里一共出现了几次。记作 `w(a→b)`

所以：**DFG = R 的边集 + 每条边的次数**。R 是 DFG 去掉数字之后剩下的骨架。EdgeIM 论文里管这个数字叫 weight（权重），Definition 3。

### 1.2 微例子（跟练习不同）

日志有三条 trace：

```
t1: X Y Z
t2: X Y Z
t3: X Z
```

先按 EX-00 的办法算 R：t1 给 `X→Y, Y→Z`；t2 一样，集合不变；t3 给 `X→Z`。R = {X→Y, Y→Z, X→Z}，3 条边。

再数次数：`X→Y` 在 t1、t2 各出现一次，共 **2**；`Y→Z` 同样 **2**；`X→Z` 只在 t3，**1**。

画出来：

```
      2         2
  X ─────▶ Y ─────▶ Z
  │                 ▲
  └────────1────────┘
```

S = {X}（起点），E = {Z}（终点）。

### 1.3 一条 trace 里同一对出现两次

`A B A B D`：`A→B` 在这条里出现两次。算 R 的时候你已经知道只记一次（集合）。**算 DFG 次数的时候记两次**——DFG 数的是"出现几次"，不是"有没有"。这是 R 和 DFG 第一处分岔，后面读原文时会用到。

### 1.4 一个自检办法

一条有 n 个事件的 trace 恰好有 n−1 个相邻对。所以**整张 DFG 所有边的次数加起来 = 日志总事件数 − trace 条数**。数完先算这个，对不上就是漏了或多数了。

### 1.5 三层计数桥：事件位置、相邻对位置、不同边类型

**1. 问题。** 一张日志可以同时有三种数；如果把它们都叫“边数”，就无法核对 DFG。event position（事件位置）指 trace 中一个活动占据的一格；adjacency occurrence（相邻对出现次数）指相邻两个位置形成一次有序对，重复也照数；distinct edge type（不同边类型）指把这些有序对去重后，集合里还剩几种。

**2. 与 L1 不同的微例。** 只看两条快递 trace：`u: 取件 扫码 取件`，`v: 取件 扫码`。请先把每个活动位置编号，再把每两个相邻位置用括号圈起来。

**3. 正式计数。** 本站每条 trace 都非空。设日志为 `L`，`|σ|` 表示 trace `σ` 中的事件位置数，`|L|` 表示 trace 条数：

```text
总事件数             = Σ σ ∈ L |σ|
相邻对出现次数总和    = Σ σ ∈ L (|σ| - 1)
                    = 总事件数 - trace 条数
不同边类型数         = |{所有相邻位置产生的有序对}|
```

这里的“事件数”在**每条 trace 的活动位置**上数；若回到原始事件表，就是数 event 行。不要在 DFG 节点、边类型或 case_id 上数事件。等式成立是因为每条非空 trace 有 `|σ|` 个位置，却只有相邻位置之间的 `|σ|-1` 个缝；对所有 trace 求和，就总共减去一个 `|L|`。

**4. 亲手填一行。** 不要把数字写进本题面；在作答文件填：

| 微日志 | 事件位置数 | 相邻对出现次数 | 不同边类型数 | 用公式自检 |
|---|---:|---:|---:|---|
| `u + v` | ______ | ______ | ______ | `______ - ______ = ______` |

正式任务的表头应写 `边 | 次数`；每行对象是一种边，不是一条 trace。

**5. 接回 EdgeIM。** 原始 event log（事件日志）提供事件位置；逐条 trace 提供相邻对出现次数；去重后的 `R` 提供边类型；带权 DFG 再给每种边记录出现次数。上游对象相同，不表示下游读取的是同一种数。

**6. 研究追问。** 两份日志若不同边类型数相同，事件数和权重分布是否也必须相同？先写一个候选反例和结论上限，不要借这个微例填 L1 的任务 1–4。
