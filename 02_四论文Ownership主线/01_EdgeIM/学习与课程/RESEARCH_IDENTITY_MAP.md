# Map 6：Research Identity & Fit（研究身份与匹配图）

- **用途**：用长期行为证据记录“我愿意反复做哪类认知活动、能承受哪类困难、与什么问题和合作方式匹配”，而不是给自己贴人格标签。
- **读者**：完成若干真实任务后回看的学习者，以及与学习者共同做项目的导师。
- **第一步**：只选最近一个持续至少两次工作回合的实例，填写“行为证据单”；没有长期证据就写 `UNKNOWN`（当前证据不足，暂不裁定）。
- **当前入口**：八站路线只提供候选观察场景，不自动生成研究身份。
- **暂时封存**：人格类型、天赋判断、一次面试得出的潜力结论，以及脱离具体课题的永久 fit。

其他地图：[知识依赖](./KNOWLEDGE_MAP.md)、[方法/谱系/迁移](./RESEARCH_MAPS.md)、[能力证据](./RESEARCHER_COMPETENCY_MAP.md)、[时间轨迹](./RESEARCH_TRAJECTORY_MAP.md)。

统一记录接口：[RESEARCH_NOTE_TEMPLATE.md](./RESEARCH_NOTE_TEMPLATE.md)。涉及系统阅读或研究怀疑的身份证据必须回指其中的证据审计和研究钩子；本图不复制模板。

## 两条记录门槛

- `Epistemic Integrity`（认知诚信）：`UNKNOWN` 表示证据不足；negative evidence（负面证据）和不喜欢、没坚持、做不动的实例也要保留；credit（贡献归属）与 provenance（来源链）要区分本人、导师、AI（artificial intelligence，人工智能）和既有材料各自完成了什么。
- `Research Economy`（研究经济性）：记录 value of information（信息价值）、cost（成本）和 decision impact（决策影响）。一项活动即使喜欢，如果长期成本过高且不改变研究决定，也不能只因投入多就写成匹配。

## 认知活动偏好

偏好指在可选择时反复回到某类活动，并愿意承担它的真实成本。它不是“我擅长什么”的同义词。

| 候选活动 | 要观察的长期行为 | 支持证据 | 反向或负面证据 | 当前裁定 |
|---|---|---|---|---|
| 从原文追来源与边界 | 是否多次主动回到原句、页码和归属，而非只读摘要 | ________ | ________ | 支持 / 不支持 / `UNKNOWN` |
| 把对象形式化 | 是否愿意反复定义输入、状态、输出、符号和不变量 | ________ | ________ | 支持 / 不支持 / `UNKNOWN` |
| 找反例与诊断失败 | 失败后是否追机制、保留错误并设计下一检查 | ________ | ________ | 支持 / 不支持 / `UNKNOWN` |
| 设计和运行实验 | 是否愿意先冻结预测，再做数据、对照和复跑 | ________ | ________ | 支持 / 不支持 / `UNKNOWN` |
| 压缩并教给别人 | 是否能多次把复杂链条讲短，同时保留条件和来源 | ________ | ________ | 支持 / 不支持 / `UNKNOWN` |

## 可长期承受的困难

“能承受”要求在多轮中仍能稳定工作、恢复和更新，不等于忍耐一次加班。

| 困难类型 | 观察窗口 | 可接受证据 | 不能当证据 | 当前记录 |
|---|---|---|---|---|
| 反复核对与复现 | 至少两个任务回合 | 发现差异后继续定位、修正、复跑 | 一次通宵或口头说“能吃苦” | ________ |
| 长时间 `UNKNOWN` | 一个问题经历多次查询或实验 | 不编答案，能维护待查项并选择下一动作 | 把未知快速改写成猜测 | ________ |
| 负面结果 | 至少一次预测被推翻 | 保留失败，缩小主张，提出更便宜的区分动作 | 只汇报成功结果 | ________ |
| 模糊反馈或多方协作 | 至少两轮交接 | 主动澄清接口、责任和完成条件 | 消息数量多或一味服从 | ________ |
| 枯燥维护与写作 | 一个 mini-project（小项目）的收尾期 | 补来源、命名、复跑和交接，不只做新功能 | 文件多或篇幅长 | ________ |

## 三类 fit

fit 指一段时间内的相互匹配，不是人的固定属性。问题、导师或工作方式变化后，应重新观察。

| fit 类型 | 要比较什么 | 长期行为证据 | 不匹配证据也要记录 | 下一次最小共事检验 |
|---|---|---|---|---|
| problem fit（问题匹配） | 问题对象、抽象层、证据类型与愿意长期投入的活动 | 在类似困难上多次主动深入，能说明为何值得做 | 持续回避核心对象，只喜欢外围包装 | ________ |
| mentor fit（导师匹配） | 反馈频率、自由度、质量标准、冲突处理 | 多轮反馈后能澄清、更新并保留自己的判断 | 只能在全程指令下推进，或长期无法对齐证据标准 | ________ |
| work-style fit（工作方式匹配） | 独立与协作比例、节奏、文档、实验和沟通方式 | 在真实节奏中稳定交付可接管产物 | 依赖临时冲刺，交接后他人无法继续 | ________ |

## 行为证据单

```markdown
### 身份观察：________

- 时间范围：从 ________ 到 ________；工作回合数：________
- 具体问题 / 团队 / 工作方式：________
- 我反复选择的认知活动：________
- 我持续承受的困难：________
- 我回避或消耗过高的部分：________
- 支持证据：路径 + 标题 / 原始输出 ________
- 负面证据：________
- credit：本人 ________；导师 ________；AI ________；既有材料 ________
- provenance：________
- value of information：这些记录可能改变 ________ 决定
- cost：时间 ________；情绪 / 协作 / 计算等可观察成本 ________
- decision impact：继续 ________ / 调整 ________ / 暂不判断 ________
- 当前裁定：支持 / 不支持 / UNKNOWN
- 证据上限：不能据此判断人格、天赋或长期潜力
```

只有一次面试、一次作业或一次顺利表现时，保持 `UNKNOWN`。更可靠的 identity 与 fit 证据来自多轮共同小项目：真实反馈出现后仍愿意更新、承担收尾，并在脚手架减少时保持可检查产出。
