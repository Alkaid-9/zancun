## 式 0(预备):轨迹、CTL 语法糖、P[ψ|s] 的语义

**轨迹**(§2.1):τ = ⟨v0 →a1 v1 →a2 ...⟩,动作由"条件于交互历史的隐式随机策略"选出。注意:真实系统是历史依赖的,后文 DTMC 把它压成"只看当前抽象状态"——Markov 假设从这里埋下。

**CTL 语法糖对偶性验证**(Def 3.1 给的糖,手动核对两条):
- AG φ ≜ ¬EF¬φ,而 EF φ ≜ E(⊤ U φ)。展开:AG φ = ¬E(⊤ U ¬φ) = "不存在一条路径最终到达 ¬φ" = "所有路径上永远 φ" ✓
- AF φ ≜ ¬EG¬φ = "不存在一条路径上永远 ¬φ" = "所有路径最终 φ" ✓

**P[ψ|s] 的定义**(§3.1):

$$P[\psi \mid s] \triangleq \Pr^s_M\{\rho \in \mathit{Paths}(s) \mid \rho \models \psi^\pi\}$$

- 论文明确处理的细节:CTL 公式是**状态公式**,(M,s)⊨ψ 是布尔值,直接写 P[ψ] 不良定;概率必须附着在**路径公式** ψ^π 上(ψ = A ψ^π,ψ^π = G ¬unsafe)。
- 测度论脚注:Paths(s) 上的概率测度由柱集(有限前缀)生成的 σ-代数与转移概率唯一确定(Ionescu-Tulcea);G ¬unsafe 的路径集 = ∩_k {前 k 步不进 unsafe} 是可数交,可测 ✓。
- 这就是 PCTL 查询 P=?[G ¬unsafe] 在 s 处的值,PRISM 直接支持。

## 式 1:valid-transition-aware Laplace 平滑(Eq 1)

$$\hat{P}^{\alpha}_{\Pi}(s_j \mid s_i) = \begin{cases} \dfrac{n^{\Pi}_{ij} + \alpha}{n^{\Pi}_i + k_i \cdot \alpha}, & \text{if } \mathsf{valid\_tran}(s_i, s_j) \\ 0, & \text{otherwise} \end{cases} \qquad (\alpha = 1)$$

其中 n_ij = Π 中 si→sj 转移计数,n_i = Σ_j n_ij(si 访问计数),k_i = si 的合法出边数。

### 归一化证明(行随机性)

$$\sum_{j:\,\mathsf{valid}} \hat{P}(s_j|s_i) = \frac{\sum_{j:\,\mathsf{valid}} n_{ij} + k_i\alpha}{n_i + k_i\alpha}$$

**当且仅当** Σ_{j:valid} n_ij = n_i(即观测数据不含非法转移)时,分子 = n_i + k_i·α,和恰为 1 ✓。

> **发现 #3(欠归一陷阱)**:若观测 trace 中出现 valid_tran 判为非法的转移(即域断言与现实冲突,例如 valid_tran 漏写了一条物理可能的转移),则 Σ_{j:valid} n_ij < n_i,分布欠归一(总和 < 1),DTMC 不再是合法概率模型,PRISM 求解结果无定义。**实现上 PACBoundSatisfied 之前必须先断言"零非法观测",违背即报错修 valid_tran,而不能静默丢弃**。这是复现与 T5 域适配时的第一个单元测试。

### 手推验证(数值)

设 k_i = 3(三条合法出边 a/b/c),n_i = 10,计数 (7, 3, 0),α=1:

P̂ = (7+1)/(10+3) , (3+1)/13 , (0+1)/13 = **(8/13, 4/13, 1/13)**;和 = 13/13 = 1 ✓

未观测的合法转移 c 拿到 1/13 ≈ 7.7% 而非 0——"没见过不等于不可能"。

### 边界检验

| 极限 | 行为 | 判定 |
|---|---|---|
| n_i = 0(未访问状态) | P̂ = α/(k_i·α) = 1/k_i,合法出边均匀先验 | ✓ 合理默认 |
| α → 0 | P̂ → n_ij/n_i,退化为频率估计 | ✓(§7 AV 域实际这么干) |
| α → ∞ | P̂ → 1/k_i,数据被冲掉 | ✓ 平滑-数据权衡显式 |
| 与标准 Laplace 差异 | 标准分母 n_i + \|S\|·α(全状态平滑);这里只平滑 k_i 条合法边 | 不给语义不可能转移任何质量;k_i < \|S\| 时平滑更轻 |
| 正下界 | 对合法转移 P̂ ≥ α/(n_i + k_i·α) > 0 | **式 4 Step 2 的前提**:链无零合法边 → B(P̂) 有限可算 |

## 式 2:PAC 正确性定义(Def 3.3 / Eq 2)

$$\Pr\left(\left|\mathbb{P}_{\hat{M}}(\psi^\pi) - \mathbb{P}_M(\psi^\pi)\right| \leq \varepsilon\right) \geq 1 - \delta$$

**两层概率的区分(初读最易错)**:
- 内层 P_M(ψ^π):固定链 M,其路径测度下"永远安全"的概率——对象级,是被估计的量。
- 外层 Pr(·):对**采样学习过程**(Algorithm 1 的随机 trace 序列)的概率——元级,是估计器的可靠度。

类比:掷硬币 n 次估 p。PAC 说的是"重复整个实验,95% 的实验里 |p̂−p|≤0.1",**不是**"这枚硬币 95% 概率正面"。所以 (ε,δ)-PAC 承诺的是"学习程序可靠",单次学出的 M̂ 没有个体证书——写 T5 的保证措辞时必须保持这个精度。

## 式 3:逐状态样本界(Bazille Thm 6,经 ProbGuard 转述)

$$n^{\Pi}_i \geq \left(\tfrac{11}{10} B(\hat{P}_\Pi)\right)^2 \cdot \frac{2}{\varepsilon^2}\log\frac{2}{\delta'} \cdot \left[\tfrac14 - \left(\max_j\left|\tfrac12 - \tfrac{n^{\Pi}_{ij}}{n^{\Pi}_i}\right| - \tfrac{2\varepsilon}{3}\right)^2\right], \qquad \delta' = \frac{\delta}{|S_{\hat M}|}$$

### 逐因子拆解

1. **(11/10·B)²**:B(P̂_Π) 是条件数——"局部转移概率误差 → 全局可达/满足概率误差"的放大系数(精确定义在 Bazille 原文,ProbGuard 未展开;本轮未读原文,S05 补)。11/10 是 slack:B 在学到的链(而非真链)上求值,留 10% 裕量。**B 以平方进入,是样本复杂度的主宰项**。
2. **(2/ε²)·log(2/δ')**:标准 Chernoff–Hoeffding 形态;δ' = δ/|S| 来自 union bound(式 4 Step 1)。
3. **方差修正因子** f(x) = 1/4 − (x − 2ε/3)²,x = max_j|1/2 − p̂_ij| ∈ [0, 1/2]:
   - f 单峰,峰在 x = 2ε/3 处,f_max = 1/4(经验频率 ≈ 1/2 ± 2ε/3,即"最像公平硬币"时样本需求最大);
   - x = 1/2(强确定转移,p̂→0 或 1):f ≈ 2ε/3 − 4ε²/9 ≈ 2ε/3,很小——确定性强省样本。ε=0.1 时 f(1/2)=0.0622,比 f_max 省 4 倍;
   - 直觉来源:伯努利方差 p(1−p) 在 p=1/2 最大,这是 Massart 式经验修正。

> **发现 #4(主文与 App A 的 max 位置不一致)**:App A 定义逐状态阈值 H*(n_s,ε',δ') = **max_t** H(n_s, n_st, ε', δ')——先对每条转移算界 H,再取最大(最保守)。主文公式却是把 **max_j|1/2−p̂_ij|** 塞进 f(·) 内——由于 f 单峰递减(当 x ≥ 2ε/3),f(max_j x_j) 恰好给出**所有转移中最松的界**。两者在常见情形(所有 x_j ≥ 2ε/3)方向相反。保守实现应按 App A:对每条转移分别检查、取最大样本需求。主文公式疑为记号压缩时的笔误;裁决需读 Bazille 原文 Thm 6(S05 任务)。下方数值手推一律用最坏因子 1/4,规避此歧义。
> 另一处待核:方差因子中 2ε/3 的 ε 是全局 ε 还是 App A 的局部 ε' = ε/B,主文与附录记号有张力,同样以 Bazille 原文为准。

### 数值手推 1(具身域量级,B=1)

取 ε=0.1,δ=0.05,|S|=8:
- δ' = 0.05/8 = 6.25×10⁻³;log(2/δ') = ln(320) ≈ 5.768
- 2/ε² = 200;(11/10·1)² = 1.21
- 最坏因子 1/4:n_i ≥ 1.21 × 200 × 5.768 × 0.25 ≈ **349 次访问/状态**
- 强确定因子 f(1/2)=0.0622:n_i ≥ **87 次访问/状态**

若每条 trace 平均访问每状态 ~2 次,需 **~50–175 条 trace**(全状态均匀访问的理想情形);冷门状态访问率低一个数量级 → 数百至数千条。与论文 Table 3 具身域下端 530 条同数量级 ✓(论文上端 10⁵ 对应 B≈481:B² 放大 2.3×10⁵ 倍,但实际需求还取决于每状态访问频率与经验频率分布,精确复算需要实测 DTMC——S05 复现时核对)。

## 式 4:Theorem 3.4 证明复推(App A 三步)

**命题**:对 Bazille 框架覆盖的可达/不变式路径性质 ψ^π,Algorithm 1 输出的 M̂ 是 (ε,δ)-PAC-correct。

设 δ' = δ/|S|,ε' = ε/B(P̂^α_Π)。

**Step 1(逐状态集中 + union bound)**:停机时每状态满足 n_s ≥ (11/10·B)²·H*(n_s,ε',δ')。由 Bazille Thm 6:对固定 s,以概率 ≥ 1−δ',max_t|P(s,t) − P̂(s,t)| ≤ ε'。
Union bound 手推:Pr(∃s 坏) ≤ Σ_s Pr(s 坏) ≤ |S|·δ' = |S|·(δ/|S|) = δ。故以概率 ≥ 1−δ,**所有**转移误差 ≤ ε' ✓(Eq 4)。

**Step 2(局部误差 → 全局满足概率,Bazille Thm 5 敏感度)**:

$$\left|\mathbb{P}_M(\psi^\pi) - \mathbb{P}_{\hat M}(\psi^\pi)\right| \leq B(\hat{P}^{\alpha}_\Pi) \cdot \max_{s,t}\left|P(s,t) - \hat{P}^{\alpha}_\Pi(s,t)\right| \leq B \cdot \varepsilon' = B \cdot \frac{\varepsilon}{B} = \varepsilon$$

**关键咬合点**:B 在**学到的链**上求值(真链未知)。合法性来自式 1 的正下界——Laplace 平滑使所有合法转移 ≥ α/(n_i+k_i·α) > 0,链无零合法边,B 有限且可从算法已维护的数据算出 → **停机条件可运行时检查**。11/10 slack 吸收"B(M̂) ≠ B(M)"的偏差(处理细节在 Bazille,转述)。若换成纯频率估计,未观测转移概率为 0,B 可能无界,均匀界失效——**这是"为什么必须 Laplace"的理论原因,也是"AV 域 Laplace 反而撑爆 B"的讽刺来源**(平滑给 >99.9% 自环域的稀有转移强塞质量,条件数被顶到 10⁷⁻⁸;两头不讨好时只能降档 Thm 3)。

**Step 3(合成)**:Step 1 的好事件(概率 ≥1−δ)蕴含 Step 2 的误差 ≤ε,即 Def 3.3 ∎

**一个技术性观察**(不算发现,记录):停机条件的右端 H* 依赖当前计数 n_st 与 B(P̂_Π)——阈值随学习过程漂移(自适应停机)。经验 Bernstein 式框架允许这种"数据依赖停机",但其正当性证明属于 Bazille 原文范围,ProbGuard 直接调用。

## 式 5:P_safe 的计算与阈值判定(Alg 2)

P_safe = P[ψ|s] = Pr^s(G ¬unsafe)。补全论文未写的求解数学:令 x_s = Pr^s(G ¬unsafe),则

$$x_s = 0 \ (s \models \textit{unsafe}); \qquad x_s = \sum_t \hat P(t|s)\, x_t \ (\text{否则})$$

等价地 x_s = 1 − Pr^s(F unsafe),后者取**最小非负不动点**(PRISM 实解可达概率的线性方程组)。

### 手推例 1:无安全吸收结构 → P_safe ≡ 0

S = {s0, s1, u},u = unsafe 吸收;P(s0→s0)=0.8,P(s0→s1)=0.2;P(s1→s0)=0.5,P(s1→u)=0.5。

x_u = 0;x0 = 0.8·x0 + 0.2·x1 ⟹ x0 = x1;x1 = 0.5·x0 + 0.5·0 ⟹ x0 = 0.5·x0 ⟹ **x0 = x1 = 0**。

交叉验证(可达概率):y_s = Pr^s(F u):y1 = 0.5·y0 + 0.5,y0 = 0.8y0+0.2y1 ⟹ y0 = y1 = 1 ⟹ x = 1−y = 0 ✓

> **发现 #1(安全 BSCC 条件)**:此链唯一的底部强连通分量(BSCC)是 {u},所有概率质量最终流入 unsafe,故 P(G ¬unsafe) 处处为 0。**一般结论:P_safe 非平凡 ⟺ DTMC 存在不含 unsafe 的 BSCC(安全吸收结构,如 task_done / reached_destination)**。若域建模漏掉安全终态(或任务是无限持续型、每状态都有微小泄漏到 unsafe),监控器对任意 θ>0 恒报警,FP → 100%。这为 AV 域 θ=0.7 时 FP=100% 提供了一个结构性候选解释(慢泄漏链的 P_safe 天然偏低),也是 **T5 选有界式 P=?[F≤k unsafe] 的硬理由**——有界可达对 BSCC 结构不敏感,长期陪伴对话恰恰是"无终态的持续过程"。

### 手推例 2:完整阈值判定演示(4 状态)

S = {s0, s1, done, u};P(s0→done)=0.5,P(s0→s1)=0.5;P(s1→done)=0.4,P(s1→u)=0.6;done/u 吸收。

x_done = 1,x_u = 0;x1 = 0.4·1 + 0.6·0 = **0.4**;x0 = 0.5·1 + 0.5·0.4 = **0.7**。

| θ | 在 s0(P_safe=0.7) | 在 s1(P_safe=0.4) | 效果 |
|---|---|---|---|
| 0.3 | 放行 | 放行 | 零提前量,违规发生才知道(逼近反应式) |
| 0.5 | 放行 | **报警** | 提前 1 步;仅在真的走向 u 的轨迹上报(此例无 FP) |
| 0.9 | **报警** | — | 提前 2 步;但走 s0→done 的轨迹(概率 0.5)也被报 → FP |

**这个 4 状态例完整重现了 Table 1/2 的机制**:θ↑ ⟹ 报警时刻单调提前(AWT↑)且误报单调增(FP↑);P_safe 沿轨迹向危险方向单调恶化是"提前量"存在的前提——若 P_safe 阶跃坠落(场景 1/2/7),θ 取哪里都在同一步触发,AWT 对 θ 平坦。

## 式 6:K 步有界响应监控自动机(Def 5.2)与同步积

$$\delta(q,\ell) = \begin{cases} \mathsf{wait}(K), & q=\mathsf{idle},\ \ell \models \varphi_s \land \ell \not\models \varphi_t \\ \mathsf{idle}, & q=\mathsf{wait}(i),\ \ell \models \varphi_t \\ \mathsf{wait}(i-1), & q=\mathsf{wait}(i),\ i>0,\ \ell \not\models \varphi_t \\ \mathsf{viol}, & q=\mathsf{wait}(0),\ \ell \not\models \varphi_t \\ q, & \text{otherwise} \end{cases}$$

Q = {idle} ∪ {wait(i)}_{i=0..K} ∪ {viol},|Q| = K+3;viol 吸收;G(φs ⇒ F[0,K] φt) 归约为积模型上的 AG ¬viol。

### 手推运行(K=2)

| 步 | 标签 | 序列 A(及时响应) | 序列 B(违规) |
|---|---|---|---|
| t | {φs, ¬φt} | idle → wait(2) | idle → wait(2) |
| t+1 | A:{¬φt} / B:{¬φt} | wait(2) → wait(1) | wait(2) → wait(1) |
| t+2 | A:{φt} / B:{¬φt} | wait(1) → **idle** ✓ | wait(1) → wait(0) |
| t+3 | B:{¬φt} | — | wait(0) → **viol** ✗ |

细节核对:idle 读到 φs∧φt(触发即满足)→ 无匹配前四行 → otherwise → 保持 idle ✓(义务即时解除,合理)。

> **发现 #2(端点 off-by-one)**:逐字执行上表,触发在 t,viol 在 t+K+1 宣告;且若 t+K+1 时刻 φt 为真,δ(wait(0), φt) = idle——**t+K+1 的响应仍解除义务**。故构造的实际响应窗口是 [t, t+K+1],比 F[0,K] 语义的 [t, t+K] 多一个时刻。工程影响:K=100(10s)时偏差 = 1 个控制周期(100ms),可忽略;但形式化陈述"归约正确"严格说差一步。相邻问题:§5.1 的同步演化式 q_{i+1} = δ(q_i, L(s_{i+1})) 从 q0=idle 起步,s0 的标签从未进 δ(初态标签未消费)。两处都是端点约定级瑕疵,**复现以代码为准,T5 写自己的自动机构造时把窗口端点写成显式引理避开同类坑**。

### 手推证明:单义务跟踪为何充分(论文未给,补全)

疑问:自动机同时只跟踪一个倒计时,而 G(φs⇒F[0,K]φt) 语义下每个触发时刻都产生独立义务,重叠触发会不会漏?

**论证**:设 wait 期间发生第二次触发 t₂ > t₁(自动机仍在倒 t₁ 的计时)。
- 若 t₁ 的义务被满足:∃u ≤ t₁+K,φt 在 u 为真,自动机回 idle。t₂ 义务的窗口 [t₂, t₂+K] ⊇ [t₂, t₁+K] ∋ u(因 t₂ ≤ u 时);若 t₂ ≤ u,则 u 同时解除 t₂ 的义务 ✓;若 t₂ > u(第二次触发发生在响应之后),自动机已回 idle,读到 t₂ 触发会重新开一个完整 K 窗口,单独跟踪 ✓。
- 若 t₁ 的义务违规:t₁+K 内无 φt,自动机进 viol(吸收),全局性质已假,后续义务无需跟踪 ✓。
- 关键单调性:最早未解除义务的 deadline 最早;它被解除的时刻也解除一切在它之前触发、窗口重叠的义务(它们的 deadline 更晚)。∎

结论:确定性单计时器对该 STL 片段是**精确**监控器(在发现 #2 的端点约定下),非近似。这一小证明 T5 写"滑动窗累积"自动机时需要重做——累积语义下单计时器**不**充分(窗口内多事件计数需要 O(K) 位记忆或滑窗计数器),这是 T5 形式化贡献的技术核心差异。

### 同步积是 DTMC(验证)

积状态 (s,q):s 分量按 P̂ 概率转移,q 分量按 δ 确定性更新(q'=δ(q,L(s')))。

$$P'((s',q')\mid(s,q)) = \hat P(s'|s)\cdot \mathbf 1[q'=\delta(q, L(s'))]$$

行和:Σ_{s'} P̂(s'|s)·Σ_{q'} 1[q'=δ(q,L(s'))] = Σ_{s'} P̂(s'|s)·1 = 1 ✓ 仍是 DTMC。状态数 |S|×(K+3):K=200(Law53)、|S|=34 时 ≈ 6.9×10³——PRISM 毫秒级可解,但**缓存表也要按积状态建**,解释了 §5.2 "同步积后开销略增"。

## 式 7:提前预警时间(Eq 3)

$$\text{AWT} = t_{\text{fail}} - t_{\text{pred}}, \qquad t_{\text{pred}} = \inf\{t : P_{\text{safe}}(s_t) < \theta\}$$

- **定义域检验**:AWT 只在实际发生违规的 run 上有定义(t_fail 存在);安全 run 上的报警是 FP,无 AWT。**故 AWT 必须与 FP 率成对报告**(论文照做:6 安全场景标定)——单独引用 38.66s 而不带"θ=0.7 时 FP=100%"是对本文最常见的误读。
- **单调性**:θ₁ < θ₂ ⟹ {t: P_safe < θ₁} ⊆ {t: P_safe < θ₂} ⟹ t_pred(θ₂) ≤ t_pred(θ₁) ⟹ AWT(θ₂) ≥ AWT(θ₁)。AWT 对 θ 单调不减 ✓ 与 Table 1 一致(场景 3/6 严格增,1/2/7 平坦=P_safe 阶跃)。
- T5 迁移:t 以对话轮计,AWT → 提前轮数;FP 标定集 = 正常陪伴对话。
