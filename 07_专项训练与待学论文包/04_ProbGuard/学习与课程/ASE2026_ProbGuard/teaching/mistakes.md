## 使用方法

每个错误必须完成四步闭环:

1. **原错误句**:逐字记录,不替学员润色。
2. **证据定位**:拆解文档/复现文档的具体文件+节。
3. **正确句**:可独立引用,消除歧义。
4. **迁移规则**:以后遇到同类问题时怎样检查。

红线错误修正后,还需闭卷重答原题;只阅读正确答案不算闭环。

## 预置高风险误区(从拆解文档的审查发现提炼;**不是实际错题**)

### P-01|认证语义误用

- 触发词:"ProbGuard 保证了""certified probabilistic guarantee""PAC 保证已兑现"。
- 自检:先问每场景采了多少 traces(30),再问最便宜的界是多少(185),最后问论文摘要用的是 analysis 还是 guarantee。
- 口令:**30 traces 买到的是演示,不是认证;PAC 部分是可行性地图**。

### P-02|两域 B 值张冠李戴

- 触发词:"B 大概几百""AV 域再采点样就能认证"。
- 自检:先说域(具身/AV),再说口径(Laplace/频率估计),最后说数量级。
- 口令:**具身 1.0–481 / AV 10⁷–10⁸;B 是"域适不适合 PAC 路线"的第一判据**。

### P-03|θ 方向与代码换算

- 触发词:"θ 越小越严格""代码里 threshold=0.1 所以论文阈值也是 0.1"。
- 自检:θ 修饰的是 P_safe(下界)还是违规概率(上界)?代码查的是 P[F unsafe] 还是 P[G ¬unsafe]?
- 口令:**θ 是 P_safe 下界越大越严;θ_paper = 1 − threshold_code;概率监控最易整体反向的一处**。

### P-04|G 无界式默认可用

- 触发词:"直接照论文查 P=?[G ¬unsafe] 就行"。
- 自检:这个域有安全吸收结构吗?任务有终态吗?FINISH 哨兵在新域还存在吗?
- 口令:**无安全 BSCC ⇒ P_safe≡0 ⇒ 恒报警;T5 用 P=?[F≤k unsafe]**。

### P-05|AWT 裸引

- 触发词:"提前 38.66 秒预警"。
- 自检:这个数字在哪个 θ 档?该档 FP 多少?零误报档的数字是多少?
- 口令:**AWT 必须带 θ 与 FP;零误报档是 15.84s@θ=0.3**。

### P-06|两层概率混淆

- 触发词:"95% 概率安全""这条链有 (ε,δ) 证书"。
- 自检:这句话里的概率是对采样过程还是对轨迹分布?
- 口令:**PAC 保程序可靠,不给单链证书**。

### P-07|名称与团队混淆

- 触发词:"Pro2Guard 那篇和 ProbGuard 那篇""ReGA 也是 Jun Sun 组的"。
- 自检:Pro2Guard 是什么(曾用名/仓名)?ReGA 的通讯作者是谁、在哪(北大 Meng Sun)?
- 口令:**一篇论文两个名字;两个 Sun 两个团队(SMU Jun Sun ≠ 北大 Meng Sun)**。

### P-08|三层版本混写

- 触发词:"ProbGuard 的导出格式是 X"(不带层声明)。
- 自检:这个断言来自 HEAD 代码、仓内现成产物,还是 README 宣称?三层在 ≥8 个格式点上互不一致。
- 口令:**V-HEAD / V-产物 / V-README,引用必带层声明**。

### P-09|相对数当绝对数

- 触发词:"完成率 80.4%""降低 65.37 个百分点"。
- 自检:先问分母——80.4% = 47.74/59.38(保留率),65.37% = 1−14.07/40.63(相对降幅),93.6% 同理;绝对数字是 14.07%/47.74%。
- 口令:**引用前先还原分母;README 一句话里的 80.4% 是相对口径**。

### P-10|复现范围夸大

- 触发词:"复现通过了,论文没问题""在线通道也验证了"。
- 自检:PASS 覆盖哪三步(P0 冒烟/P1 监控修复/P2 学习通道)?P3/P4 为什么没做?B 对表用的是哪层产物?
- 口令:**PASS 的是离线管线机制;P3/P4 空白;s1 的 B 不可直接对 Laplace 锚点**。
