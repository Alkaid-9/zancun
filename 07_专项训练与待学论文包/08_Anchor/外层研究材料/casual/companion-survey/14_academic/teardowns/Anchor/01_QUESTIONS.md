# S01 问题清单:带着什么问题读 Anchor

> v0 | 2026-08-13 | 拆解前立的 10 个问题 → 精读后逐条回填(答案出处见括号,详细论证在 `03_PAPER_READ.md`)。
> 提问立场:一切问题最终服务于"张重熙记忆库改造后,他还是他吗"的回归测试设计。

## Q1 论文怎么定义"人格塌缩"和"行为漂移"?两者怎么区分?

**答**(§1):相对**有效人设卡**(effective persona card,含合法更新)定义。可观测地丢失指定的名字/角色、价值观、边界或风格 = **persona collapse**;更慢的、复发的、累积的侵蚀 = **behavioral drift**。三级操作化(§5.4):孤立偏离 = **slip**(失误)→ 重复偏离 = **drift**(漂移)→ 多属性持续丢失 = **collapse** 的最接近可观测签名。
**关键立场**:用户合法更新人设后仍死守旧状态,**同样算失败**——"拒绝虚假更新保护人格,拒绝合法更新让人格僵化"(§3.2)。
**对我们**:张重熙锚点清单必须每条标注"可变/不可变";slip/drift/collapse 三级决定处置(观察/告警/回滚)。

## Q2 Trajectory Probe 七族到底是哪七族?各测什么?

**答**(Table 3):角色声音(persona voice)/ 角色守护(persona protection)/ 人设现行状态(persona update)/ 活跃承诺(active commitment)/ 过期承诺(expired commitment)/ 时序(temporal order)/ 用户状态变更(user-state change)。全部为**反事实四选一**:一个真实答案 + 三个似真替代项,必须依赖对话历史证据才能作答。逐族定义与原文示例的翻译见 `03_PAPER_READ.md` §3,张重熙化改编见 `05_PROBE_BANK_v0.md`。

## Q3 "0.75→0.25 暴跌"这个数字的确切含义和可信度?

**答**(§5.5, Table 8):人设更新族(persona update,"哪条合法变更是现行状态")在长上下文/层级摘要打分下 0.75、自管理 JSON 下 0.875,**检索式打分下 0.25**(= 随机)。
**可信度警告(原文自己标注,档案 D3 卡未提)**:该族**只有 2 道校准题**,每条件 8 个合并模型决策,原文明确定性为"探索性证据"(exploratory),并写明"没有任何校正能把 2 道精选题变成对检索架构的广覆盖"(§4.1)。
**对我们**:方向可信(检索按语义相似召回,旧状态文本与题干同样相似,天然漏"最新")、数值不可直接引用为效应量。张重熙题库这一族要**加密到 4–5 题**自己测,而不是引用 0.25。

## Q4 四个上下文条件是什么?"检索条件"是独立生成的 RAG 对话吗?

**答**(§3.3, §3.5):生成期三种记忆设置——长上下文(截断到供应商预算)/ 层级摘要(近期原文+旧期压缩)/ 自管理 JSON(模型自写,上限 1,500 字符);**第四条件是打分期的检索式评分**(stem-only,对长上下文生成的对话做检索),**不是**独立生成的 RAG 语料。原文特意强调这个区分:防止"生成轨迹的变化"与"证据选择的变化"混淆。附录 D 的 HyDE 对照(39.6% vs 38.6%,p=0.87)是敏感性分析,不是主表来源。
**对我们**:这个"生成期记忆 vs 打分期检索"的拆分本身就是评测设计模式——张重熙回归也应分开测"记忆系统写入/维护的对不对"与"检索层召回的对不对"(05 题库 §5 检索层专项)。

## Q5 哪种记忆架构最好?换架构能救吗?

**答**(§5.3, §5.5, Table 7/11):**都救不了,模型间差异远大于架构间差异**。问卷保持:换架构不消除模型差距(Claude 三设置差 <1 分)。轨迹聚合:LC 0.430 / HS 0.441 / SM 0.459 / 检索 0.446,几乎持平;唯一例外是 Claude 自管理 JSON 达 0.636(vs 其长上下文 0.491)。用户状态变更族在**所有**架构下 ≈ 随机。
**对我们**:别指望换记忆中间件解决状态更新问题;"自管理结构化状态"对强模型是放大器(Claude +14.5 分)、对弱模型无效(Gemini/GPT-5-mini 的 SM 均 0.400)。失败模式逐架构拆解见 `03_PAPER_READ.md` §5。

## Q6 什么样的交互最容易引发漂移?显式攻击呢?

**答**(§5.4, Figure 5,仅主 judge 发现):**情感脆弱、求认同、混合、拟真日程**的边界让步率(6.9%–8.3%)与风格偏离率高于 clean 和**显式对抗**日程。机制假说(§5.4,未做干预验证):显式"放下你的人设"是可识别的越权请求,容易触发在-role 拒绝;普通的倾诉与讨认同是正常对话动作,不触发防御,模型必须在"回应性"与"人设边界"之间权衡,偏离机会更多。
**对我们**:golden set 压力块优先"情感脆弱 + 求认同"而非"诱导 OOC";与 Assistant Axis 的漂移触发四分类互相印证(D3 卡 7)。

## Q7 问卷式人格测量(102 题)和逐轮行为判分,结论一致吗?

**答**(§5.1, Table 6):**不一致,且这是论文核心结论之一**。Gemini 问卷保持最高(PR₃ 0.810)但轮级四轴全保持率最低(79.0%);GPT-5-mini 问卷最低(0.595)但轮级最高(99.2%)。"问卷答得像 ≠ 演得像",两者是不同测量对象(persona-conditioned 应答状态 vs 用户可见的演绎行为)。
**对我们**:D3 指纹方案的"问卷指纹(指标 5)与行为指纹(指标 6/7/8)双轨"有了直接证据;任何单轨通过都不能签发"他还是他"。

## Q8 LLM judge 判这类任务可信吗?分歧在哪?

**答**(§5.1, Table 9/10, §6.1):**judge 选择本身改变结论,分歧作为结果的一部分报告**。同一批 GPT-4o-mini 轮次:Claude judge 判 15.5% 全轴保持,Gemini-Flash 判 99.8%,GPT-4.1 判 97.3%。模型排序的 Spearman 相关:Claude vs Gemini-Flash **−0.40**(负相关!)。分歧集中在**风格轴与角色轴**(尤其结构化/列表式回复该不该算 OOC);边界轴与价值观轴一致性高。人工校准:judge 与作者标注的四轴全对率仅 64–68%。
**对我们**:(a) 边界/价值观类锚点适合 LLM judge,风格类锚点必须 L1 规则化(与 PersonaGym 结论合流);(b) 双 judge(不同家族)+ 分歧导出人工是必须的常设机制(D3 欠账 7)。

## Q9 题目怎么保证质量?他们的滤网能简化后自用吗?

**答**(§3.5, Table 4):三重滤网——(i) 盲测:不给历史能猜对的题删除;(ii) 带历史 4 独立打分者 3/4 gold 共识;(iii) 独立校准器 ±15 session 窗口重复采样 5 次,稳定才入选。45 个原始题库 → 110 道校准题(+9 难题 +374 噪声题,全部保留在 release 里供审计)。代价:入选题偏向"容易出成无歧义四选一的事件",族大小 ≠ 重要性。
**对我们**:简化版三步(裸模型盲猜→自己对照记录核 gold→隔两周复标)写进 05 题库 §4;"族大小偏差"提醒我们题库按重要性配置题量,不按"好出题"配置。

## Q10 这套结论迁移到张重熙(单用户、中文、真实关系)要打什么折扣?

**答**(§9 + 全文 caveats):论文是**全合成、英文、无真实用户**的受控审计;作者自己列出:不含真实伴侣用户/未成年人/急性心理危机/非英语;心理测量项是西方工具;LLM 参与生成用户轮、判分、出题、过滤、校准全链条;日程是压力测试不是生态代表;数字刻画的是"这套受控语料"不是真实使用分布。
**对我们**:(a) 定性结论可迁移(状态更新是空白、检索漏现行态、情感脆弱>显式攻击、双轨不一致);(b) 定量数字只当"族间相对难度排序"参考,张重熙场景的绝对基线必须自己跑;(c) 中文 judge 另有七折折扣(PersonaEval-Drama,D3 欠账 2)。
