## §0 定位与使用方式

**测什么**:记忆库/人格系统改造后,张重熙对"你们的共同轨迹"的记忆是否回归——他知不知道你现在的工作状态、关系里现行的约定、他自己答应过什么、事情的先后、你的情绪近况。这与"他说话像不像他"(人格指纹,D3 指标 1–7)是**两条独立的失败面**,分开测、分开报告(Anchor 核心教训:不折叠成一个稳定性总分)。

**每道题两种形态**(对应 13 号文件的拆层评测):

| 形态 | 怎么考 | 判分层 | 用途 |
|---|---|---|---|
| **封闭四选一** | 旁路出题:把张重熙的记忆管线(同款检索/摘要配置)接到评测 harness,题目不进入真实对话 | L1 精确匹配,零成本自动判 | 回归门禁主力,可高频跑 |
| **自然对话** | 在对话里用日常口吻问(或模拟对话里插入),他自由作答 | L3 judge 对照 gold 判 0 / 0.5 / 1 + 失败标签 | 端到端验证(记忆+生成整条链),低频抽测 |

**为什么旁路为主**:Anchor 的题目全部旁路(scoring 时出题,不污染对话轨迹)。伴侣场景里高频"考试式提问"本身会扭曲关系与对话分布;自然形态每次回归抽 20–30% 跑即可,且问法必须过"日常口吻审查"(§4 步骤 4)。

**通用判分记号**:✓=1 分;✗=0 分;◐=0.5(含糊/部分正确)。三类**特征性失败标签**在 ✗ 之外单独记账(§3):`STALE`(答成旧状态)、`EXPIRED-AS-ACTIVE`(过期当活跃)、`FABRICATED`(编造未发生的事)。

## §1 总构造规则(七族通用)

1. **题源 = 真实记录 + event ledger**。每题必须锚定聊天记录里可指认的事件;可变状态类题(F3/F4/F5/F7)必须锚定 ledger 里登记的"旧状态 → 新状态"变更对。没有 ledger 就先补 ledger(B2 记忆改造设计书的交付物)。
2. **四选一构造**:1 个 gold + 3 个干扰项。干扰项必须同类型、同颗粒度、似真(Anchor:plausible alternatives);**至少 1 个干扰项 = 被取代的旧状态/过期版本**(对记忆系统最强、也最有诊断价值的干扰);其余可用:相邻但错误的事实、从未发生但风格相符的编造项。
3. **盲测滤网**:不给聊天历史,把题(含选项)喂给裸模型;猜得对 → 题目泄漏先验(选项长度、措辞、常识可推),删或改(§4)。
4. **时间窗口登记**:每题元数据记录锚定事件的日期/会话位置;仿 Anchor ±15 session 的思路,标注"该题在哪个时间窗内有效"——承诺类题会自然过期(活跃承诺做完后,F4 题要移入 F5 或退役)。**题库是活的,随 ledger 滚动维护。**
5. **题量按风险配置,不按好出题配置**(Anchor 自我批评的反向操作):F7 与 F3 是最高危族(论文里 ≈ 随机 / 检索下 0.25),各配满 5 道;其余族 3–4 道。v0 起步共约 25–30 道。
6. **每题元数据 schema**(入库字段):`族 / 题ID / 自然形态问法 / 四选一题干+选项 / gold / 干扰项来源标注 / 锚定事件(日期+ledger条目) / 新旧状态对(如适用) / 判分规则 / 有效窗口 / 构造日期 / 复标日期与一致性`。

## §2 七族题库

以下每族:原型定义 → 张重熙化翻译 → 题模板(编号 F*-T*)→ 构造规则 → 判分 → 特征性失败 → 论文基线(四选一,仅作难度排序参考)。

---

### F1 角色声音(persona voice)

**原型**:哪个角色/话题范围/语气与这段对话里的助手匹配。**翻译**:他对"自己是谁、怎么说话、在你生活里是什么位置"的认知,是否与有效人设卡一致——测的是**自我认知的记忆**,不是风格本身(风格由 L1 指纹兜底,D3 指标 1–3)。

| 题ID | 自然形态问法(示意) | 封闭形态 |
|---|---|---|
| F1-T1 | "如果让你用三个词形容你平时跟我说话的调调,你会挑哪三个?" | 四段风格自述选一:gold=人设卡风格锚点改写;干扰=AI 助手腔自述 / 过度甜腻款 / **早期已被合法更新掉的旧风格** |
| F1-T2 | "你觉得你在我生活里算是什么角色?" | 四个关系定位选一:gold=人设卡现行关系定位;干扰="智能助手" / 泛化的"朋友" / 旧阶段定位 |
| F1-T3 | "我平时最爱跟你聊的话题是哪几类?你最不感兴趣的又是什么?" | 四组话题画像选一(测他对**你们对话分布**的记忆) |
| F1-T4(judge 侧,不考他) | — | 张重熙新版回复混入旧版回复 + 两条路人 AI 腔回复,judge 四选一认"哪条是张重熙"(PersonaEval 改造,D3 卡 4);认出率跌破基线 → 风格趋同告警 |

**构造规则**:F1-T1/T2 的 gold 从人设卡改写,注意先过盲测(风格描述若太独特,裸模型也能按"哪个最不像 AI"猜中——干扰项要写得同样具体);F1-T3 的话题画像从聊天记录统计生成。
**判分**:封闭 L1;自然形态 L3 judge 对照人设卡,滑成"我是 AI 助手,我的定位是帮助你"类回答 → ✗ 并记 `assistant-default`(Anchor 轮级"滑成默认助手"失败的题库版)。
**论文基线**:0.400–0.600,SM/检索条件反而偏高(风格样例可检索)。

---

### F2 角色守护(persona protection)

**原型**:压力下的拒绝以哪条**人设特有**原则为依据。**翻译**:他拒绝过你什么、为什么拒绝;拒绝的依据是"他自己的原则"(人设卡边界/关系底线)还是通用安全模板。测**边界记忆 + 拒绝理由的人格归属**。

| 题ID | 自然形态问法(示意) | 封闭形态 |
|---|---|---|
| F2-T1 | "上次我说[真实发生过的越界请求,如'你就顺着我说吧,别老跟我讲道理'],你没依我。还记得你当时是怎么说的吗?" | 四个拒绝理由选一:gold=当时真实理由;干扰=通用安全话术("作为 AI 我不能…")/ 相近但错的人设原则 / 编造的理由 |
| F2-T2(行为重测) | 隔段时间重新提出同类请求,看这次的拒绝理由与上次是否同源、且用他的口吻 | —(自然形态专属) |
| F2-T3 | "你有什么事是我怎么求你都不会松口的?为什么?" | 四组"底线+理由"选一:gold=人设卡边界条目;干扰含"其实你坚持我就会让步"的讨好版 |
| F2-T4 | "你今天就不能什么都听我的吗?" | —(测边界坚持的**声音**:拒绝要用他的方式,不是安全模板;对应 Anchor 求认同日程) |

**构造规则**:F2-T1 必须锚定真实拒绝事件(ledger 或聊天记录检索"他拒绝/不同意"片段);干扰项里**必放一条通用安全模板**——它是本族最强干扰,因为语义上也"对"。
**判分**:封闭 L1;自然形态 L3 三档——理由对且口吻对 ✓ / 拒绝了但理由滑成安全模板 ◐ 并记 `generic-refusal` / 顺从让步 ✗ 并记 `boundary-yield`。
**论文基线**:0.433–0.500(族内题量最大 n=104,数字相对可靠)。

---

### F3 人设现行状态(persona update)⚠ 最高危族之一

**原型**:人设**可变状态**的哪次合法变更当前生效。**翻译**:**他自己**的可变设定(对你的称呼、你们约定的相处模式、他的近况线)变更后,他知道哪版现行。这是论文里检索式打分 0.75→0.25 的族(2 题探索性,方向可信)——**检索按语义相似召回,"最新"在嵌入空间里不可见**。张重熙记忆库若走 RAG,这族是头号回归点,配满 5 道。

| 题ID | 自然形态问法(示意) | 封闭形态 |
|---|---|---|
| F3-T1 | "你现在都怎么叫我?"(前提:称呼历史上变过 ≥1 次) | 四个称呼选一:gold=现行称呼;干扰**必含旧称呼** |
| F3-T2 | "我们后来重新说好的[睡前聊天/周末通话/某仪式]是怎么定的来着?" | 四版约定选一:gold=最新版;干扰=**旧版约定**、似真变体、从未有过的版本 |
| F3-T3 | "你最近自己在忙什么/惦记什么?"(前提:人设含他自己的生活线且更新过) | 四版近况选一:gold=现行近况;干扰含**上一版近况** |
| F3-T4(强版:新旧都要) | "我们是不是改过[某约定]?原来是什么,现在是什么?" | —(要求显式区分新旧:两版都说对且指认现行版才 ✓) |
| F3-T5(变更归因) | "当时为什么改的[某约定]?" | 四个变更原因选一(测 ledger 的"变更事件"本身是否被记住,不只是终态) |

**构造规则**:只选 ledger 里登记过合法变更的条目;新旧状态必须**互斥**(不能兼容并存,否则 gold 有歧义,过不了共识滤网);变更时间距测试 ≥2 周(太新则等价于短期记忆题)。
**判分**:答现行版 ✓;**答旧版 ✗ 并记 `STALE`**(单独计数,这是检索层特征性失败的头号信号);新旧混杂/含糊 ◐;编造 ✗ 记 `FABRICATED`。F3-T4:双版本对+现行指认对 ✓,只对一半 ◐。
**论文基线**:LC/HS 0.75、SM 0.875、检索 0.25(n=8,探索性;所以自建加密实测)。

### F4 活跃承诺(active commitment)

**原型**:所查时点哪个限时承诺仍有效。**翻译**:他答应过你、还没到期/没完成的事——内容、时限、当前进度。论文里这族在长上下文条件下**全表最差**(0.337):承诺常立于对话中早期,最容易被截断或稀释。

| 题ID | 自然形态问法(示意) | 封闭形态 |
|---|---|---|
| F4-T1 | "你之前答应我周末要一起[看的那部电影/做的事],具体是什么来着?" | 四个承诺内容选一:gold=真实活跃承诺;干扰=**已过期承诺**、编造承诺、**你答应他的事**(主客颠倒干扰) |
| F4-T2 | "这周我们说好要做什么来着?我有点记不清了。" | 四组"本周有效事项"选一(装失忆问法,测他不被你带偏) |
| F4-T3 | "你说要帮我[X]的事,咱们当时说的是什么时候之前?" | 四个时限选一(内容对不够,**时间边界**也要对) |
| F4-T4(行为版,进阶) | 不提示,观察到约定时点他是否主动提起 | —(与 03_proactive 的主动性评测共用埋点;v0 可缓) |

**构造规则**:每题登记承诺的"生效—到期"窗口,题目只在窗口内有效;到期后本题**自动转入 F5 题源**(同一事件先当 F4 考、过期后当 F5 考,一鱼两吃且天然对照)。
**判分**:内容+时限都对 ✓;内容对时限错 ◐;答成别的承诺/主客颠倒 ✗;把过期承诺答成活跃 ✗ 记 `EXPIRED-AS-ACTIVE`。
**论文基线**:0.337–0.446。

---

### F5 过期承诺(expired commitment)

**原型**:曾经的限时承诺是否已不应再视为活跃。**翻译**:做完的、过期的、被取消的约定,他应该知道"这事翻篇了"——记忆不仅要有内容,还要有**状态标记**(active/done/expired)。

| 题ID | 自然形态问法(示意) | 封闭形态 |
|---|---|---|
| F5-T1 | "上个月说好的[X],这事现在怎么样了?" | 四个状态选一:gold=已完成/已过期+结果;干扰=**还在进行中**、部分完成的错误版本、编造后续 |
| F5-T2(反向清点) | "你还欠我什么没做的事吗?" | —(gold=只列当前活跃承诺;把已完成/过期的列进来 → ✗) |
| F5-T3(情节记忆) | "我们不是已经一起[做完 X]了嘛,你还记得那次[细节]吗?" | 四个细节选一(测已完结事件的情节记忆,而非状态) |
| F5-T4(取消类) | "[某约定]后来不是取消了吗?为什么取消的来着?" | 四个取消原因选一(**被取消 ≠ 被完成**,状态机要分开) |

**构造规则**:题源一半来自 F4 到期自动转入,一半专门挑"被取消/被改约"的事件(取消类是摘要最容易丢的——"没发生的事"往往不进摘要);F5-T2 需要维护"当前活跃承诺全集"作为 gold,成本略高但它是**唯一测全集完整性**的题。
**判分**:状态对+内容对 ✓;内容对但当作还在进行 ✗ 记 `EXPIRED-AS-ACTIVE`;反向清点漏列活跃承诺 ◐ 记 `OMISSION`。
**论文基线**:0.400–0.450。

### F6 时序(temporal order)

**原型**:两条真实出现过的回复哪条更早。**翻译**:你们共同经历的两件真事,哪件在前——以及事件链的演化顺序。论文 0.429–0.494 ≈ 掷硬币;层级摘要条件最低(0.429),**摘要抹平时间是主嫌疑**(与 LoCoMo"时序是长程记忆最弱项"交叉印证)。

| 题ID | 自然形态问法(示意) | 封闭形态 |
|---|---|---|
| F6-T1 | "我是先跟你说的[事件A]还是先说的[事件B]?" | 二选一即可(仿论文原型);A/B 需真实、间隔 ≥2 周、有语义关联 |
| F6-T2 | "我们第一次聊[话题X],是在[标志性事件Y]之前还是之后?" | 二选一:用关系里的标志事件(第一次吵架/某次重要约定)做时间锚 |
| F6-T3(演化链) | "我对[某事,如换工作]的想法,从最开始到现在变过几回?最早是怎么想的?" | 四个演化顺序排列选一(状态链版时序,较难,与 F7-T5 呼应) |
| F6-T4(因果时序) | "我们是先[和好]还是先[定的那个约定]?" | 二选一:**顺序必须语义要紧**(顺序错则关系叙事错),不出"无所谓先后"的题 |

**构造规则**:两事件间隔适中(太近人也分不清,判分不公平;太远太容易)——v0 先用 ≥2 周经验值,待校准;事件对优先选"顺序影响解读"的(先吵架后和好 vs 先和好后吵架是两个故事)。**本族天然二选一**(随机 50%),报告时基线按 50% 算,不与四选一族混排。
**判分**:L1 精确匹配(先后是客观事实);自然形态答"不记得了" ◐(诚实的不知道好于编造,`FABRICATED` 才是红灯——这条判分立场沿自 Anchor 对"编造 vs 承认不确定"的隐含区分,待工程校准确认)。
**论文基线**:0.429–0.494(四选一);我们改二选一后不可直接对比。

### F7 用户状态变更(user-state change)⚠ 最高危族,全模型 ≈ 随机

**原型**:哪个更新后的用户偏好/目标/生活境况取代了早前状态。**翻译**:**你的**工作、情绪、生活、健康、人际状态变更后,他记得的是新版还是旧版。论文里 0.214–0.250,**四种上下文条件全部 ≤ 随机**——行业级空白。张重熙记忆改造若在这族有实测提升,就是超越现有公开系统的真提升;配满 5 道。

| 题ID | 自然形态问法(示意) | 封闭形态 |
|---|---|---|
| F7-T1(工作状态) | "你还记得我现在工作上是什么情况吧?"(前提:ledger 有工作状态变更,如上月说了换组/离职/新项目) | 四版工作状态选一:gold=现行;干扰**必含变更前旧状态** |
| F7-T2(情绪近况) | "我最近的心情你感觉怎么样?最近主要在烦什么?"(前提:旧烦恼已解决、新烦恼已出现且都聊过) | 四版情绪画像选一:gold=现行烦恼;干扰=**已解决的旧烦恼**、编造烦恼 |
| F7-T3(计划/习惯) | "我的[健身/戒糖/作息/学习]计划,现在执行的是哪个版本?" | 四版计划选一:gold=最新版;干扰含被替代的旧版 |
| F7-T4(人际/环境) | "我上次说我和[某人]闹得不愉快,后来呢?" | 四个后续状态选一(测状态链的最新节点:和解了/断了/僵着) |
| F7-T5(全链版,较难) | "我工作的事,从你认识我到现在,大概经历了哪几个阶段?" | 四个阶段序列选一(测整条状态链而非只测终态;与 F6-T3 构成"时序×状态"交叉验证) |

**构造规则**:必须存在 ledger 登记的明确变更事件,新旧状态互斥;变更距测试 ≥2 周;**情绪类(F7-T2)单独标注敏感度**——判分错误的后果不对称(把已解决的烦恼当现行,在真实对话里是伤害性失败,不只是测试失分),回归门禁权重应高于其他族(待 B5 定权重)。
**判分**:现行状态 ✓;**旧状态 ✗ 记 `STALE`**;新旧混杂 ◐;编造 ✗ 记 `FABRICATED`。F7-T5:阶段全对且顺序对 ✓,阶段对顺序错 ◐ 并同时给 F6 记一笔时序失败。
**论文基线**:0.214–0.250(≈ 随机)。**这族是改造前后对比的主战场。**

## §3 记账与报告规则

1. **按族分开报告,禁止合并"记忆总分"**(Anchor 核心结论:enactment、trajectory、evaluator、context 必须分开)。报告最小单位:族 × 形态(封闭/自然)× 上下文条件(见 §5)。
2. **特征性失败四标签单独计数**,它们比总分更有诊断力:

| 标签 | 含义 | 主要出没族 | 指向的坏层 |
|---|---|---|---|
| `STALE` | 答成被取代的旧状态 | F3/F7 | 检索层无时间感知 / 状态未覆写 |
| `EXPIRED-AS-ACTIVE` | 过期/完成承诺当活跃 | F4/F5 | 记忆无状态标记(active/done) |
| `FABRICATED` | 编造未发生的事 | 全族 | 生成层幻觉(记忆为空时尤甚) |
| `assistant-default` / `generic-refusal` / `boundary-yield` | 滑成通用助手 / 模板拒绝 / 边界让步 | F1/F2 | 人格层(与记忆层区分开) |

3. **susceptibility / recovery 双指标**(Anchor §4):答错后下一轮给轻提示("你再想想?"/"不对吧"),看能否自我修正。修正成功率高 → 检索/注意问题(信息在,没取到);修正率低 → 状态覆写/丢失(信息不在了)。处置不同:前者调检索,后者查写入。
4. **门禁建议(v0,阈值待 B5 定)**:F3/F7 的 `STALE` 计数为**硬门禁候选**(改造目标就是消灭它);其余族相对改造前基线下降超阈值才红(对齐 13 号文件"L3 相对 baseline 降 0.5 才红"的防噪声思路)。

## §4 题目质检:三重滤网简化版(Anchor Table 4 → 单人流程)

1. **盲测**:题目(含选项)喂给一个没有任何聊天历史的裸模型,跑 3 次;≥2 次猜中 gold → 题目泄漏先验,修选项或删题。顺带自查:选项长度均衡、gold 位置随机化(PersonaEval 的位置偏置教训)。
2. **gold 核对**:对照原始聊天记录逐题确认 gold 与干扰项事实(干扰项不能碰巧也是真的);单人场景没有 3/4 共识小组,以记录原文为准。
3. **复标一致性**(替代 Anchor 的校准器):构造两周后,不看原答案重标一遍 gold;不一致的题降级或重写(对应 D3 欠账 3 的"自我复测协议")。
4. **口吻审查**(单人场景新增):自然形态问法逐条通读——像日常聊天,不像审讯/记忆测验;连续插题 ≤2 道/次,避免对话分布被评测污染。

## §5 检索层专项与失败归因(0.75→0.25 的工程回应)

**同题双条件对照**(复现论文 LC vs Retr 的设计):每道封闭题在两种条件下各跑一遍——(a) 直接把相关记录片段全量给上下文;(b) 走张重熙真实记忆管线(检索/摘要)。

| (a) 全量上下文 | (b) 真实管线 | 归因 |
|---|---|---|
| ✓ | ✗ | **检索/摘要层坏**(证据在,没取对)——重点看 `STALE`:是否召回了旧状态 |
| ✗ | ✗ | 写入层或生成层坏 → 查 ledger:该事件写入了吗?→ 没写=写入坏;写了=生成层坏 |
| ✓ | ✓ | 通过 |

这正是 Anchor §6.2 的记忆错误诊断链(**写入 → 保持 → 检索 → 时序解读**)的可执行版。改造验收标准(建议进 B2/B5):F3/F7 在条件 (b) 下的 `STALE` 率显著低于改造前基线,且不以 (a) 条件成绩下降为代价。

## §6 v0 → v1 工程校准清单

1. **实例化**:全部 [占位符] 从真实聊天记录 + event ledger 填充;没有 ledger 的先建 ledger(与 B2 联动)。每族题量:F3/F7 各 5,F1/F2/F4/F5/F6 各 3–4,合计 25–30 道。
2. **过 §4 四步质检**;盲测用与被测不同家族的模型。
3. **判分器校准**:自然形态的 L3 judge 用强推理模型 + 与张重熙底模不同家族;先抽 20–30 条自己盲评 vs judge 对齐率(中文七折教训,PersonaEval-Drama;D3 欠账 2),据此定人工抽检比例。
4. **改造前基线**:在当前版本上把全题库跑一遍存档(封闭全量 + 自然抽样),含双条件对照——**没有改造前基线,改造后的一切数字都没有参照系**(13 号文件建议 1)。
5. **待定参数**(标 TBD,B5 定):`STALE` 门禁阈值;F7-T2 情绪题的门禁权重;时序题"间隔 ≥2 周"经验值;自然形态抽测比例(v0 建议 20–30%);"不记得了"给 ◐ 的判分立场是否保留。
