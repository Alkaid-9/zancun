## 使用方法

每个错误必须完成四步闭环:

1. **原错误句**:逐字记录,不替学员润色。
2. **证据定位**:拆解文档(README/01/02/03/04/GLOSSARY)中的文件+节名,必要时到论文节号。
3. **正确句**:可独立引用,消除歧义。
4. **迁移规则**:以后遇到同类问题时怎样检查。

红线错误修正后,还需闭卷重答原题;只阅读正确答案不算闭环。

## 预置高风险误区(不是实际错题)

从拆解文档审查发现提炼;供主考出追问、供学员自检,不得冒充已发生错误。

### P-01|拦截率口径三连混淆

- 触发词:"AgentSpec 拦截率 91.5%""准确率超 90%""78.9% 是论文报的"。
- 自检:先写 #inv/#vio 定义,再写全量算式,再写剔除口径与剔除依据,最后标 [推算]。
- 口令:**333/422 全量,333/364 剔除后,两者都是 [推算];引用用 Table 3 分类数据**。

### P-02|定义误当定理

- 触发词:"§3.3 证明了…""形式化保证了安全"。
- 自检:数一遍论文的定理数(0);问自己 Eval(τᵢ, aᵢ) 有没有实现。
- 口令:**有语义定义、零定理;违规必干预 ≠ 危险必违规**。

### P-03|reactive/proactive 分界丢失

- 触发词:"AgentSpec 预测风险""提前干预""轨迹级分析"。
- 自检:判定函数是 viol(τᵢ)∈{0,1}(当下、定性)还是 P[ψ|abs(sᵢ)](未来、定量)?
- 口令:**当下判定归 AgentSpec,前瞻归 ProbGuard;§6.3 就是分界原文**。

### P-04|DSL 表达力误读(双向)

- 触发词:"DSL 写不了时间窗,所以做不了窗口检测"(低估);"谓词能读全前缀,所以能强制任意 LTL 性质"(高估)。
- 自检:区分 DSL 表面(无析取/时序)与谓词层(可读整条 τᵢ);区分过去可测与未来性质。
- 口令:**past-complete, future-free [个人分析];窗口今天就能藏进谓词,只是不可见于 DSL 表面**。

### P-05|封闭集与安全税抹除

- 触发词:"AV 100% 合规达成交通法保证""具身零成本归零"。
- 自检:AV 分母是 8 场景;具身归零伴随 58.62%→54.26%;Liquid and Spill 基线本来就是 0%。
- 口令:**100% 是 8 场景封闭集;归零有安全税;基线 0% 的类不算证据**。

### P-06|出处三层混写

- 触发词:"论文说 ProbGuard 依赖它""论文提出 ECA 范式""论文证明它等价 edit automata"。
- 自检:说任何一句前先问——这是论文原文、[D6] 仓库实见,还是拆解 [个人分析]?
- 口令:**依赖链与 token 数是 D6 实见;ECA/edit automata/干预强度谱是个人分析;论文原文只到 §6.3 与 Falcone 引用**。

### P-07|裁决者错位

- 触发词:"违规就弹窗问用户要不要继续"(companion 场景)。
- 自检:这个域里 user 是安全权威还是风险承受者?inspection 对象应是谁?
- 口令:**金融 user=权威;companion user=风险承受者;升级对象改平台/监护角色**。

### P-08|两位孙姓 PI 混淆

- 触发词:"北大 AgentSpec""ReGA 也是 Jun Sun 组的"。
- 自检:AgentSpec/ProbGuard/FixDrive/LawBreaker/μDrive = SMU Jun Sun(孙军);ReGA = PKU Meng Sun(孙猛);桥文献是 ICML 2025 立场文(本文参考文献 53)。
- 口令:**SMU 行为轨迹黑盒动作级;PKU 内部表示白盒 token 级;两组不混**。
