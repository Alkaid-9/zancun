每个错误必须完成四步闭环:

1. **原错误句**:逐字记录,不替学员润色。
2. **证据定位**:拆解文档(README / 01_QUESTIONS / 03_PAPER_READ / 04_DERIVATION / GLOSSARY)内的文件+节。
3. **正确句**:可独立引用,消除歧义。
4. **迁移规则**:以后遇到同类问题时怎样检查。

红线错误修正后,还需闭卷重答原题;只阅读正确答案不算闭环。

## 预置高风险误区(不是实际错题)

从拆解文档的审查发现提炼;首考前主考可通读,但不得当作学员已犯错误登记。

### P-01|"偏序更优"话术滑坡

- 触发词:"偏序 alignment 找到更便宜的对齐""unfolding 的对齐质量更高(代价意义上)"。
- 自检:先问代价值是否变(P1:不变),再问增量在哪(结构/诊断/搜索空间)。
- 口令:**优势在依赖结构,不在代价值**。

### P-02|时间/排队方向反转

- 触发词:"unfolding 更快""A* 内存爆炸"。
- 自检:时间 A* 全胜 71.45%–99.11%;排队状态 unfolding 赢(Dijkstra 最多多 118,318.48%);长尾在 unfolding 侧。
- 口令:**时间输、队列赢、长尾要防**。

### P-03|admissible 当 consistent

- 触发词:"启发式可采,所以 ⊂-单调成立""FoldA Thm 4.3 证明完整"。
- 自检:h(M2) 是下界不是真实代价;所需是一致性 h(M1)≤Z(E_d)+h(M2);marking-equation 启发式恰好一致(LP 一行证明)。
- 口令:**换代价必验一致性**。

### P-04|映射方向忘翻转

- 触发词:"missing events 就是缺失偏差"。
- 自检:Siddiqui 以模型为被评对象(Cortado 发现工具);T2 以安全性质网评轨迹。
- 口令:**T2 缺失=model move=undesired;T2 越权=log move=missing**。

### P-05|venue 张冠李戴

- 触发词:"Siddiqui,BPM 2025""两篇都是 BPM"。
- 自检:FoldA=BPM 2025(LNCS 16044);Siddiqui=PETRI NETS 2025(LNCS 15714);T2 提案 §7 合写行本身就是易错源。
- 口令:**引用前先过一遍 README 论文卡 ⚠ 勘误**。

### P-06|可复算幻觉

- 触发词:"算法是确定的,所以输出可复算"。
- 自检:FoldA 平局用 Python id()(内存地址);Siddiqui 第三键=入队序,依赖扩展枚举顺序;等代价多解时返回结果可漂移。
- 口令:**要可复算,先换确定性规范序(改造点 A4)**。

### P-07|保证外溢

- 触发词:"定理保证了 T2 偏差报告 sound/complete""该方法在 agent 域已验证"。
- 自检:保证=输入无误下的精确最优性/完备性;评测域=业务过程日志;标签映射误差与域外推都在界外。
- 口令:**保证到算法为止,输入与域外推自负**。

### P-08|数字与命名硬化

- 触发词:"BPIC17 完成 697(或 679)确定无疑""FoldA 就是 unFOLDing Alignments 的缩写(论文说的)"。
- 自检:697(正文)vs 679(Table 2)不一致疑笔误——两口径并报、标待核;"FoldA"命名论文未解释,缩合说是拆解推断。
- 口令:**存疑数字并报两口径,推断标注为推断**。
