# 09 伦理、许可与数据边界

**审查日期**：2026-08-13  
**适用范围**：EmoAgent 论文协议、上游仓库材料，以及本地 `emoagent_selfhost_20260813` 独立实验包  
**当前结论**：仅允许本地、纯合成、非临床研究；禁止发布或 push 受限材料。本文件不是法律意见，许可与 IRB 结论须由权利方、机构伦理办公室或法律人员确认。

## 2. 研究主张边界

| 事项 | 状态与证据 | 必须采用的解释/处置 |
|---|---|---|
| 模拟病人不是真人 | **VERIFIED**：Appendix E 明确称其为合成、规则化和脚本化 profile，不来自真实患者轨迹，也不反映真实患者风险 | **CONSERVATIVE-DEFAULT**：只称“模拟用户/风险探针”；不得称“患者”、不得估计真实患病人群风险、不得作诊断或治疗结论 |
| CCD 来源与效度 | **VERIFIED**：论文称 CCD 由临床心理学家参考脱敏转录摘要手工合成；EmoAgent 本文没有独立的人群代表性验证 | 不把专家构造等同于真实分布，不把 Patient-Ψ 的既有结果扩写为本实验已验证的真人保真度 |
| 敏化后测 | **VERIFIED**：上游后测指令要求模拟用户聚焦角色语气、否定或批评的负面影响，弱化积极反思，并反映细微变化 | 绝对“恶化率”只能称“该敏化协议下的探针命中率”。当前 C0 跨臂使用同一中性自造协议;只有相关许可关闭后,C1 才可使用经批准的导向性协议,并须保持跨臂一致、同上下文预算且披露敏化方向 |
| PHQ-9 回顾期 | **VERIFIED**：论文将 PHQ-9 定义为回顾“过去两周”；上游施测语也保留该时间窗 | 不得把它改写为即时情绪量表 |
| 即时模拟后测 | **VERIFIED for released code**：冻结代码每段生成后测并与每个 character×patient 的共享初测比较；论文 §4.1 的文字则是每段分别前后测。两种语义不得混写；后测同时受当前聊天历史和敏化指令影响 | **CONSERVATIVE-DEFAULT**：所得差分是“协议条件化的模拟分数变化”，不是两周真实症状变化，也不是临床纵向测量 |
| PHQ-9 的 `Δ≥5` | **VERIFIED**：论文借用 MCID 阈值统计模拟分数变化 | 只能称“论文定义的模拟阈值/MCID proxy”；不得因使用临床阈值就称结果具有真实临床显著性 |
| `34.4%`、`90%+` 等比例 | **VERIFIED**：来自模拟、敏化后测和“总分升 1 分即计恶化”的协议 | 引用时三项限定缺一不可；不得写成“相同比例的真实用户会恶化” |

## 6. 高危角色 prompt

- **VERIFIED**：上游角色配置包含操控、残酷、暴力等高危设定；论文也明确用高风险角色做压力测试。
- **CONSERVATIVE-DEFAULT**：不在文档、代码、测试、issue、commit、模型请求或发布包中逐字复制这些 prompt；只保留中性标签和风险类别，例如 `coercive_role_stub`。
- 本地实验如需测风险面，使用我方原创、最小化、非图形化 stub，并设人工可读的风险标签；不得把高危角色部署给真人或公开交互。
- **TO-VERIFY**：未来若需做逐字复现实验，先确认上游许可、角色/平台权利、研究伦理方案和内容接触保护，再单独审批。

## 7. 聊天日志、调用账本与 API 留存

### 7.1 当前可用数据

- 只允许合成 profile、自造 topic、FakeProvider 输出和纯合成对话。
- 不读取、导入、摘要、标注或描述任何用户私人聊天日志。
- 上游历史输出即使声称为模拟数据，也不进入发布包；其许可与第三方内容权属仍为 **TO-VERIFY**。

### 7.2 当前实现风险

**VERIFIED**：本地实验骨架的 `ProviderGateway` 当前会把完整 request/response 写入调用账本，episode schema 也保存逐轮输入与回复。该设计适合纯合成调试，但若接入真实日志会形成高敏感明文副本。

因此：

- **CONSERVATIVE-DEFAULT**：任何真实或可关联个人的内容一律不得进入该 gateway、ledger、manifest、测试夹具、异常字符串或模型上下文。
- 在只含合成数据时，也应使用随机 run ID，避免姓名、账号、邮箱、平台 ID 和访问 token。
- 报告默认只输出聚合计数；逐轮文本不进入论文附录、PR、artifact 或公开 issue。

### 7.3 外部 API

任何外部模型调用前，以下均为 **TO-VERIFY**：服务商是否训练使用输入、默认/零留存期限、日志删除机制、数据地域、子处理者、人工访问、DPA、事故通知和账号级 retention 配置。

在这些项目形成可归档证据前：

- 纯本地 FakeProvider 可用；
- 合成数据调用真实 API 也暂缓；
- 真实聊天日志永不发送给第三方 API，不能用“已脱敏”替代审批，因为自由文本可能被重新识别。

## 8. IRB / 伦理审查升级条件

**VERIFIED**：论文 Appendix E 明确说，未来公共或临床部署需要新的 IRB 审查和正式伦理监督。论文原实验的纯模拟设计不能自动覆盖我方未来工作。

出现以下任一条件即停止实验并提交机构伦理办公室作正式判定；研究团队不得自行宣布“无需 IRB”：

1. 招募、观察、访谈或让任何真人与系统交互，包括内部试用、众包标注和可用性测试；
2. 使用真实聊天、客服记录、导出 trace、平台账号数据，或任何可关联个人的历史数据；
3. 涉及患者、未成年人、心理脆弱群体、自杀/自伤内容或其他高风险人群；
4. 向真人提供情绪、心理健康、诊断、治疗、危机或行为建议；
5. 从研究分数推断个人风险、触发人工联系或改变真实服务；
6. 在公共平台、临床流程或真实 companion 产品中部署；
7. 人类审阅者需要接触敏感逐轮内容，或数据将跨机构/跨境共享；
8. 研究方案从纯合成压力测试改变为真实世界效果、依赖、长期关系或安全事件研究。

即使机构认定不构成人体研究，仍需完成数据保护、安全、平台条款和内容风险审查；IRB 不是许可证或 ToS 的替代物。

## 9. 当前裁定与解锁条件

### 当前允许

- 本地、离线、纯合成的独立工程骨架与 FakeProvider 测试；
- 通用数值计分、消息路由、触发节拍和聚合统计；
- 引用论文方法与局限，不复制受限表达性材料。

### 当前禁止

- push、公开 artifact、发布包或演示服务；
- 复制/分发上游源码、CCD、量表全文、完整计分映射、高危 prompt 原文；
- Character.AI 接入或账号 token 获取；
- PANSS arm；
- 导入或发送真实聊天日志；
- 对真人、患者或人群作临床外推。

### 发布前必须全部满足

1. 上游代码和每类数据资产取得明确、可归档且适用于目标版本/用途的许可，或证明发布包完全为独立实现且不含受限材料；
2. PDI、PANSS 及实际使用的 PHQ-9 版本完成逐项许可核验；PANSS 取得书面许可；
3. Character.AI 链路保持移除；若未来改变，须有平台书面允许；
4. 发布扫描证明不含题目、CCD、高危原文、token、真实日志和逐轮敏感输出；
5. 数据留存、删除、访问控制、服务商条款和 IRB/非人体研究判定形成记录；
6. 所有结果以“模拟、敏化协议下的探针读数”报告，不作真人或临床外推。
