## §2 口令表（对 AI 说什么）

| 你说 | AI 做 |
|---|---|
| "开始 EX-01"；前一练习已交卷并完成批改后，才可说“开始 EX-02/03” | AI 先核验顺序门禁，再起表 90 分钟 + 排 80/90 分钟提醒，然后沉默陪跑；不满足门禁时不跳题 |
| "hint" | 从 H1（方向）开始给，最多到 H2（定位）——**本包没有 H3**，别硬要 |
| "提交 EX-03 翻译，进入攻防" | 冻结前 50 分钟的五条翻译；只有此后 Grader 才开封 EX-03 对应反例库，并逐条出招 |
| "交卷" | EX-01/02：停表后进入批改；EX-03：攻防与复盘完成后收卷。随后出复盘要点并记 LEDGER |
| "暂停" | 记录用时与断点，下次"继续 ra30"接着走 |
| "继续 ra30"（新窗口） | AI 读 KICKOFF + LEDGER 末行 + 交接档 §13 恢复现场 |
| "SBPN 论文读完了：<精读产物路径>" | AI 核验至少一篇目标论文的精读产物及 file + 定义编号；通过后才解锁 EX-04 |

## §5 Agent 分工（你只需要记住谁在什么时候出现）

| 角色 | 什么时候出现 | 做什么 | 绝不做什么 |
|---|---|---|---|
| 主控 | 全程 | 核门禁、计时、记录断点、最后写 LEDGER | 代你建模、提前开封 |
| Coach | 你主动说 `hint` 时 | 依次给 H1、H2 | 给 H3 或完整答案 |
| Grader | 你冻结/交卷后 | 按 rubric 批改；EX-01 对账，EX-03 出反例 | 改写你的原答案、读别题密封件 |

| Literature Scout | 可与 EX-01~03 并行 | 走合法渠道找 SBPN 原文、验文件与哈希 | 绕付费墙、代你精读、拿 SBTPN 冒充 SBPN |
| Archive Auditor | 每个 EX 收账后 | 查公开控制面、文件和索引是否一致 | 读取密封正文、直接改共享账本 |

Agent 可以并行做文献获取或公开档案审计，但**不能并行代做另一个 EX**。你一次只做一个练习，包内严格 EX-01→02→03。
