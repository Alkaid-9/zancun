## §2 练习序列

### 阶段 1（现在可做）

### EX-01 · 对自己的设计做批判性精读（90 min）

**题面**：戴上"恶意审稿人"帽子重读自己的 README，产出三张清单：
1. **隐含假设清单**（≥5 条）：文档没明说但协议正确性依赖的前提。提示维度（只给维度不给答案）：时序与时钟、操作原子性、并发交错、失败时点、外部组件行为。每条写"假设不成立时哪一段协议先坏"。
2. **最脆弱不变量**：五条不变量（去重/游标/清账/append-only/物化）按"最容易被并发交错打破"排序，第一名写 300 字论证。
3. **未定义行为清单**：文档没覆盖的输入/时序组合（例如某两个操作恰好同时发生时协议说了怎么办吗）。
**交付物**：`EX-01/EX-01_批判精读.md`（三清单）。
**hint**：H1“想想两个窗口同时做 X 时”→ H2 指出一个具体交错场景；**本包 H2 封顶，不提供 H3**。
**rubric**：假设的"击中要害"度 50%（挖出的假设是否真的载重）· 脆弱性论证质量 30% · 自我批判诚实度 20%（能不能对自己的得意设计下狠手——Grader 特别看这个）。
**Setter 需求**：有——Setter 独立做同题（它没有作者滤镜），密封三清单。对账的意义：**你和 Setter 各自挖到对方没挖到的，交集是真要害，差集是视角教材**。

### EX-02 · Petri 网建模（90 min）

**题面**：
1. （0-20 min）学：库所/变迁/token/使能/激发/不变式，5 行自查笔记（能答"token 在你的模型里代表什么"才算过）。
2. （20-80 min）建模：**写路径**（多窗口→共用缓冲→分组→压缩→两阶段提交落账）与**读路径**（游标→增量注入→物化）各一张 PN。硬要求：① 每个库所写清 token 语义（一个 token = 一条消息？一个窗口的写权？）；② 并发点显式建模（多窗口同时写缓冲在图上长什么样）；③ 两阶段提交的"崩溃损耗上界 = 一个缓冲阈值"（README 原文承诺）要能在模型上指出对应结构。
3. （80-90 min）自查：哪些地方你"画了个框但说不清 token 怎么流"——标出来，这是诚实的存疑区。
**交付物**：`EX-02/EX-02_模型.md`（mermaid/graphviz 图 + 每个库所变迁的文字定义 + 存疑区）。
**hint**：H1“你的缓冲阈值在模型里是 token 数还是别的”→ H2 给一个子结构的建模示例（非本协议的通用例）；**本包 H2 封顶，不陪走本协议的 token 流**。
**rubric**：PN 语义正确性 40%（不是画流程图）· 并发点表达 30% · token 语义自洽 20% · 存疑区诚实度 10%。

### EX-03 · 五不变量 → 形式性质 + 反例挑战（90 min）｜首铸卡：形式性质翻译法

**题面**：
1. （0-50 min）逐条翻译：五不变量各写成基于 EX-02 模型的可判定表述（不变式："任意可达标记下，库所 X 与 Y 的 token 数满足…"；或可达性："不存在从初始标记到坏状态 Z 的路径"）。允许发现"我的模型表达不了这条"——那就记录模型的表达力缺口（这是重要发现不是失败）。
2. （约 50 min）先对 AI 说“提交 EX-03 翻译，进入攻防”，把五条翻译写入交付物并冻结该版；**只有此刻之后** Grader 才可开封对应反例库。
3. （50-85 min）**反例攻击轮**：Grader/Setter 每条抛一个具体交错场景（“窗口 A 在压缩落账的两阶段之间，窗口 B 读取，你的性质 3 还成立吗？”），你逐个回防：证明反例不适用 / 承认击穿并精确修补表述 / 承认协议本身有洞（若真发现协议级问题——恭喜，这是可以回馈到文档 v2 的真产出）。
4. （85-90 min）复盘：翻译中最难的一步是什么。
**交付物**：`EX-03/EX-03_性质与攻防.md`（五条翻译 + 攻防记录）。
**rubric**：翻译的可判定性 40%（写出来的东西能不能机械检查）· 回防质量 40% · 协议级发现加分 20%。
**铸卡点**：《形式性质翻译法》v0.1（自然语言承诺 → 识别量词与时序词 → 选表述形态（不变式/可达性/时序性质）→ 绑定到模型元素 → 找反例自测）。
