## 1. 不是“一篇在学，三篇放着”

更合适的课程结构是：

> 一篇主干 + 一篇横向对照 + 一篇实验方法论 + 一篇纵向后继。

| 论文 | 处理方式 | 主要训练能力 | 深度 |
|---|---|---|---|
| EdgeIM | 主干，拆到能独立重建 | DFG、sampling、representation、distributed discovery、IM、claim 边界、算法审计 | 5/5 |
| sigRank | 横向方法对照 | sampling 优化对象、预算、ranking、model-quality objective、fair comparison | 4/5 |
| Ground Truth Approach | 实验与证据方法论 | ground truth、noise/deviation 区分、实验能支持什么 claim | 4/5 |
| CrossEdgeIM | 纵向后继 / genealogy | EdgeIM 后来往哪里长、架构为什么变、旧瓶颈解决后出现什么新瓶颈 | 3/5，先浅后深 |

因此不是平均用力，而是：

\[
\boxed{\text{EdgeIM 是“学习对象”，另外三篇是三个观察镜头。}}
\]

## 2. EdgeIM：研究对象 ownership 的主干

EdgeIM 的主干地位不变。它同时满足三项条件：

1. 是当前最直接的鲁法明署名对象；
2. 篇幅和方法边界允许真正拆穿，而不只做摘要级理解；
3. 包含后续大量研究概念的接口。

主链是：

\[
\text{event log}
\rightarrow
\text{sampling}
\rightarrow
S/E/R
\rightarrow
DFG
\rightarrow
\text{distributed aggregation}
\rightarrow
IM
\rightarrow
Petri\ Net
\]

论文三阶段候选结构是 preprocessing + feature-preserving sampling、edge-side feature construction、central aggregation/model discovery。

EdgeIM 的目标不是“读懂摘要”，而是从 paper comprehension 走到 research object ownership：

- 不看论文重建 Algorithm 1；
- 解释每一个 representation 为什么存在；
- 自己造反例；
- 改一个 assumption 后预测哪里会坏；
- 重实现最小版；
- 审查其 claim；
- 用其他方法攻击其设计选择。

当前正在处理的 DFG support/weight、Stage 1 invariant 与后续 IM cut 都属于主干。

关键接口是：Algorithm 1 按 `S/E/R` 集合覆盖决定是否保留 trace，而 Stage 2 从过滤后的 `D'` 重新累计关系次数。集合 support 的保存与 weight/frequency 的变化必须分别理解。

## 3. sigRank：不是第二篇主干，而是 EdgeIM 的 sparring partner

sigRank 不应像 EdgeIM 一样从第一页逐句教学。它的功能是在用户真正理解 EdgeIM sampling 后，把另一种 sampling philosophy 摆到旁边。

EdgeIM 的选择问题是：

> 这个 trace 是否带来了以前没有的新结构 feature？

若没有新增 coverage，就丢弃。

sigRank 的候选选择问题是：

> 在给定 sampling ratio 的预算下，哪些 trace 更值得保留？

它为 trace 计算 significance，再按预算选择高价值 trace。

二者形成三组核心张力：

\[
\text{coverage} \quad vs \quad \text{importance}
\]

\[
\text{endogenous sample size}
\quad vs \quad
\text{fixed sampling ratio}
\]

\[
\text{structural preservation}
\quad vs \quad
\text{downstream model quality}
\]

sigRank 值得学习的部分还包括：它把 sample log 用于 process discovery，再用原日志评价发现模型的质量；用户输入指出，论文展示了相同 15% sample ratio 下模型质量可以相差很大。该数字和图表必须回到原文核验。

这篇专门训练：

> 不要把方法自己的 surrogate objective 当成最终 objective。

EdgeIM 保存 `S/E/R` 后，还必须追问最终 process model 的 fidelity 或 quality。sigRank 的角色不是取代 EdgeIM，而是迫使我们区分 sampling surrogate 与 downstream consumer。

## 4. Ground Truth Approach：不是学新算法，而是学习凭什么下结论

这篇与前两篇不在同一训练维度。它的问题是：真实 event log 虽然来自真实系统，但 underlying process 往往未知。

若一个算法发现模型 `M`，即使 fitness/precision 很高，也不能自动知道：

- 模型是否恢复正确；
- 缺失 behavior 是算法造成还是日志原本没有；
- deviation 是真实业务变化还是 logging error；
- 测到的是 robustness、fidelity、conformance 还是其他量。

其核心世界生成链可写成：

\[
\text{initial ground-truth model}
\rightarrow
\text{known behavioral deviation}
\rightarrow
\text{deviating model}
\rightarrow
\text{recording errors}
\rightarrow
\text{imperfect event log}
\]

ground truth 在生成过程中被保留，才可能判断 process-mining technique 的输出在哪里对、哪里错。

对我们的直接作用是约束以下常见错误：

```text
提出“EdgeIM sampling 会不会扭曲模型？”
-> 在 BPIC/Sepsis 上跑一次
-> 得到 F-measure 0.91
-> 宣布假设成立或不成立
```

这条链不够，因为 underlying model 未知，sampling effect、日志缺失、behavioral deviation 与 recording error 可能混在一起。

用户输入还记录，作者把 process-mining assessment 拆为 correctness/validation、quantitative and qualitative evaluation、reliability/reproducibility、robustness、performance/scalability、usability 等层。具体分类与原文措辞需核验，但其研究训练价值已经清楚：

> 学会构造一个真正击中 claim 的 world。

这与“verifier/environment 本身也要验收”共享同一个 Research Operator。该文应成为 Experimental Design / Claim-Evidence 教材，而不是另一份算法背诵任务。

## 5. CrossEdgeIM：学习下一篇是怎么长出来的

CrossEdgeIM 的角色是 genealogy，而不是重学一遍 DFG。

用户输入给出的 predecessor 关系是：EdgeIM 在 edge node 构造 local features，再由 central node 聚合 global model，主要面向 single-organization IoT；CrossEdgeIM 把对象扩展到跨组织 IoRT/robotic behavior discovery。

候选架构变化是：

```text
EdgeIM
case filtering
-> edge feature
-> central global DFG
-> central discovery

CrossEdgeIM
activity node 在线维护 feature
-> delta DFR / delta S / delta E
-> organization-level DFG
-> organization-level model discovery
-> central merge of local models
```

用户输入指出，CrossEdgeIM 把 activity node 当作最小 edge-computing unit，维护直接跟随关系并向 organization node 发送增量更新，再由 organization node 构造自己的 DFG。具体字段与消息语义须以原文为准。

最适合训练的链是：

```text
predecessor
-> residual bottleneck
-> redesign
-> new residual
```

候选 genealogy：

```text
EdgeIM：distributed data 很大，避免把全部日志搬到中央
->
CrossEdgeIM：机器人系统持续流式、跨组织、多自治实体
-> computation 继续下沉，模型分层
->
下一问：真正跨组织 interaction 如何表示？
```

这里训练的是 idea genealogy + residual bottleneck，也就是“他们如何想到下一篇”。

CrossEdgeIM 没有鲁法明署名，所以对“鲁老师本人产出”的直接权重低于 EdgeIM；但它属于高度相关的公开合作谱系，可用于理解该圈子如何向 robotics、distributed behavior 和 multi-agent-like systems 扩展。

## 6. 四篇形成一个十字架

```text
                         CrossEdgeIM
                         【往后长】
                            ^
                            |
                         genealogy
                            |
sigRank  <------ compare -- EdgeIM
【横向方法】                【主干】
                            |
                         evaluate
                            |
                            v
                  Ground Truth Approach
                    【证据/实验地基】
```

四篇分别回答：

1. EdgeIM：方法是什么？
2. sigRank：是否有另一种解决方法，设计选择差在哪里？
3. Ground Truth：如何知道比较真正说明了目标问题？
4. CrossEdgeIM：方法做完后，路线为什么继续生长？

对应四种科研能力：ownership、comparison、evidence judgment、genealogy reconstruction。

## 7. 不四篇并行硬啃，而是在节点上打开镜头

正确节奏仍是 EdgeIM 深挖为主，但每到合适节点就打开对应镜头。

### Algorithm 1 / DFG 后

短开 sigRank，回答：它为什么不按 coverage 选择？

此时只比较 selection philosophy，不完整拆实验。

### EdgeIM sampling/representation 深入后

再次打开 sigRank，比较 coverage、importance、ratio、budget、downstream model quality 与 fair comparison。

### 进入实验设计时

打开 Ground Truth Approach，回答 synthetic experiment 怎样才真正拥有 ground truth，怎样分开 behavioral deviation 与 recording error，指标如何对齐 claim。

### EdgeIM 全链与 IM/Petri net 理解后

打开 CrossEdgeIM，做一次完整：

```text
predecessor -> residual -> redesign -> new residual
```

三篇不会打断主线，也不会被推成“以后再说”。

## 8. 为什么不四篇都逐页精读

四篇的训练目标不同：

- EdgeIM 要建立 research object ownership；
- sigRank 要形成方法对照与 objective sensitivity；
- Ground Truth 要形成实验世界和 claim-evidence 判断；
- CrossEdgeIM 要形成研究演化追踪能力。

用同一种逐页精读模板处理全部论文，会把课程变成“完成四份阅读笔记”，反而丢失三篇镜头的功能。

更接近真实科研训练的方式是：一篇建立 ownership，其他论文分别逼迫学习者比较、验证和追踪研究演化。
