## §2 · handoff 命名规则 (8-5 晚立)

### 2.1 单工作区日

```
YYYY-MM-DD__full-day-handoff.md       ← 主 handoff (新窗口必读)
YYYY-MM-DD__morning-window-handoff.md ← 副 handoff (历史, 不再主读)
YYYY-MM-DD__evening-window-handoff.md ← 副 handoff (历史, 不再主读)
```

**关键原则**:
- 一天 1 件 **full-day** = 主 handoff = 新窗口必读
- morning / evening = 副 = 历史档案(留作 audit trail,不反向引用)
- 命名带日期前缀, 按天排

### 2.2 多工作区日 (未来可能)

```
YYYY-MM-DD__N-<slug>__handoff.md       ← N = 1, 2, 3... (当天第 N 个工作区)
```

例: `2026-08-06__1-evoagent-audit__handoff.md` + `2026-08-06__2-lu-email__handoff.md`

### 2.3 跨天工作

- 主档留在"最后一天"(`2026-08-07__full-day-handoff.md`)
- 前置天只写 `task_log` 不写 `handoff`
