# 进组材料本人证据确认单

日期：2026-09-20。状态：`FUTURE-GATE / OUTREACH-FROZEN / NOT-CURRENT-TODO`。

当前不填写本表。它只在用户完成学习与本人产物、并重新授权材料定稿后使用；届时只填写自己能够确认的内容。不要为了“完整”补造，也不要粘贴隐私数据、密钥或原始交互日志。

| 字段 | 是否必须 | 需要的最小证据 | 外发规则 |
|---|---|---|---|
| 姓名、学校、专业、联系方式 | 定稿必需 | 本人确认；学校英文名另核官方写法 | 不从旧草稿或网名推断 |
| 入学/预计毕业时间、GPA | 可选；写了就必核 | 学籍信息或本人确认 | 不按“2026 大三”倒推年份 |
| EdgeIM 当前学习进度 | 面谈提到时必需 | [当前路由](../CURRENT_LEARNING_ROUTE.md)的 R1–R6 对账；本人笔记/代码路径 | 写“正在学习/已完成具体动作”；未验收不写 PASS/OWNED |
| 对 EdgeIM 能讲清的问题 | 建议至少一项 | 一段本人解释、一个手算/反例或可定位笔记 | 只说证据覆盖的层级，不借课程答案冒充掌握 |
| EvoAgent 本人贡献 | 可选 | 具体文件/commit/修改、本人运行记录、AI/团队边界 | 运行现成代码写“运行/复核”，不写“设计并实现” |
| XES/GraphML/PM4Py demo | 可选 | 新复跑命令、环境、退出码、stdout/stderr、产物；本人能解释 | 区分离线规则流水线与四条合成轨迹；不称真实 LLM 实验 |
| 长期人机交互平台 | 可选 | 本人负责模块与运行范围 | 对外前另核隐私、许可和脱敏；不默认写数月/数千轮 |
| MindBridge | 可选 | 本人具体贡献、数据来源、训练/评测真实记录 | 未本人完成的微调、部署、指标删除或改为团队/Agent 工作 |
| MCM 等竞赛 | 可选 | 证书/结果页、团队分工、本人代码或说明 | 奖项与本人贡献分开；不默认沿用 LOC/核数 |
| GitHub/公开代码 | 可选 | 可访问 URL、仓库身份、本人贡献与公开许可 | 未公开不写“已开源” |
| 数字与性能 | 可选；写了就必核 | 固定版本、测量命令、结果与日期 | 旧 8,800/43/2,400/4,470/23 核等不得仅凭旧稿恢复 |
| AI/Agent/队友协助 | 有协助时必需 | 说明生成、修改、复核和本人接管范围 | 不必贬低项目，但必须准确归属 |
| 附件隐私与许可 | 带附件时必需 | 数据来源、许可、脱敏检查和最终文件清单 | 没有通过就不附；可只带学习笔记 |

## 未来解冻后的定稿裁定

每条候选句只选一个状态：

- `KEEP — USER-VERIFIED`：本人确认且证据可定位；
- `WEAKEN — USER-REPORTED`：本人记得但当前证据未闭合，只写有限事实；
- `PLAN`：尚未完成，明确写计划或学习目标；
- `OMIT`：与场景无关或证据不足，从最终稿删除。

未来验收：先有用户重新授权；再要求邮件、一页纸、简历与附件对同一经历的归属、数字和时态一致，内部说明与未填方括号已删除，用户看过最终副本并另行决定是否发送。
