# 研究提案：LLM 多智能体系统故障传播的 Petri 网展开分析与概率根因定位（T1+T4）

> 日期：2026-08-12 ｜ 状态：草案 v0.1（T-PROP）｜ 视角：**防御与可靠性**——只做建模、检测、隔离、归因，不含任何攻击方法或利用步骤；对抗性文献仅作防御对象引用。
> 上游证据：`W1_lu_side/LU_SIDE_MAP.md` §2/§3 ｜ `W2_sun_side/SUN_SIDE_MAP.md` §3 ｜ `bridge_scan_2026-08-12/D_fm_x_mas_redblue.md` §4/§5 ｜ 8-09 设计档 §3.2/§4.5

## 0. 一句话

把 LLM 多智能体系统（LLM-MAS）的故障/污染影响跨 agent 传播建为**分层着色/随机 Petri 网**：用网展开（unfolding）求影响可达集与最小隔离集（T1），用 SBPN/SBTPN 概率时序推断做根因定位（T4），为图归因方法补上"并发/循环/确定性可回放"的形式化骨架。

## 1. 问题与动机

LLM-MAS 中单个 agent 的错误输出、被污染记忆或失效工具会经消息、共享内存、任务依赖跨 agent 扩散（AgentWorm 实证了自传播风险，[arXiv:2603.15727](https://arxiv.org/abs/2603.15727)，本提案仅取其防御面）。现有防御研究有三个缺口：
① **归因侧**：Securing MAS 的节点贡献反传归因 NCB（[arXiv:2510.19420](https://arxiv.org/abs/2510.19420)，ICML 2026）假设 DAG 交互与末端决策，覆盖不了循环协作与并发交错（W2-A §2 明示）；
② **监控侧**：逐消息本地监控会漏组合性危害（[arXiv:2607.11751](https://arxiv.org/abs/2607.11751)），LTL/自动机监控存在覆盖上界（[arXiv:2608.01388](https://arxiv.org/abs/2608.01388)）；
③ **语义侧**：8-12 查新确认 FM 顶会 2025-26 无"验证 agent 行为"条目，PN/DES×影响传播零命中（D 报告 §4）。
PN 的偏序并发语义与展开的确定性可回放恰好同时补三个缺口。

## 2. 研究问题

- **RQ1（建模）**：LLM-MAS 的主体/能力/依赖/风险状态四层结构能否被着色 PN 忠实且可判定地编码？"忠实"以对真实 trace 的重放拟合度衡量。
- **RQ2（可达与隔离，T1）**：给定初始故障标识，影响可达集能否用有限完全前缀高效计算？最小隔离集（切断传播所需停用的最小信道/权限/门禁集合）能否规约为展开前缀上的最小割问题？
- **RQ3（根因，T4）**：给定异常终态与部分可见日志，SBPN/SBTPN 概率+时序推断能否输出**可复算**的根因后验排名，并在循环协作场景显著优于 DAG 归因？

## 3. 方法

- **M0 分层建模（铁律，先于一切 PN 构造）**：按 8-09 设计档 §3.2 分别定义**主体层**（agent 实例与角色）、**能力层**（工具/权限集合）、**依赖层**（消息信道、共享内存读写、任务队列）、**风险状态层**（主体×资源的健康/降级/污染状态机）。PN 元素由四层联合导出：库所承载 agent 局部状态、工具状态、共享内存单元、任务阶段；变迁对应消息收发、工具调用、门禁判定；token 着色编码消息可信度与来源链。**严禁"agent=库所"机械映射**（8-09 §4.5 假融合风险第 2 条）。
- **M1 展开分析（T1）**：分层网 → 有限完全前缀（McMillan 前缀 + ERV 改进）→ 影响可达集 = 前缀中污染 token 可达的条件集合；最小隔离集 = 前缀因果结构上分离故障源与关键资产的最小割（先 ILP 精确解、后贪心近似求规模化）。展开天然携带偏序因果，输出附**可回放执行**——审稿人可确定性复验（W1-C 确认主流预测式检测重演靠随机调度，此为硬卖点）。
- **M2 概率根因（T4）**：同一分层结构上为变迁装随机延迟/概率权（SBPN/SBTPN，参数从日志估计），以部分可见异常事件为观测，用染色回溯+概率推断输出根因后验；与 NCB 在同场景对照。
- **M3 闭环**：隔离集 → 门禁/权限干预建议 → EvoAgent Canary/Shadow 验证（对接 8-09 O→D→M→I→V 闭环）。

## 4. 数据

- **EvoAgent trace**（自有平台：trace_events / agent_messages / checkpoints / DLQ），注入已知故障源作 ground truth——只注入抽象失效/污染标签，不实现攻击载荷；
- **公开 MAS 基准**：AgentWorm 论文的拓扑/场景配置（仅取拓扑与防御评测，[需验证：工件是否开源]）；Securing MAS 所用基准（[需验证：数据集清单]）；
- **合成网族**：参数化生成含循环协作、并发扇出的拓扑，做规模扫描与控制变量。

## 5. 基线

① 普通有向传播图 + BFS 可达/最小点割；② 静态调用图（无状态无并发语义）；③ 平坦基础 PN（无分层无着色，即"agent=库所"反例组）；④ 根因侧：NCB 图归因、LLM-as-judge 归因（TrajAudit 类）。
指标：可达集精度/召回（对照注入 ground truth）、隔离集大小与阻断率、根因 top-k 命中率、循环场景增量、展开前缀规模 vs 状态空间规模。

## 7. Kill criteria

- **K1**：循环/并发场景下 PN 展开的可达精度或隔离集质量对基线①无统计显著增量 → T1 降级为 T3 值流路线（FUSION_ROADMAP 阶段 2 既定预案，2027-08 检查点）。
- **K2**：四层建模对 EvoAgent trace 重放拟合度 <80%（结构性失真）→ 回炉 M0，冻结 M1/M2。
- **K3**：SBPN 参数无法从日志稳定估计（bootstrap 区间不收敛）→ T4 退为确定性染色回溯（仍可独立发表）。
- **K4**：月度快查发现同题抢发（PN/展开×LLM-MAS 传播）→ 触发维护 runbook §5 差异化重排。

## 8. 风险与缓解

- **状态爆炸**：着色+风险状态层使网膨胀 → 分层折叠、对称约简、只展开污染影响锥。
- **语义鸿沟**：LLM 非确定输出难离散化 → 风险状态层只建可观测证据（消息哈希、工具返回码、reviewer 判定），不建模 LLM 内部语义。
- **数据外部性**：外部工件可得性未证实（§4 两处[需验证]）→ EvoAgent+合成网自持底线。
- **窗口风险**：Bollig 组占偏序监控位、SMU Jun Sun 组 5 个月一迭代（W2-B §5）→ 2026-12 前 toy+arXiv 占位。
- **合规**：全程防御视角；实验只注入抽象故障标签，不产出可复用的攻击组件。
