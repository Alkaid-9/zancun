## 三、声音 A(更谦逊)· 全文

# Research Statement · [姓名]

**一、身份定位。** 我是[学校][专业]的[身份表述],将于 2026 年 9 月进入[课题组],希望以本科生科研的方式在组里踏实跟随学习。我感兴趣的方向是 LLM agent 运行时安全与形式化方法的交叉:用概率模型检验为长期运行的交互 agent 构建可量化的行为护栏。围绕这个方向我做了一些准备:自建并持续运营一个长期人机交互平台,积累了数月纵向数据,盼望能在老师们指导下派上用场。

**二、已有工作(三件套)。** 以下是我练手做的三件小事,恳请老师们指正:

- **EvoAgent**:自进化 PR 审查多智能体平台(约 8,800 行 Python、43 个单元测试),含 harness 生命周期管理、LangGraph 编排与评测门禁下的提示词进化闭环;实现了 agent 轨迹到 XES 1.0 事件日志与 GraphML 交互图的同源双出口,分别通过 PM4Py 与 networkx 的读取验证。
- **自建长期人机交互平台**(FastAPI):向量记忆管线、显式情绪状态引擎、定时主动行为、WebSocket 多端同步;已持续运行数月,沉淀数千轮经脱敏的纵向交互日志。
- **MindBridge**:校园心理支持多智能体系统;基于 Qwen2.5-7B 以 2,400 条合成心理问答做指令微调,量化为 q4_k_m GGUF 经 Ollama 本地部署;事件驱动 5-agent 协作 runtime,混合检索(向量 + BM25),含 Recall@K/MRR/NDCG 评测。

**三、研究兴趣。** 我最希望跟随学习的题目是**面向长期人机交互 agent 的概率行为护盾**。读文献时我注意到,这类 agent 存在现有护栏尚未覆盖的失效模式:单条消息均无害,但多轮累积轨迹越界(边界侵蚀、依赖强化、人格漂移);实证研究(INTIMA;MIT/OpenAI 四周 RCT)提示风险普遍,而现有防护以 prompt 规则与 LLM-judge 为主,缺乏量化承诺。我初步的想法是沿用文献中的成熟管线:谓词抽象为符号状态、从执行 trace 学 DTMC、以 PAC 区间提升为 iMDP、离线综合干预策略并压缩为决策树、运行时查表分级干预;我明白,这只是在谓词抽象、日志完备性与模拟用户评测的明确假设下给出带 PAC 区间的概率预测,并不构成端到端的形式保证。在我 2026 年 8 月的调研中,概率护盾工作(ProbGuard,原名 Pro2Guard、ASE 2026;ShieldAgent)的评测域集中在具身、自动驾驶与 web 场景,未见长期交互域带概率保证的同类护盾工作;我的平台数据或许能提供一点起步条件——是否可行、怎么走,盼多听老师们的意见。

**四、近期计划(2026.09–12)。** ① 复现打底(9–10 月):先跑通 ReGA 的公开实现,整理一页复现简报向老师们汇报;ProbGuard 的官方仓库我实际拆读过,目前处于重构中、暂不可整仓跑通,打算改以论文与代码对照的方式定向精读跟进;② 域建模(10–11 月):我已试着把 INTIMA 行为分类学改写成 16 个带时间窗的可执行谓词(谓词表 v0),接下来在老师指导下做双人标注、报告一致性 κ,并从平台导出脱敏 trace,打通"符号 trace → DTMC → 越界概率验证"的最小闭环;③ 12 月前:若进展尚可,在老师指导下整理成 workshop/arXiv 短文。伦理边界:不做真人实验,评测采用模拟用户范式;自有数据仅用于模型学习,不作评测主数据。

**三、研究兴趣。** 主线:**面向长期人机交互 agent 的概率行为护盾**。动机:此类 agent 存在单条消息均无害、多轮累积轨迹越界的失效模式(边界侵蚀、依赖强化、人格漂移),实证已确认风险普遍 [1][2];现有防护(prompt 规则、LLM-judge 监控 [3])无量化承诺;概率护盾管线 [4][5] 的评测域集中于具身、自动驾驶与 web,在我 2026 年 8 月的调研中未见长期交互域带概率保证的同类护盾工作。据此提出:

- **RQ1(域建模)**:已将 INTIMA 分类学 [1](31 类行为)改写为 **16 个带时间窗的可执行谓词**(谓词表 v0);该谓词集能否以可接受的标注一致性(κ)与覆盖率,把此域的越界轨迹表达为符号状态序列?
- **RQ2(预测增量)**:从 trace 学 DTMC [4]、以 PAC 区间提升为 iMDP [6],其越界概率预测相对 LLM-judge [3] 与 prompt-only,在提前量(轮数)与 AUC 上有无显著增量?
- **RQ3(干预权衡,可选)**:经决策树压缩 [7] 的分级干预(改写/冷却/降级),在"安全率 × 人格一致性"平面呈何种 Pareto 形态?

保证边界:仅在谓词抽象、日志完备性与模拟用户评测假设下,对可表达的越界轨迹给出带 PAC 区间的概率预测;执行链含 LLM,不声称端到端形式保证,保证止于符号模型层。

**四、近期计划(2026.09–12)。** ① 9–10 月:复现 ReGA [8] 的公开实现,产出一页复现简报;ProbGuard(原名 Pro2Guard)[4] 官方仓库现处重构状态,改为论文-代码对照的定向精读——两者与主线同构,复现与精读即预研;② 10–11 月:基于已产出的谓词表 v0(16 个)完成双人标注并报告 κ,导出平台脱敏 trace,打通"符号 trace → DTMC → 越界概率验证"最小闭环,回答 RQ1 的一致性与覆盖率问题;③ 12 月前:整理为 workshop/arXiv 短文占位。伦理:不做真人实验,评测采用模拟用户范式;自有数据仅作模型学习,不作评测主数据。
