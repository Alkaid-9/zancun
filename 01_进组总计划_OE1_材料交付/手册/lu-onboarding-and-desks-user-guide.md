## 3. 一次最短试用（新隔离现场准备好后）

1. 打开“学习与能力→基础与目标”。选择数三、英一、统计学、数据结构或鲁侧训练；可以没有论文，预填范围说明不是已保存对象。
2. 给同一知识分别建考试/科研要求，填写最低、正常、长期后续。留空就是未定义；确认要求不等于本人达标。
3. 从“继续”进入一个原问题工作区，留草稿和继续点，选知识及版本，再“保存原处并开补学分支”。暂放后重开检查是否能接上。
4. 保存一次尝试/反馈，写明输入、帮助程度、参与者和产物；不能把AI代码或强提示下成功记成独立完成。
5. 保存并返回原问题，核当时/当前版本区别。返回应恢复阅读身份与上下文，不覆盖后来改过的正文。
6. 另记研究判断，引用分支产物的实际版本；与个人表现分别维护。不知道/未运行toy就保留未知/候选。
7. “按版本选择导出”：勾选需要的正文/视图版本，先看预览与external_refs，再导出。未选的尝试正文不应跟出，原文件和历史字节并不包含。

试用只需集中告诉维护者：卡在哪个动作、期望/实际是什么、记录对应哪个版本、是否丢稿/回错位置。无需把所有机器测试再做一遍；需要教学补充的地方单独记，不用功能测试替代教学效果评估。

## 4. 来源、保存和返回的常见误解

| 看到的现象 | 应如何理解 |
|---|---|
| 来源选择可以搜索全部候选 | A已取消前300项截断；不代表每份原件正文都已索引或PDF已OCR |
| 普通文本显示“原段未定位” | 当前精确原段摘录还只是窄合同，不要把整份来源当作段落锚点 |
| 保存不确定或版本冲突 | 保留输入，查看实际记录和版本；不连续重试制造重复记录 |
| 返回后正文不同于离开时 | 查看当时/当前版；返程恢复上下文，不强制回滚后来的编辑 |
| 历史反馈版本未知 | 原记录未固定版本，不能自动补成最新版 |
| 导出成功 | 只证明所选内容生成，不代表来源附件备份、回链全成功或知识正确 |

## 5. 工作台现在怎么用

新增“工作台接续（人工）”入口：在原问题工作区保存正文→打开面板→填任务记录位置及产物/验收位置→复制交接文本，或“保存交接为普通记录”后填写操作者并保存。打开后再改正文也必须先保存；未保存会阻断复制和普通记录创建。复制前会刷新已读取版本与本页继续点。

将返回URL人工写进任务正本；执行、产物、验收仍按任务自身合同记录。URL按workspace/view/record精确返回当前内容，不恢复旧正文；版本是生成时观察值，非最新保证。缺身份、错工作区或错数据根明确报错，不按同名替换。面板未派发任何任务，空任务/产物仍为未填写；保存的note不是Task。详见[N3回执](/mnt/d/MyResearch/research-desk/acceptance/n3-TASK-20260915-013/RECEIPT.md)。

现阶段沿现有任务正本记录任务目的、输入、依赖、允许范围、预期产物和验收，执行结果回链到原问题；人工完成须写明人工，不能冒充程序自动接驳。普通笔记、提问和手推不必为此新增task。

WP0的两个GET端点只在隔离实现中有证据，本次没有验证live可用。任务ID签发成功也不证明新taskstore或跨台桥已经加载。涉及实际服务重启/部署必须按WP0原门，不直接从本手册复制一个启动命令绕过。

工作台记录“任务交付”，科研台判断“证据说明什么”，学习台记录“本人能做什么”，三者不互相自动变绿。

## 6. 进组使用与收尾

先用补充计划确定下一学习动作及证据缺口，再引用到pitch/简历/一页纸。未核来源、未独立完成、尚未运行的实验都保留明确边界。此手册不发送材料、不安排与导师联系，也不改变本人考试年份或学习门。

结束时保存草稿/继续点、记实际阻断和下一动作、确认选定导出可读；只停止自己启动的服务。备份、复跑、提交和恢复由维护手册办理，不删除runtime或验收目录。
