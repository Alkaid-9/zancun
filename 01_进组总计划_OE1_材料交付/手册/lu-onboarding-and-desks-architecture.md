## 1. 三台分工与多层网络

科研台负责问题、假设、方法/路线比较和研究判断；学习台负责目标要求、学习动作、帮助条件、反馈/重做/复测及本人能力证据；工作台负责任务/执行/依赖/资源/交付接受与恢复。阅读和手推可以直接发生，不经过调度也有效。

这是多层网络，不是把一个无差别图加几种筛选。层之间可共享对象身份和产物，但关系含义、证据义务、修改权限与评价不同。七图是不同观察/工作视角，不能七个按钮指向同一列表就算实现。

| 语义层 | 对象/关系 | 对应要求 | 当前覆盖 |
|---|---|---|---|
| 专业知识 | 定义、前置、机制、组成、条件 | 能解释连接为什么成立及适用范围 | 有旧地图及局部关系；正式内容未建齐 |
| 目标要求 | 同知识对考试/鲁侧的最低、正常、长期后续 | 要求状态与本人表现分开，空白不冒充覆盖 | B已支持编辑与版本 |
| 研究认识 | 问题、假设、替代、主张、支持/反驳、未查面 | 来源/推理与竞争解释可追；未知不同于已反证 | B有问题与独立判断记录；完整语义网未完 |
| 科研方法与指导实践 | 配方、适用情境、采用、效果/失败 | “有指导条目”不同于“本次实际用过” | 旧指导入口/设计；C05完整使用链待做 |
| 对话/探索过程 | 问答分支、摘录、暂放、返回、来源当时/当前 | 对话父子关系不等于知识前置或论证支持 | B一次补学往返；精确文本摘录为提案 |
| 个人实践证据 | 尝试、提示、产物、反馈、重做、复测 | AI生成/辅助/独立分别记录，不自动评分掌握 | B有版本与条件；真实学习验收开放 |
| 执行协调 | 候选、任务、run、产物、验收、恢复 | 执行完成不等于研究正确/个人会做 | 既有任务正本；跨台调度桥待接 |

该表用于解释职责，并不新增七张数据库表。当前原生对象/关系结构不足以证明完整网络已实现；跨层影响只应先提示待复核，不自动把下游结论或用户状态翻转。

## 2. 一个产物如何在不同层使用

```text
鲁侧原问题/已知来源
  ├─ 补学分支 → 尝试/反馈的指定版本 → 返回原阅读上下文
  │                                  ├─ 个人证据：在什么帮助下做到了什么
  │                                  └─ 研究判断：支持什么、尚不能说明什么
  └─ 候选行动 → 人工任务/产物/验收引用 → 原问题（N3人工返回已交；自动桥待接）
```

前一条B已在合成DEMO贯通一次往返；后一条仅N3人工引用/普通note保存/身份返回已交，不派发或执行任务。同一产物可被两种评价引用，不复制正文，也不让评价相互自动继承。

## 3. 权威位置与系统边界

| 位置 | 管什么 | 不管什么 |
|---|---|---|
| MAS `progress/decisions`、task_logs、handoff、runbooks | 需求/决策、实际工作日志、恢复指针、操作说明 | 不作为应用源码仓或实际个人成绩生成器 |
| `learning/training/lu-edgeim-algo1` | 学习/论文训练合同、内容与真实记录 | 不被应用字段/演示替代；ownership-v3独占写域保留 |
| 独立 `/mnt/d/MyResearch/research-desk` | 原生JS界面、Python服务/对象语义与持久层 | A/B b54ea71、N3 c86f6d1、试用0b3a541已提交；不是完整工作台任务库 |
| 应用配置指定的content/registry与研究data/export根 | 资料登记、策展、对象/版本/关系/活动及导出 | 目录名runtime不证明可删除；导出不等于全备份 |
| WP0隔离树 `tools/dashboard/taskstore` | 日志权威的读取/事件写入，派生SQLite查询，M4 | 不为科研内容建立第二正本，不是已加载的live能力 |
| 原PDF/笔记/工作簿/享做导出 | 来源实体，按许可和选定范围只读引用 | URL或Markdown索引不等于原件已备份 |

WP0任务日志为事实源，其SQLite为派生索引；研究台自己的对象持久库承担另一职责。两种SQLite不能混为“都可重建，所以都可删”。

## 4. 当前实现与尚待实现的合同

- N3人工接续：原工作区→生成身份/观察版本/来源/继续点及人工任务路径→复制或现有note事务保存；同源URL经三个ID读取并返回当前内容。生成/复制不写数据、不派发；note仅在明确保存后持久化，不自动回写任务/研究/学习状态。错误身份显式失败；没有Task HTTP写端点、可达性探测或幂等执行承诺。实际语义与M1–M7见[N3合同](/mnt/d/MyResearch/research-desk/acceptance/n3-TASK-20260915-013/CONTRACT.md)。
- A：来源全集选择检索和保存反馈；不保证原件全文已抽取。
- B：goal/requirement、attempt/feedback、独立research decision、受限return_context、v2显式版本导出。入口和写语义见[B实际合同](/mnt/d/MyResearch/research-desk/acceptance/b-TASK-20260915-004/CONTRACT_DELTA.md)。旧未固定版本显示unknown，返回阅读上下文不回滚正文。
- 原段摘录：UTF-8文本整行区间、quote与本人正文分开、来源版本与片段身份、缓存/返回/导出检查，见[窄合同](../decisions/two-desks-delta-20260914/SOURCE_EXCERPT_PROPOSAL.md)。未施工；不承诺PDF页/OCR。
- WP0已有隔离实现的只读端点为`GET /api/tasks.json`与`GET /api/task/<id>.json`，不在GET里重建DB；本次没有验证live端点可用。任务写回/委派接口不能由这两个GET推导。
- 跨台桥候选字段为request/task/run与origin_ref、输入/产物版本；沿[工作台设想](../decisions/three-desks-v0.1/WORKBENCH.md)与WP0合同细化，不另建PlanWeave/TaskQuay双任务正本。

## 5. 内容建设与科研出口

四科最低/正常/长期要求与研究知识内容分别逐步补齐；已有三档编辑只是容器。当前问题所需的局部知识/来源/方法/个人产物优先形成可走通的路径，后续再扩跨论文、谱系、工业比较和影响复核。

短期鲁侧，孙/OAI为阶段参照；知识记录不以立刻服务进组或toy为前提。科学关系成立和本人已掌握独立。Transfer Card继续消费既有机制/假设/反例/比较资产，按原DROP/PARK/PROMOTE判定，不新增自动novelty评分。
