# RD-2 需求与施工追踪 v0.3

本表把v0.2的R01–R27映射到新施工编号。状态只描述当前证据，不计算项目完成百分比。`已有基础`不等于目标用户体验完成；`后续`表示已有明确包，尚未授权本轮实施。

## 1. 编号规则

- `UI-GLOBAL / UI-TOPIC / UI-WORKSPACE / UI-HOME`：页面或工作面，不叫P1/P2。
- `C00–C07`：本手册施工包。
- `ACxx-yy`：验收项。
- `LEGACY-Nx / LEGACY-WB1 / LEGACY-B1a / LEGACY-P1 / LEGACY-G1x`：历史交付或任务，保留证据但不作为新顺序。
- `X-*`：需另行启动的专项。

旧含义：v0.2 README的P1/P2/P3分别是全局／专题／工作区页面；three-desks的P1是保存恢复实施；Canvas的P0–P4是外部画布路线；初始蓝图P0–P5是另一条阶段表。以后回执必须带上面的命名空间，不再写裸`P1完成`。
