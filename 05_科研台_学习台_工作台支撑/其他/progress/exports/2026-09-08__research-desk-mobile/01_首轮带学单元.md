# 首轮带学单元：先完成一个具体动作

材料包：research-desk-mobile-20260908-v0.1。状态：教学准备，尚无用户作答。

这些是本次编写的教学构造，不是 EdgeIM、IM、SegLock 或其他论文的原例；不是研究实验，也不证明论文性质。若用户带来了当前课堂材料，优先续接真实问题，不必做下面所有单元。

## A. 递归：一次调用拿到什么、返回什么

目标：能说明一个小树上一次递归调用的输入、基础情形、子问题和返回。预计一段自然学习即可尝试，时间按实际理解调整。

先解释这个小世界：一棵树可以是单个叶子，也可以是包含两棵子树的分支。函数 `count` 只数叶子个数。叶子是没有子树的点；把一棵子树交给函数，就是对这个更小对象提出同一个计数问题。

定义：

```text
count(叶子) = 1
count(分支(左子树, 右子树)) = count(左子树) + count(右子树)
```

示范：`分支(a,b)` 有两个子调用，分别收到叶子 a 与 b，分别返回 1；当前调用收到这两个返回值后相加，返回 2。这不是把函数名当作魔法，而是把较大计数拆成两个更小计数。

现在的输入：

```text
分支(a, 分支(b,c))

        根
       /  \
      a   分支
          / \
         b   c
```

给带学 AI：先只问“最外层调用把哪两个对象交给两个子调用？”。等用户作答再展开下一步，不一次给出整张答案表。

可以逐步记录：

| 当前调用收到的对象 | 直接返回还是拆分 | 等待哪几个返回值 | 最后返回 |
|---|---|---|---|
| 用户逐步填写；未作答前留空 | | | |

后续按需引导：递归何时停；子调用结束后回到哪里；当前计算保留什么；为什么有限且无环的树最终能数完。若函数、输入输出、加法返回本身不熟，先在这个小世界讲清。

第一个变式：把叶子 c 换成 `分支(c,d)`，先预测哪些调用会变化，再手推。后续复用时可改为数所有结点，明确基础值和组合规则也变了；不要求首次一口气做完。

接回论文时：找到提供材料中一次真实调用的输入对象、终止条件、子问题构造和返回类型。数树只是帮助理解“调用结构”；没有 cut 定义与原文时，不从这个玩具例子推出 IM 或 EdgeIM 的规则。

可留下的菌丝连接：递归依赖函数输入输出；终止解释关联“更小的有限对象”；后续正确性解释可连到结构归纳。是否独立理解仍看用户真实作答。

## B. 关系与路径：相邻和可达为什么不同

适用：当前难点在 DFR、图或箭头的含义；也可作为以后复用的小单元。

小世界只有一条活动序列 `〈a,b,c〉`。定义“直接跟随”为这条序列中相邻的两个位置所对应的活动对。由这些活动对画有向边，再把沿一条或多条边能到达叫作存在路径。

先示范 a 后面紧跟 b，所以有一条 a→b 的边。只让用户接下一个问题：“按这个定义，a 与 c 是直接跟随吗？判断依据是什么？”之后再区分边与路径。

变式可增加另一条序列 `〈a,c〉`，观察关系集合如何变化。明确本例不涉及频率过滤、空轨迹或 cut 判定；需要这些内容时另给定义。

可连接集合、二元关系、图、路径和传递闭包。是否对应程序的先后关系，要先重建程序事件的定义，不能只因都画箭头就等同。

## C. P／O 的兴趣短探

只选一个小世界尝试，局部基础随动作解释。这里不替用户定研究题，也不替代已有 P／O 材料；拿到已有材料时继续使用其中的具体设定。

### P：锁与等待

约定：L、M 是互斥锁；每把锁同一时刻只能由一个线程持有；申请已被别人持有的锁时，线程等待，并保留自己已持有的锁；没有超时、强制释放或额外外部动作。

```text
线程甲：取得 L → 取得 M → 完成工作 → 释放 M、L
线程乙：取得 M → 取得 L → 完成工作 → 释放 L、M
```

先解释线程、一步调度和持有／等待。让用户推演“甲取得 L，随后乙取得 M”后的状态，再分别看两者下一动作。AI 每次只推进一小步。

后续可改变两线程申请锁的顺序，比较这个小例的执行；不把两线程两锁的观察升级为一般死锁检测算法。接原文时再问作者处理哪些程序、调度和同步语义，怎样定义检测目标、是否需要重演。

### O：批准对应哪个版本

约定：文档有 v1、v2 两个版本；一次批准只对当时明确指定的版本有效；发布某版本必须已有该版本的批准。

```text
编辑文档 v1 → 批准 v1 → 改为 v2 → 发布 v2
```

先让用户指出每个动作关联哪个版本；再判断最后一步是否满足约定，以及判断需要保留哪些信息。若只看“编辑—批准—编辑—发布”的活动名字，哪些信息消失了。

后续改变规范为“批准对所有后续版本有效”，观察结论为何变化；这说明判断依赖规范，不说明后一规范合理，也不声称发现了研究创新。接原文时明确对象、关系、约束与已有一致性方法。
