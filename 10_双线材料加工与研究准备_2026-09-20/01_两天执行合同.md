**五、可复用论文包的验收标准**

P2 包必须让后续执行者能够回答“原文说了什么、为何成立、在哪些条件下成立、我能抽取什么、哪些尚未验证”，而不是再读一遍长摘要。

| 组成 | 必须出现的内容 |
|---|---|
| 身份与来源 | 题名、作者、年份、版本、DOI/稳定链接；PDF 页码与印刷页码区分；来源哈希及取得时间 |
| 全文论证链 | 问题→假设→形式对象→机制→理论/实验支持→限制；按章节登记 coverage，主要贡献原文逐项编号 |
| 形式与推导 | 符号类型、单位、量词、前置条件；关键证明/推导的依赖、未证步骤、可反驳条件 |
| 实验与结论 | 数据、预处理、基线、指标、参数、随机性及威胁；明确哪些只是转录、复算或重新运行 |
| 资产接口 | 输入输出 schema、前后条件、不变量、异常、复杂度/成本、适用及禁止外推的范围 |
| 使用材料 | README、fixture、预期行为、运行方法或手工演算；可执行部分附真实运行证据 |
| 增量说明 | 旧资产已覆盖什么，本次纠正/补足什么；保留未解决项，不把重排版写成新增研究 |

理论论文可交经核验的推导、反例和机械可检查部分；没有代码的论文可交明确标记的机制重建。没有可执行主张时，运行项注明不适用及理由；有计算主张却缺实现时，登记缺口，不能借“不适用”取得同等完成度。

**E01：EdgeIM 的结构覆盖不保留频次，关联 TA2 / OA2 / AC03–05。**

输入 `frequency_pair.json` 含两个各 10 条轨迹的日志：

- L1：9 条 `[a,b,z]`，1 条 `[a,c,z]`。
- L2：1 条 `[a,b,z]`，9 条 `[a,c,z]`。

教学合同定义 `S` 为首活动集合、`E` 为末活动集合、`R_DF` 为直接跟随边集合。两者均须得到 `S={a}`、`E={z}`、`R_DF={(a,b),(b,z),(a,c),(c,z)}`；边计数分别为 `9,9,1,1` 与 `1,1,9,9`。在活动 a 处归一化的分支频率分别为 `.9/.1` 与 `.1/.9`。

只有确认原文定义一致，才把 `R_DF` 映射到论文 R。演示仅支持“这些集合不能确定频次”，不声称任何指定下游算法必然产生不同模型。Stage1 不添加 fixed K；Stage1 集合 R 与 Stage2 weighted R 分别说明。

接口接受非空字符串轨迹，拒绝空轨迹及非法事件；重复边按发生次数累加，不能每条轨迹去重。计数部分复杂度为 O(事件数)，排序展示成本另列。测试包括上述反例、重复活动以及非法输入。该统计器只是公开教学例；EI-01还必须包含原Algorithm 1机制实现和独立参考核验，不能以统计器替代采样算法。缺作者代码时，README 必须标为教学统计器/机制重建。

**E02：PNULock 配套锁语义练习，关联 TB1 / OB1 / AC03–06。**

输入为线程、锁及事件序列：

```text
T0 acquire L0
T1 acquire L1
T0 blocked_request L1
T1 blocked_request L0
```

教学假设为互斥锁、无超时、无抢占、请求阻塞且持锁不自动释放。输出应含等待边 `T0→T1、T1→T0` 及循环集合 `{T0,T1}`。对照输入删除最后一行，只能报告“未发现等待环”，不能报告整个程序安全。

主控实现事件合法性检查和等待环检测；对“同一锁同时由两线程成功持有”“对空闲锁声明 blocked_request”等输入返回语义错误。另写一个改变超时/释放假设的边界例，说明原结论为何不再直接适用。

这是明确约束下的配套教学模型，只计 A 线基础素材，不满足 OB1/PNU-01 的论文机制交付。B 必须另给“教学对象—PNULock 原文对象”的逐项映射和差异；若原文语义不匹配，保留为 CS 练习，并重新限定论文片段。等待图演示通过，不能替代 PNULock 算法正确性或工具复现。

**E03：SBPN 概率与依赖练习，关联 TB2 / OB2 / AC03–05。**

输入边际概率 `P(A)=0.2、P(B)=0.3`：

| 条件 | 交集概率 | OR 概率 | AND 概率 |
|---|---:|---:|---:|
| 显式独立假设 | 0.06 | 0.44 | 0.06 |
| 指定相关联合分布 | 0.15 | 0.35 | 0.15 |

相关情形的联合分布为 `P11=.15、P10=.05、P01=.15、P00=.65`，四项和为 1，边际保持不变。程序校验非负、归一化及 Fréchet 边界，拒绝本例 `P(A∩B)=.25`。浮点断言容差为 `1e-12`；独立性必须显式传入，不能默认为真。

这个练习只计 A 线概率基础素材，不满足 OB2/SBP-01 的论文公式/推理交付。它验证概率合同，不能把 token firing 次数当作概率，不能据此宣称掌握 SBPN 的完整 RCA，也不能直接迁移到 SBTPN。原文门语义若有附加条件，保留一般概率练习并单列映射缺口。

运行统一由主控完成。示例命令规格如下；脚本须在执行阶段先实现：

**九、从论文资产到研究的升级规则**

| 阶段 | 必交内容 | 升级条件与禁止事项 |
|---|---|---|
| 论文→机制资产 | P1/P2、来源坐标、接口、限制 | 无须每篇提出 idea；摘要或类比不能替代机制 |
| 机制→跨论文比较 | 对齐问题、输入信息、保证、成本、失败模式 | 图/Petri 网同形不等于语义相同 |
| 比较→候选 | 可反驳假设、受益场景、预期失效场景、最小验证 | 无机制差异或可测预测的“组合”不升级 |
| 候选→novelty 检查 | 最近邻及差异表，论文/开源/工业/负结果检索记录 | 未查到不等于不存在；窄范围差异不能写成领域首次 |
| novelty→研究 toy | 固定协议、独立真值、强基线、控制变量、资源预算 | 先通过方法检查再运行；toy 正结果不等于新颖性 |
| toy→后续研究 | 重复结果、失败解释、外部有效性和下一实验 | 不以候选数量、toy 数量或正结果验收 |

最近邻检索使用“问题、机制、保证、输入信息、预算”分别检索，并查引用/被引、开源 issue、企业机制说明及失败报告。记录具体检索式、日期、覆盖源和排除理由。企业材料只支持公开描述的机制，宣传指标不自动作为比较真值。

TR2 两天须交来自至少两个问题族的候选比较；优先审查“选择/表示与下游目标错配”“并发约束与可重演见证”“概率阈值/协同识别的误差与校准”。这些是问题种子，禁止预称创新。每个保留候选须有最近邻与简单强方案；充分否定后可交淘汰档案，不凑idea数量。TR3须为一个经初查仍有意义的候选交可执行toy协议；没有合格候选时，交完整否定证据和下轮检索动作。研究toy实际运行列目标交付，未运行不得算研究闭环完成。

“固定审查预算下选择轨迹”是待筛选示例，不是已选题。预注册规格至少包括：

- 固定各方法能看到的日志字段、历史范围、可用标签和预算；审查所得信息的使用时机一致。
- 真值由独立生成器的隐藏过程状态或穷举规则提供，不能由被比较方法自身打标签。
- 至少比较同信息同预算的规则/风险评分强基线、可运行的最近邻机制以及随机/分层参照；不确定性模型若未训练或拿到更多信号，不列为公平基线。oracle 仅作有特权上界。
- 协议必须冻结标签生成规则/对象状态机、每种失败族、正常/恶意条件、成本预算K、被测打分函数、参数搜索和退出阈值，不能只给样本数；具体协议见施工卡 RT-01。可按每种子100条开发、200条测试的起步规模，种子固定为 `11、23、37、51、89`；按过程配置分组，防止近重复泄漏。规模调整须在看测试结果前记录。
- 预算取同一可解释单位；若轨迹长度不同，额外报告事件读取及实际运行成本。参数只在开发集选择。
- 报告缺陷召回、漏检类型、成本和跨种子波动；逐项消融，不能只胜随机。
- 设置“可见日志相同、隐藏真值不同”的不可辨识对照。若方法无法区分，应解释信息限制；若优于基线仅来自额外信息，则候选失败。
- 强基线持平/更好、性能依赖单一种子或成本超限时，保留负结果，缩小或放弃候选。
