**共同局限(四篇通用,面谈时可作为"我能补的位"来讲)**:
1. **评测规模小、无真实场景数据**:全部是教学级基准/合成数据/仿真平台(CalFuzzer 例程、Juliet、Syn/TE),没有一篇在真实规模系统上验证;各自宣称的复杂度优势(多项式 vs 指数)都没有大规模实测支撑;

## 二、鲁组方法论 DNA

**怎么选题——"主流方法的信息丢失点"驱动**:四篇的立论结构完全同构:找到主流模型丢掉的一类信息(锁图丢执行轮次与释放-获取因果;分段图丢 lock-start 耦合;lockSet 丢历史锁;值流分析丢并发因果;时序因果发现丢 AND/OR 与协同),然后论证"丢失 ⟹ 假阳性/不可信",再用一个更精细的形式模型补上。**选题公式 = 已有模型 X + 被忽略的信息 Y → 扩展模型 X+Y → 消掉一类假阳性**。这与鲁侧图"每条线握一个主流未覆盖的可辩护差异点"的判断一致。

**怎么建模——PN 是"因果承载体"而非目的**:四篇里 PN 的角色都是**装偏序因果/资源语义的容器**:轨迹网装"谁先谁后+锁占用",分段 PN 装"控制流因果",SBTPN 的变迁装"因果规则"。当 PN 太重时,组里毫不犹豫退到图近似(SegLock),**判断标准是"信息够不够消掉目标假阳性",不是形式化纯度**。扩展手法固定三板斧:加节点类型(锁库所/协同弧/段)、加标签(时延/轮次/序号/概率)、加伴随构造(recover 变迁、伴随标签 α/β、伴随事件集)。

**怎么求解——离散判定优先,统计为辅**:D2 全线是"构造 → 环/死标记/兼容性判定"的判定式管线,连 D1 的 RCA 最后一步也是"概率打分 + 因果路径完整性"的双重离散过滤。**确定性、可解释、可重演**是全组统一的价值函数(重演三分判定"真/假/未知"宁可输出未知也不冒充确定,这个诚实度在写自己论文时应当继承)。

**怎么评测——自建对照 + 组内对标,轻外部基准**:评测惯式是"选一组能精确控制 ground truth 的小基准(自建例子/合成数据),对比 2–4 个经典方法,报精度+开销"。04 篇直接拿组内 02 篇当 baseline,说明**组内允许并鼓励内部路线竞争**。弱点同上("共同局限"第 1、2 条);发表阵地是 IEEE Access/JAS/TST 一线中刊(鲁侧图已判定:与 agent/SE/FM 社区声誉体系脱节,T 课题不应复制这个投稿习惯)。

## 三、进组准备清单

### 3.1 面谈可聊的 5 个具体技术话题

1. **"重模型 vs 轻模型"的能力边界**(04 vs 02):SegLock 精度持平 PNULock 但两篇都没回答"展开能推广到未观测交错、图方法是否也能"。我可以提议构造区分性样例集,把 trade-off 从耗时深化到检出能力——这是组内路线之争缺失的一块证据,话题安全且显示读透了两篇。
2. **D1+D2 闭环的第一个接口设计**:D2 的反例配置/源汇路径如何变成 SBTPN 的"异常事件"输入?具体障碍:D2 输出是偏序离散事件、SBTPN 要等间隔时序 + 噪声。〔08-15 后注(08-24 就地化):此障碍表述已过时——SBPN(06)静态截面无等间隔时序障碍,面谈话术以 09 §5 为准,原 README §四.②外部指针就地化〕可以带着一个草案去聊(事件窗口聚合 → 报警变量化,仿照 TE 实验的 3σ 高/低报警拆分)——直接对应鲁侧图"闭环无人占据"的判断。
3. **确定性重演迁移到 MAS**(T1/T3 的硬卖点):02/04 共用的"授权序列 δ + park/unpark 探针"调度器,把锁授权换成消息投递序即可复现多 agent 攻击;可讨论 MAS 场景里"跨运行 ID 映射"假设(输入相同、fork 序一致)会先在哪里破(LLM 非确定性输出 → 需要 seed 固定或语义等价类映射)。
4. **cut-off 循环摘要的独立价值**(03 篇埋着的点):用展开的 cut-off 事件做循环摘要替代 CBMC 定次展开,这个技巧目前没有单独量化;在 MAS 里对应"agent 循环交互(反思/重试环)的有限摘要",是 T3 里现成可复用的组件。
5. **SBTPN 的协同效应机制映射到腐败级联**(T4):防御/审计 = 抑制因子、信任/高权限通道 = 催化因子、多 agent 共谋 = AND 结构;顺带聊 η1/η2 定阈〔08-22 符号勘误:原文为 η〕与"根因对抑制不敏感"启发是否该形式化进算法 4——既展示读了正文也读了补充材料。
