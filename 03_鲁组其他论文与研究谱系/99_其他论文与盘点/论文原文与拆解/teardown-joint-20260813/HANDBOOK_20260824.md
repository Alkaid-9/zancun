## §三 维护手册（改动纪律）

### 3.1 数值质量四规则（08-24 用户批准,正本在 learning/methodology/SOP.md）

① ≥4 行数值表禁手填,脚本生成留档可复算;② 数字先源头(A4 类正本)后广播(指针面),禁同波次双改;③ 数值终判交付前必过 fresh-context 盲算(fable/GPT 轮换);④ 勘误注记三要素=错因/捕获者/修正依据,历史错误保留不静默清除。

### 3.2 指针面同步义务

改 A4 终判口径 → 必须 grep 同步全部指针（当前 9 处:README:16/05:16/09:16+179/04卡:76+80/STUDY_ROADMAP:19+39/02b 更新块）;反向（只改指针）禁止。验收命令:
```bash
grep -rn "1/2–1/6" --include="*.md" . | grep -v _archive/_review/_launch  # 应全部带勘误指针
python3 _audit_remediation_20260824/recalc_ratios.py                      # 数字应与 A4 §比值重算逐项一致
```

### 3.3 教学包闭环流程

开考 → 判分（SOP §5 键）→ 错题 48h 内记 mistakes.md（模板 M-P00_ 四步:错因/正确链/重考变体/复测日期）→ 变体入 B 卷池 → +1/+3 天延迟再测打标。mistakes.md 是唯一错账本,禁跳过直接重讲。
