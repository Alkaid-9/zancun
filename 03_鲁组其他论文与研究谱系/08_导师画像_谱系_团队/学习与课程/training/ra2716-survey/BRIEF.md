# 训练包 ra2716 · 导师调研：盲写画像 → 对账（科研情报能力）

**训练对象**: 桌面 `每日收获/调研中/`（RA-27）+ mentor-audit 三报告（RA-16）
**为什么这两个资产合成一个包**: 它们天然构成完美的训练闭环——`papers/ people/` 原始材料是**题面**，三份背调报告 + SYNTHESIS + 矩阵版审计是**现成的密封答案**（7-27~8-1 由 API 背调 + 多轮人工调研产出）。你先只用原始材料盲写导师画像，再开封对账：差距就是你调研能力的精确画像。
**主训练模式**: 盲做先行 + 对账。**产出双重性**: 这个包同时是 OE-1（9 月邮件，due 9-10）的弹药生产线——训练完成时素材包顺手成型。
**诚实设定**: 你可能读过部分现成报告（它们是 7 月底你在场的产物）。盲写不会纯"盲"，但训练价值不减：**凭记忆复述**与**用方法重构**的差距，恰好暴露"读过"和"内化了调研方法"的区别——对账时把"我记得的"和"我重新查证的"分开标，是本包的特殊纪律。

## §2 练习序列

### EX-01 · 盲写鲁法明研究画像 v0（90 min）

**题面**：只用白名单材料 + 公开网络，产出画像六维：
1. **研究方向分布**（近 5 年主题簇 + 各簇活跃度趋势——判断依据写明：发表年份分布？合作者变化？）
2. **代表作 Top 3**（每篇一句话：解决什么问题 + 为什么选它当代表作）
3. **合作网络**（核心合作者 + 机构；有没有工业界联系）
4. **学生与团队**（能查到的在读/毕业生规模与去向线索）
5. **接口点**（你的方向 A/B 和他的哪个具体工作能对上——精确到论文，不许写"都是 Petri 网所以相关"）
6. **不确定与缺口**（哪些维度查不到/证据弱——诚实标注，这一维的质量 Grader 单独看）
**过程纪律**：① 每条判断带来源（URL/文件+段落）；② "我记得的"与"我重新查证的"分开标（`[MEM]` vs `[VERIFIED]`）——只有 `[VERIFIED]` 计入对账得分；③ 90 分钟到点即停，完成度本身是估时能力的记录。
**交付物**：`EX-01_鲁法明画像v0.md`。
**hint**：H1"六维你漏了哪维的常规检索入口"→ H2 给一个检索入口（如"某数据库的作者页有 X 信息"）→ 本包无 H3（给答案 = 直接对账，无意义）。
**rubric**：（对账在 EX-02 出分）本 EX 只评过程分：来源纪律 40% · [MEM]/[VERIFIED] 分离诚实度 30% · 时间盒内的取舍质量 30%（60 分钟还在刷第一维 = 取舍失败）。

### EX-02 · 开封对账 + 差距归因（90 min）｜首铸卡：调研画像方法

**题面**：
1. （0-40 min）开封三报告 + SYNTHESIS + 矩阵版，逐维对账你的 v0：**重合**（你和报告都有且一致）/ **你漏**（报告有你没有）/ **你独有**（你有报告没有——可能是你的新发现，也可能是你的错误，逐条判定）/ **冲突**（结论相反，查谁的证据硬）。
2. （40-70 min）**差距归因**（本 EX 核心）：每个"你漏"归因到方法层——是检索入口没想到？证据看到了但没识别出信号？时间不够的主动放弃？归因写成"下次怎么改流程"而不是"我太菜"。
3. （70-90 min）铸卡：《调研画像方法》v0.1——六维清单 + 每维的检索入口表 + 证据分级（一手发表记录 / 二手转述 / 推断）+ 时间盒分配建议。**卡的内容 = 现成报告的方法逆向 + 你的差距归因**，这张卡是本包最重要的产出。
**交付物**：`EX-02_对账与归因.md` + `methodology/调研画像方法卡.md`。
**rubric**：对账完整性 30% · 归因深度 50%（到方法层，不到情绪层）· 卡的可操作性 20%（下次拿卡就能开工的程度）。

### EX-03 · 增量复核 + OE-1 素材包合成（90 min · 贴 8-25 后）｜衔接产出

**题面**：
1. （0-30 min）增量对照：开封 `research/bridge_scan_2026-08-12/`（8-12 四 Agent 调研新档）+ 三个 untitled 清账——新档相对 7 月底报告改了什么判断？BR-1（NSFC 放榜）需要复核的条目逐一查证（放榜信息 8-25 后可得）。
2. （30-75 min）素材包合成：产 `progress/research/oe1-materials/素材包.md`——每条素材 = 一句可进邮件的事实 + 原档坐标（file+section）+ 时效标记（7-31 快照 / 8-12 新档 / 8-25 复核后）+ 归属话术分支（按 OE-1 的分支设计）。**素材句纪律**：只收 `[VERIFIED]` 级，转述必留锚（坐标腐烂 D1 教训）。
3. （75-90 min）交接：素材包挂到 outreach 线（OE-1 任务的输入），记 task_log 一行（这一步产出转正，出训练区进权威链）。
**交付物**：素材包（转正）+ 增量对照记录（留训练区）。
**rubric**：素材坐标完整率 100% 硬要求 · 时效标记正确性 · 分支归属合理性。
