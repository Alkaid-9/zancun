## 使用方法

每个错误必须完成四步闭环:

1. **原错误句**:逐字记录,不替学员润色。
2. **证据定位**:TARGET_DIR 拆解文档的文件名 + 节名(必要时注明"以原 PDF 为准")。
3. **正确句**:可独立引用,消除歧义。
4. **迁移规则**:以后遇到同类问题时怎样检查。

红线错误修正后,还需闭卷重答原题;只阅读正确答案不算闭环。

## 预置高风险误区(从四篇易混点提炼;**不是实际错题**)

### P-01|四篇身份混淆

- 触发词:"鲁法明的 SBTPN""包云霞的 SegLock""四篇都发 Access"。
- 自检:背身份卡四行——01 王晓亮/JAS 2026;02 鲁法明/Access 2024;03 李珊珊/Access 2025;04 鲁法明+袁贵元通讯/TST 2026。
- 口令:**一作看 01 王 02 鲁 03 李 04 鲁,通讯看 01 鲁+周、02 包、03 包、04 袁**。

### P-02|"闭环已实现"错觉

- 触发词:"四篇形成检测→归因闭环""D2 的输出已经喂给 SBTPN"。
- 自检:查互引事实(仅 03 引 02);闭环出自鲁侧图 §1 的空位判断。
- 口令:**零互引;闭环是机会不是事实**。

### P-03|展开 vs 弧标签技法混淆

- 触发词:"SegLock 也给每次执行建一个变迁""PNULock 用弧标签区分轮次"。
- 自检:02 = γ 一一映射、每次执行独立变迁;04 = 弧标签 ⟨segID,(t,lockSet),m,segID⟩^(k);03 = 静态分段 PN 保留分支。
- 口令:**02 变迁级、04 弧标签级、03 静态段级**。

### P-04|精度/开销数字倒挂

- 触发词:"SegLock 更准""PNULock 检测更快""SegLock 内存最小"。
- 自检:精度 SegLock = PNULock;检测时间 SegLock 为 1/2–1/6;内存 iGoodlock < SegLock < PNULock;PNULock 检测慢于 iGoodlock(用时间换精度)。〔⚠️ 08-24 勘误：原文“1/2–1/6”为整体范围宣称；共享 8 基准真实 1.70–6.35×（中位 2.76×），Table 5 对标数字整列错位，非逐项保证；见 02b §〇.2 与 _audit_remediation_20260824/A4_pdf_verification.md §终判。〕
- 口令:**持平不超越;快在时间、让在内存下限**。

### P-05|三种"锁×线程启动"因果的归属

- 触发词:"lock-start 是 PNULock 提出的""Canary 能识别 lock/fork 耦合"。
- 自检:02 问题 2 = 释放-获取因果(锁弧天然编码);03 = lock/fork 耦合(vs Canary 增量,伴随标签 α/β);04 = lock-start + lock-held 两种新增(图方法物化)。
- 口令:**同一问题三种载体:锁弧 / α β 标签 / 段间弧**。

### P-06|协同弧当因果弧

- 触发词:"催化变量也是原因之一""把 S 并进 F 简化模型"。
- 自检:S 与 F 分离;催化/抑制经式 6/7 的 λ 权重修正的是根因概率打分 Pr(p̂i∣p̂j)(定义层面=提高/降低因果规则成立的概率);候选取 UnrelatedPlaces;误并 = MTE/PCMCI 错法。
- 口令:**协同改概率,不改因果向**。

### P-07|评测规模与开源状况夸大

- 触发词:"在 Chrome 上验证过""D2 工具都能下载"。
- 自检:四篇基准 = CalFuzzer 例程/Juliet/Syn/TE 全为教学级或仿真;CVE-2021-21148 只是 03 的动机;仅 SBTPN 开源(netlearninglabs/SBTPN),D2 三篇未开源是**推断**。
- 口令:**小基准、一仓库、推断要带标注**。

### P-08|三分判定说成二分

- 触发词:"重演成功=真死锁、失败=假死锁"。
- 自检:全部 δ 清空+成环=真;清空+正常终止=假;其余=未知(Program 1 的假阳性被"未知"拒绝确认)。
- 口令:**宁可未知,不冒充确定**。

### P-09|跨篇数字张冠李戴

- 触发词:"UAF 篇 recall 高 33.3%""SBTPN 比 SOTA 高 25%"。
- 自检:+25%/+33.3% 是 03 vs Canary 的 recall/precision;+3%/+15.1% 是 03 vs Saber;11%+ 是 01 的 RCA 摘要口径;1/2–1/6 是 04 的检测时间比。〔⚠️ 08-24 勘误：原文“1/2–1/6”为整体范围宣称；共享 8 基准真实 1.70–6.35×（中位 2.76×），Table 5 对标数字整列错位，非逐项保证；见 02b §〇.2 与 _audit_remediation_20260824/A4_pdf_verification.md §终判。〕
- 口令:**每个百分比先说属于哪篇、比谁、量什么**。
